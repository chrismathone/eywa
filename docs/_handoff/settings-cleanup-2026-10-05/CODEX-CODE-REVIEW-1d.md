2026-10-05. 리뷰 1c 이후의 version·수정 표식·훅·관련 배선과 테스트를 재검토했다. **중요 D1·D2 때문에 수리가 필요하다.** 기존 N1 반례의 훅 처리와 테스트는 제대로 보강됐지만, 앱이 호출하는 SQL writer 한 곳이 표식을 되돌릴 수 있고, 편집용 ‘행 없음’ 읽기를 버전 모름으로 취급하는 구멍이 남았다. 수동 스크립트의 운영 전제 D3는 경미 후속이다.
