# 계획 검증 기록

2026-10-02 · 대상은 이번 워크트리의 계획 문서뿐이다.

## 커밋 전 자체 검토

- 사용자 요구가 빠지는지 점검: 별도 워크트리, 실제 Claude/Grok 협의, 영어→수학, 강사 배치↔통합 학생 배정, 자유 배치/충돌 이유, 전체 단축키, 스마트 추천, 선택적 JEV, 구글 추가 탭 보존을 각각 문서와 완료 기준에 연결했다.
- 검토자 의견을 사용자 결정으로 바꾸는 위험: Grok의 N/X 기능 제외와 엔진 우선순위를 최종 정책으로 자동 채택하지 않았다. 남은 수식 이견을 명시했다.
- 2-way 비교로 운영 변경을 지우는 위험: 3-way, 안정 ID, 명시적 delta, 최신 상태 재검증을 추가했다.
- 숨겨진 기존 월별 계획을 유실하는 위험: 데이터 보존과 한 방향 가져오기, 자동 폐기 금지를 추가했다.
- 검사 경로가 다른 정책을 갖는 위험: 물리 위반·기존 확인 정책·추천 가능 여부·정보 부족을 분리했다.
- 표시 안 되는 배치/학생을 안전하다고 보는 위험: 교시 밖 배치, 동명이인 ID, 분리등원 재매핑, 기간별 외부 점유 시험을 추가했다.
- 셀 Delete가 수강 종료 또는 숨은 유지가 되는 위험: 초안의 미배정과 명시적인 유지/이동/종료 의도를 분리했다.
- 수식/엔진의 내부 이력이 운영 상태를 바꾸는 위험: 하나의 명령 이력, 명시 값 확정, 자동 네트워크/운영 쓰기 금지와 실제 실험을 요구했다.
- 완료 과장 위험: 모든 성능 수치는 목표이며 실측하지 않았음을 표시했다. 단축키 전수 실행·엔진 선정·기능 구현·배포가 미완료임을 표시했다.

## 실제 수행 범위

- 읽기: 로컬 소스/결정 문서, 공식 Google Sheets·편집 엔진·TypeSafe 문서.
- 작성: `docs/timetable-lab/`의 계획 문서와 Claude/Grok 검토 보고서.
- 실제 모델 협의: Orca Run `run_6a03da3620b6`, 검토 2건 + 교차 검토 2건, 모두 succeeded 보고.
- 수행하지 않음: 애플리케이션 코드 수정, DB 조회/쓰기, 운영 시트 읽기/쓰기, 패키지 설치, 앱 테스트, 브라우저 기능 검증, 배포.
- 원본 검토서는 당시 의견을 그대로 보존한다. 최종 채택 여부는 `decisions.md`가 설명한다.

계획 문서 12개를 UTF-8로 읽어 확인했고, 상대 링크 19개가 모두 존재함을 확인했다. Git 공백 검사 후 계획만 커밋한다. 이 기록은 향후 구현 검증을 대신하지 않는다.
