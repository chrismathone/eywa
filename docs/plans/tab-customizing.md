# 탭 및 메뉴 구성 — 구현 및 검증 계획

## 목표와 결정

- 학원 공통 관리자 메뉴: 큰 탭 추가·이름·아이콘·순서·삭제, 내부 메뉴 배치·이름·아이콘·순서·숨김.
- 대시보드·고객센터·설정은 고정한다. 설정 복귀 경로도 서버 검증과 읽기 양쪽에서 보장한다.
- 등록된 목적지만 배치한다. URL·권한키·모듈·원장 전용·담당 반 조건은 코드의 원본 정의에서만 가져온다.
- 강사뷰의 별도 표시·순서 설정과 홈 우선 규칙을 보존한다. 관리자 변경이 강사 메뉴를 덮지 않는다.
- 아이콘은 실제 이미지가 존재하는 기존 메뉴 아이콘 중 선택한다.
- 관리자 기본 구성 복원은 관리자 탭/메뉴 설정만 초기화한다. 저장 전 취소할 수 있고 강사뷰는 유지한다.
- 먼저 현재 격리 워크트리에서 dev로 제공한다.

## 데이터 및 호환성

- `navigation.menus`의 href 식별자는 유지하고 label/icon/groupId를 추가한다.
- `navigation.groups`에 안정적인 id별 이름·아이콘·순서·숨김을 저장한다. 기본 그룹은 코드에서, 새 그룹은 저장값에서 합성한다.
- 기본값은 빈 override 배열. 기존 숨김/순서는 그대로 읽고, 새 메뉴는 기본 위치의 뒤에 나타난다.
- 사라진 목적지·알 수 없는 아이콘·잘못된 필드·중복·없는 그룹을 읽기 시 정규화한다. 저장 시에는 명시적으로 검증한다.
- 구버전 폼이 새 필드를 누락하면 저장된 새 필드와 강사 구성을 보존한다. 신버전 초기화는 명시적 빈 배열로 구분한다.

## 반드시 검증할 사례

- 기존 저장값 없음 / 기존 숨김·순서만 있음 / 구버전 폼 저장 / 기본 구성 복원.
- 새 그룹, 이름·아이콘 변경, 그룹 간 메뉴 이동, 삭제한 그룹의 메뉴 재배치, 빈 그룹, 긴 이름.
- 같은 권한키의 서로 다른 목적지(`/billing?tab=…`, 출결·셔틀 면)를 독립적으로 변경.
- 권한 없는 메뉴, master 전용, super_admin, 담당 반 필요, 일반판 전용, 꺼진 모듈을 이동·개명해도 조건 유지.
- 기본 이름과 변경 이름 양쪽 검색, 숨김/이동 후 현재 위치 판정, 메뉴 직접 진입, 새로고침·창 복원.
- 두 테넌트의 설정 격리, 강사 홈·설정 보존, 고정 항목 변조 차단.
- 잘못된 저장값 폴백, 신규 코드 메뉴 추가, 서버 저장 실패 시 편집 상태 유지.
- dev 확인은 운영 설정을 바꾸지 않는 격리된 미리보기 또는 로컬 데이터로 진행.

## 조사에서 확인한 누락

- 모바일은 HUB 목록 대신 NAV_GROUPS를 평탄화하여 그룹과 query 목적지가 누락된다.
- 사이드바 현재 위치는 기본 HUB_GROUPS에서 판정하므로 그룹 이동을 반영하도록 수정해야 한다.
- iframe title 관찰이 창 열 때 준 메뉴 이름을 덮는다. 창 렌더 시 현재 주소에 맞는 표시값이 필요하다.
- 저장은 서버 캐시를 갱신하지만 iframe 밖 부모 셸 갱신은 별도로 연결해야 한다.

## dev 확인 방법 및 범위

- **미리보기:** http://localhost:3017/dev/navigation — 로그인 없이 실제 편집기·스키마·메뉴 해석기로 확인. ‘미리보기에 적용’ 후 아래 ‘적용 결과’에서 그룹·검색·역할별 노출 확인. 새로고침하면 초기 상태.
- **실제 설정:** http://localhost:3017/owner?tab=navigation — 로그인한 학원의 실제 저장 화면. 저장하면 해당 학원 전체에 적용.
- dev 전용 미리보기는 production에서 404. 운영 학원 설정 저장 및 배포는 수행하지 않았다.
- 서버 저장은 Supabase를 mock한 액션 검사까지 완료했다. 로그인한 실제 학원에 저장하는 E2E와 서로 다른 기기 간 반영은 이번 검증에 포함하지 않았다. 같은 브라우저의 열린 문서는 저장 신호로 갱신하며, 다른 기기는 다음 조회/새로고침 때 반영된다.
- 아이콘은 기존 이미지 카탈로그에서 선택한다. 외부 이미지 업로드는 포함하지 않는다. 이름 길이는 큰 탭 24자, 내부 메뉴 40자.
- 내부 기록 제목·날짜·권한명은 원래 의미를 유지한다. 커스터마이징은 메뉴 표시 이름에 적용한다.

## 후속 — 폴더처럼 담는 드래그 앤 드롭

- 왼쪽 큰 탭 / 열린 탭의 내부 메뉴 / 검색 가능한 메뉴 보관함을 나란히 배치한다. 좁은 화면에서는 보관함이 내부 메뉴 위에 놓인다.
- 보관함의 메뉴를 탭 위에 놓으면 해당 탭에 담긴다. 내부 메뉴를 다른 탭으로 옮기거나, 메뉴 사이 삽입선·맨 아래 영역·빈 탭에 놓을 수 있다.
- 큰 탭도 손잡이로 순서를 바꾼다. 고정 탭은 드롭 대상으로 등록하지 않는다. 영역 밖 드롭과 Esc는 편집 내용을 바꾸지 않는다.
- `navigation-placement.ts`로 드래그·화살표·소속 선택의 이동 처리를 통합했다. 같은 목적지가 중복 생성되지 않으며 이름·아이콘과 기존 저장 payload를 유지한다. 드롭은 편집 상태를 바꾸고, 실제 학원 적용은 기존 저장 버튼에서 이뤄진다.
- 드롭 대상 강조, 삽입선, 끄는 메뉴 표시, 결과 안내, 가장자리 자동 스크롤을 제공한다. 키보드는 스페이스·방향키·Esc, 터치는 손잡이를 사용한다. 보관함 본문을 쓸면 목록을 스크롤할 수 있다.
- 후속 확인: 타입 검사·변경 파일 lint 통과. dev 브라우저의 포인터 이벤트로 메뉴의 탭 간 이동·메뉴 정렬·탭 정렬·보관함에서 빈 탭에 담기·Esc 취소·미리보기 적용을 확인했다. 390px 폭에서 가로 넘침 없음(clientWidth/scrollWidth 380px).
- 위 291개 테스트는 최초 구현 시 결과이며 이 후속 변경에서 자동 테스트를 추가하거나 다시 실행하지 않았다.

## 후속 — 강사뷰 동등 구성, 기본 통계, @메뉴 참조

### 요구와 연결 계획

1. 강사뷰도 같은 폴더 편집기를 사용한다. `teacherMenus`에 이름·아이콘·소속을 확장하고 `teacherGroups`를 별도로 저장한다. 관리자뷰와 강사뷰 초기화는 각각의 배열만 비운다.
2. `teacher-menu-links`와 입구 정책을 강사 원본으로 사용한다. 셸에서 계산한 실제 권한·담당 과목 조건을 먼저 적용하고, 해당 강사의 홈을 항상 첫 항목으로 둔다. 기본 설정에서는 기존 평면 목록을 유지하고 폴더를 구성한 경우 서브메뉴로 연다.
3. `/admin`의 이용 분석은 기본 URL → 메뉴 키 → 기본 이름 경로를 유지한다. 지점의 이름·폴더를 계측 키나 분석 라벨로 읽지 않는다.
4. 공지와 고객센터에서는 `@`로 **메뉴 목적지**를 선택한다. 작성·읽기 UI의 칩은 지점의 현재 이름을 쓰고, 저장된 참조와 운영자 화면은 기본 목적지/이름을 쓴다. 일반 텍스트의 단어를 자동 치환하지 않는다.

### 구현 연결

- 강사 `teacherNavigationFor` → 실제 `TeacherMenu`/공유 폴더 렌더러 → 강사·임베드 `NavigationProvider` → 화면 제목·내부 탭 표시까지 연결.
- 강사 배열의 스키마, 읽기 정규화, 구버전 저장 보존, 감사로그, 변경 revision, 저장 후 갱신은 기존 단일 저장 경로를 사용한다. `teacherGroups` 기본값을 두 프리셋 모두에 등록했다.
- 이용 계측은 실제 경로만 전송하고 서버 `toUsageRows`가 기본 `menuKeyOfRoute`로 분류한다. 분석 화면은 `MENU_LABEL`/`SUBTABS_BY_MENU`를 계속 사용한다. dev의 메뉴 선택 결과에도 기본 분석 이름을 함께 표시한다.
- `menu-mentions.ts`의 기본 목적지 목록과 `@[기본 이름](menu:/목적지)` 참조 형식을 공통 사용한다. DB는 기존 text 필드를 사용하므로 마이그레이션은 없다. 편집기는 저장 구문을 칩으로 보여 주고, 입력/붙여넣기/다시 편집할 때 같은 참조를 보존한다.
- `@` 후보는 현재 이름과 기본 이름 모두로 검색한다. ↑↓/Enter/Esc와 클릭으로 선택한다. 한국어 IME 조합 중 Enter는 선택으로 소비하지 않는다. 편집기는 지연 로드한다.
- 적용 범위: 슈퍼관리자 공지 **본문**, 고객센터 요청 **본문**, 운영자 **답변**, 학원 팝업 공지 **본문**. 모든 작성창에 “메뉴를 설명할 때는 @를 입력해 선택해 주세요” 안내를 제공한다. 제목은 일반 텍스트다.
- 공지 상세/요청 상세/답변/팝업 읽기 모두 같은 `MenuMentionText`를 사용한다. 슈퍼관리자 요청 상세는 기본 이름으로 읽으며 지점 업무 화면으로 이동하는 링크는 만들지 않는다. 지점의 메뉴 링크는 기존 페이지 권한 검사를 따른다.
- 알 수 없거나 폐기된 목적지는 저장된 기본 이름을 일반 텍스트로 표시한다. 임의 외부 URL과 HTML은 메뉴 링크가 되지 않는다. 본문 길이 초과는 서버가 거절하므로 참조를 중간에서 자르지 않는다.
- 영문 팝업 번역은 메뉴 참조를 그대로 유지하도록 지시하며, 반환된 목적지 목록이 원문과 다르면 번역을 저장하지 않는다. 표시 시 강사 화면 언어/현재 이름이 적용된다.

### 확인 현황과 범위

- 타입 검사·변경 파일 lint 통과. dev 페이지 HTTP 200 및 실제 클라이언트 렌더 확인.
- 강사뷰에서 이름 변경 → 새 폴더 → 보관함의 메뉴를 포인터로 드롭 → 적용 → 실제 공유 드롭다운의 폴더 열기/메뉴 선택 확인.
- 홈을 폴더로 옮기고 숨겨도 첫 항목 유지. 영어 전담에서 수학 메뉴 제외, 제한된 권한에서 허용 메뉴만 표시. 강사 기본 복원 후 평면 기본 구성/기본 이름 복귀, 한영 전환 확인.
- 같은 참조가 지점에서는 `@우리 수업 일정`, 운영자에서는 `@시간표`로 표시됨. 기존 참조를 유지한 채 이름 변경/기본 복원/영어 전환이 작성 칩과 읽기 화면에 반영됨. `@시간` 후보에서 Enter로 원자 칩 삽입 확인.
- 390px 폭에서 문서 clientWidth/scrollWidth 모두 380px로 가로 넘침 없음.
- 이 후속에서는 자동 테스트를 추가하거나 다시 실행하지 않았다. 앞의 291개 결과는 최초 관리자뷰 구현 당시 결과다. 실계정 DB 저장, 실제 공지 게시·고객센터 전송, 영문 번역 API 호출, 다른 기기의 갱신은 수행하지 않았다. 운영 데이터와 통계에 개발 확인 내용을 기록하지 않는다.

dev 하단 **공지·고객센터 @메뉴**에서 직접 입력하고 지점/운영자 표시를 비교할 수 있다.

## 푸시 전 추가 점검

- 사용자 요청 “이상없으면 밀어”에 따라 관련 회귀 검사를 재실행하고 강사 폴더·드롭 배치·기본 통계·메뉴 참조·실제 작성 편집기 검사를 보강했다.
- **38개 파일 / 416개 테스트 통과.** 강사 실제 메뉴 및 기존 권한·번역·통계 검사도 포함한다.
- 구버전 강사 초기화 시 `href`만 남던 무의미한 행을 제거했다. 이름·아이콘·폴더 같은 새 설정을 보존하는 정책은 유지한다.
- `@메뉴`를 문장 중간에 붙여넣을 때 생기던 앞뒤 줄바꿈을 수정했다. 실제 편집기의 후보 선택/저장 형식/설정 갱신/붙여넣기/IME·Esc 처리를 검증했다.
- 강사 그룹 필드와 공통 렌더러 분리에 맞춰 기존 테스트의 데이터 모양·배선 경로를 갱신했다.
- 푸시 대상은 작업 브랜치 `chrismathone/tab-customizing`이다. 실제 학원 설정 저장·공지 게시·운영 DB 변경은 수행하지 않는다.
