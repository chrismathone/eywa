## 2026-10-14 — 수업보고서 이름 앞에 반명 붙이기

- 내 정보의 수업보고서 이름에 선택 토글. 기본은 꺼짐이며 본인 계정 `users.report_class_name_prefix`에 이름과 함께 저장한다. 화면 보기 취향이 아니라 학부모 발송 명의 설정이다.
- 켜면 `보고서 반명 + 공백 + 발송용 이름`(미입력 시 실명). 반은 보고서 `class_id` 기준이며 반 정보가 없으면 이름만 표시한다. 동명 직원이 있으면 기존 안전 규칙에 따라 이름 변경·접두 모두 적용하지 않는다.
- 원스크린 행별 미리보기·공유 링크·인쇄·ClassNote 이미지와 게시 작성자명에 적용한다. 귀속·통계용 `lesson_reports.teacher_name`은 그대로다. 이미 발송된 이미지·게시 작성자명은 소급 변경하지 않고, 공유 링크는 현재 설정을 따른다.
- 앱과 워커의 표시 규칙은 패리티 테스트로 검증한다. 워커 신규 조회는 동기화 API 허용 목록과 실행 파일 목록에도 포함한다.
- ClassNote 게시 작성자명은 새 워커 적용 후 반영된다(하트비트 `caps.reportAuthorClassPrefix`). 웹 배포만으로 이미 실행 중인 워커를 갱신하지 않는다. 관리형 연동 앱은 다음 정식 앱 릴리스에 이 런타임 소스를 포함해야 한다(레거시 워커 ZIP만 적용하는 방식과 구별). 기존 게시물은 수정·재발송하지 않는다.

## 2026-10-03 운영점검 합의 — 미리보기와 공지 확인

- 원스크린 미리보기는 **가용 폭이 좁으면 버튼으로 열고, 넓으면 기존 3열**을 유지한다(원장 선택). 2026-08-05의 오른쪽 고정·가로 스크롤 결정은 넓은 폭에만 유지한다. 휴대폰도 버튼 방식이며, 배율·사이드바를 제외한 실제 콘텐츠 폭을 기준으로 한다. 보고서 입력 카드는 이동·재마운트하지 않고, 대화상자는 같은 상태의 미리보기를 보여 준다.
- 원생 개별 공지는 서버가 실제 수신 대상과 제외 사유를 먼저 계산해 확인받는다. 확인과 큐 적재는 같은 해석기를 쓰며 대상·본문·첨부·발송 설정이 달라지면 다시 확인한다. 반 검색으로 숨겨진 선택은 유지하고 수를 표시한다. 100반·1,000수강 한도에서 조용히 잘리지 않도록 청크와 페이징을 함께 적용한다.
- 발송 응답이 유실되면 성공·실패를 추측하지 않는다. 확인 창을 닫고 이력을 다시 읽으며 작성 내용은 유지한다. 지문은 중복 방지 토큰이 아니라 대상 변경 감지용이다.
- 학부모 글은 최근 14일을 100개씩 조회하며 게시시각·id 순서와 전체 수를 함께 사용한다. 영상만 있는 글의 재생·답글 경로는 유지한다.

- 모드 A와 B의 P2에 원문과 보존 지침을 코드로 동봉해 학원별 프롬프트를 편집해도 적용한다. 문장 수·날짜 금지는 실제 메모 사실을 지우는 근거가 아니다. 수행률로 특정 과제 미수행을 대체하지 않고, 명백하게 충돌하는 일반 요약보다 구체적인 메모를 우선한다. 숫자를 임의 보정하지 않는다.
- 공통 FACT_GUARD, 학생별 입력, 말투 프로파일의 내용 전이 금지, 사과/양해 원문 보존, 추세 항목 분리는 유지한다. 기존 저장/발송 문구를 자동 변경하지 않으며 다음 자동작성부터 적용한다.

## 강사 원스크린 목록·안내 (원장 2026-10-03)

- 가운데 수업 전환은 유지한다. 왼쪽도 **수업별** 목록으로 표시하고 같은 학생이 정규·특강을 들으면 각 반 아래에 보인다. 선택은 해당 보고서로 연결되고 발송/출결은 그 수업만 판정한다.
- **기존 보고서 라벨만** 발송 완료는 초록, 수업 종료 후 미발송은 붉은색. 이름 옆의 중복 상태 문구/배지는 제거한다. 마지막 교시 종료 시각을 기준으로 하며 결석·보고서 제외 수업은 경고하지 않는다.
- 멘트·글씨 크기는 상단 `설정`으로 묶되 계정 저장은 유지한다. **발송 완료 설명의 다시 보지 않기만** 사용자 지시로 이 브라우저의 localStorage에 저장한다(일반 뷰 설정의 계정 귀속 규칙에 대한 명시 예외). 설정에서 다시 켤 수 있다.
- 날짜 글자를 누르면 달력을 연다. 출결 모드 진입은 흰색, 모드 안의 종료는 파란색이며 강사 홈으로 돌아간다.
- 카드·표의 학생 수는 중복 제외 기준으로 일치시킨다. 보고서 건수는 별도다. 정렬은 반별(기본)/가나다이며 계정에 저장한다. 직접 지정한 반 내 순서를 저장하면 반별 표시로 전환한다.
- 상단 학생·진도·테스트·발송·마감 집계는 중복이라 제거한다. 반별 표에서는 학생 행의 반 이름을 반복하지 않고, 가나다/순서 편집에서는 남긴다.
- 카드 특이사항은 두 번째 열의 생성 문구 위에 둔다. 일괄 입력은 데스크톱 2열/모바일 1열, 공지 이력은 5건씩 접힌 목록으로 표시한다.
- 이전 내용 숨김도 계정 설정으로 두 화면이 공유한다. 이전 내용 토글은 설정 한 곳에만 둔다. 표의 참고 칸은 최대 두 줄, 마우스·포커스에서 전체 표시. 원문은 줄이거나 저장값을 바꾸지 않는다.
- 카드의 일괄 작업과 표의 상세 편집은 **기존 공통 작업 화면을 재사용**한다. 보고서 행은 학생 id + 수업 이름으로 선택하며 모드를 바꿔도 같은 상태·권한·저장/발송 핸들러를 사용한다. 일괄 적용/이전값 가져오기는 선택된 행만 채운다(다른 수업으로 태도·과제가 새지 않게).
