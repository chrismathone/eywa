## 2026-11-04 — 영어 Monthly Test = 영어 월말 칸 · 영역 넷 + 총합 자동

- 원장 *"monthly test 결과 담을 수 있는 … 시험 이름은 … 먼슬리테스트 … 듣기 읽기 말하기 쓰기 총합 이렇게 들어가게 총합은 자동 SUM"*. 영어 시험 칸 = 듣기평가·중간·기말 + **`monthly`(화면 이름 `Monthly Test`)** — 새 칸 키를 만들지 않고 수학 월말평가와 같은 `monthly`(월 축 0288a)를 쓴다. 이름만 과목별(`examSlotLabel` · `exam_name`에도 그 이름).
- 🔑 행의 `score` = **영역 합**(서버가 영역에서 다시 셈 — 화면 총합은 안 믿는다) · `max_score` = 영역 만점 × 4 · 영역 값 = `area_scores` jsonb(s2_0023, 키 listening·reading·speaking·writing). 그래서 추이·평균·학생 상세는 총합으로 그대로 돈다.
- 🔴 엑셀·원장 행 수정은 총합만 고친다 → 영역 값은 **합이 맞을 때만** 보여 준다(어긋난 영역은 지우지 않고 다음 영역 입력이 덮는다).
- ⚠️ 영향: 강사평가 '월말평가 응시율'·원생 기여도 참여는 `monthly` 기록을 과목 구분 없이 읽는다 — 영어 Monthly Test를 적은 달부터 영어 담임에게도 그 항목이 계산된다(그 달 기록이 있는 과목만 · 마감 월은 그대로).

## 2026-10-14 — 성적 원장 열 머리: 정렬은 넷 · 나머지는 엑셀식 값 필터 · 점수 칸 제목 '점수'

- 원장 *"성적관리에 정답률 -> 점수 로 변경"* — 원장(통합 성적 '성적 기록') 점수 칸 **제목만** '점수'. 칸 값은 그대로(기록 단위 `4개 / 5개`·`84점 / 100점`), 이 칸의 필터 선택지는 그대로 **만점 대비 비율**(90% 이상·60~89%·60% 미만 — 2026-09-24 결정: 단위가 섞인 값을 거르는 것이라 %가 정직하다). 학생 상세 '성적' 탭 칸 제목도 '점수'(원장 2026-10-14 *"점수로 교체"*).
- 원장 *"오름차순/내림차순 필요없는 제목 행에 대해서는 엑셀처럼 필터적용가능하게"* (구글 시트 '값별 필터링' 화면을 보여 줌) → **정렬 = 시험일·이름·점수·증감**만. **학교학년·반·담임·시험·시험정보 = 엑셀식 값 필터**([`HeaderValueFilter`](../../src/components/header-value-filter.tsx)): 검색 · 모두 선택 · 지우기 · (공백) · 취소/확인. 체크를 바꾸고 **확인**을 눌러야 걸린다.
- 주소 값 규칙 단일 소스 = [`value-filter.ts`](../../src/lib/value-filter.ts)(서버 거르기와 화면 체크가 같은 풀이): `a,b` = 이것만 · `!a,b` = 이것만 뺀다(체크가 절반 넘게 남으면 이쪽 — 주소가 짧고, 기간을 넓혀 새로 생긴 값은 보인다) · 빈 칸은 '(공백)' 하나 · 한 줄에 값이 여럿(두 반)이면 하나라도 고른 값이면 보인다 · 값 안 쉼표는 역슬래시로 감싼다. 옛 한 값 링크(`fClass=c2`)도 그대로 '이것만'.
- 검색칸 Enter = **검색 결과만** 건다(엑셀 빠른 검색 — 결과 중 체크한 것, 없으면 결과 전부). 확인 버튼은 숨은 값의 체크까지 그대로(구글 시트).
- 툴바 '시험'(`kind`)을 바꾸면 열 머리 '시험'(`fKind`)·'시험정보'(`fInfo`)를 푼다 — 어긋나 0건이 되지 않게. 검색칸의 한글 조합 중 Enter는 걸지 않는다. ⚠️ 엑셀 내보내기는 열 머리 필터를 반영하지 않는다(원래부터).
