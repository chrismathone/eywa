영상 과제 제출 관리

회차마다 제출 상태를 기록하고, 학생·반·담당교사별 현황을 한눈에 확인합니다.

시안용 예시 데이터입니다. 학생명은 가명이며 실제 시트와 자동 연동하지 않습니다. 동일한 이름도 학생·반별 기록 ID로 구분하는 화면을 가정했습니다.

학생별 제출 기록

회차 칸을 누르면 상태가 바뀝니다. 학생을 열면 상세 기록과 메모를 볼 수 있습니다.

✓ 제출◷ 시간 표시 제출 · 제출수 포함× 미제출· 미기록 · 집계 제외

집계 방식 제출수 = 제출 + 시간 표시 제출, 수업시수 = 제출 + 시간 표시 제출 + 미제출. 빈칸은 두 수치에서 제외합니다. 0회 기록은 제출률을 계산하지 않습니다.

회차 입력만으로 바로 집계

✓ 제출 +1 제출 · +1 시수◷ 시간 표시 +1 제출 · +1 시수× 미제출 +0 제출 · +1 시수· 미기록 집계 제외

‘⏰’의 정확한 운영상 명칭은 원본 자료에서 확인되지 않아 이 시안에서는 ‘시간 표시 제출’로 표기했습니다.

관리 우선순위

    반별 제출 현황

    학생 기록을 반별로 묶고, 제출수 합계 ÷ 기록된 수업시수 합계로 계산합니다.

    담당교사별 현황

    기록이 없는 학생도 기록 수에 포함합니다.

    관리상태 임시 기준

    원본 내보내기에 상태 계산식은 포함되지 않았습니다. 아래 값은 원본 출력과 맞는 잠정 기준이며, 화면에서만 조정됩니다.

    평가 시작 회차기록된 수업시수가 이 값보다 작으면 ‘관찰중’
    정상 제출률평가 대상 중 이 비율 이상이면 ‘정상’
    %

    전체 제출률은 각 학생의 비율 평균이 아닌 제출수 합계 ÷ 수업시수 합계입니다. 원본 시트에는 현재 제출현황과 원본데이터가 다른 행이 있어 실제 도입 때 원본 대조가 필요합니다.

    강사 사전 검사 화면

    보고서 입력 전에 영상 과제를 확인합니다. 카드와 표는 같은 기록을 사용합니다.

    영상 과제 사전 검사는 보고서의 ‘과제 수행률’과 별도 항목입니다. 강사가 선택한 회차 상태는 위 관리자 집계에 즉시 반영됩니다.
