# 탭 아이콘 만들기 — 어떤 이미지 생성 모델을 쓰든 **같은 세트**가 나오게

> 원장 지시(2026-09-08): *"다음에 어떤 이미지 생성 모델이든 같은 시리즈의 아이콘을 생성할 수 있도록
> 아이콘 생성 관련한 일관성있는 문서를 만들어두고."*

aywa의 **탭·내부 탭 아이콘은 손으로 그린 SVG가 아니라 이미지 생성물(PNG)** 이다. 화풍은 원장이
시안 네 갈래(이모지 · 스티커 · 말랑3D · grok 3D) 중에서 고른 **B 스티커**로 확정됐다.
🔴 **다시 선화 글리프로 되돌리지 말 것** — 그 이유로 한 번 반려됐다.

이 문서 하나면 **모델이 바뀌어도** 같은 세트를 이어 만들 수 있다. 순서는 아래 5단계 그대로다.

---

## 0. 지금 있는 것이 곧 기준이다

- 현재 세트: **`public/icons/*.png` 49장**(128px, 합계 약 660KB).
- 새 장을 만들 때는 **말로 된 설명보다 이 파일들을 먼저 열어 보게** 하라. 사람이든 모델이든,
  "같은 세트로 보이는가"의 판정 기준은 문장이 아니라 그 그림들이다.
- 기준 3장을 굳이 고른다면 `calendar.png` · `users.png` · `wallet.png`(원장이 화풍을 고를 때 본 시안).

---

## 1. 화풍 규격 (프롬프트에 그대로 넣는다)

- **납작한 단색 면**(그라디언트는 아주 약하게만) + 면 바깥을 두르는 **굵은 흰색 테두리**
  (스티커를 오려 붙인 느낌) + 그 바깥에 아주 옅은 그림자.
- 팔레트는 **보라 · 코럴레드 · 노랑 · 흰색** 중심. 또렷하고 대비가 세다.
- 형태는 둥근 모서리의 기하 도형. **디테일은 적고 덩어리는 크다.**
- **512×512 정사각, 배경 완전 투명**(알파 채널).
- 그림은 가운데, 사방 여백 약 6%.
- **글자·숫자 금지**(도움말의 물음표만 예외). **얼굴(눈·입) 금지** — 작게 줄이면 얼룩이 된다.
- **18~20px로 줄여도 형태가 읽혀야 한다**(사이드바 18px · 폰 메뉴 14px · 메뉴 보드 38px).
  잔디테일·가는 선·작은 점 금지.

> 🔴 **흰 테두리는 장식이 아니다.** 활성 탭 배경이 남색(`--primary #153e75`)이라, 테두리가 없으면
> 보라 면이 배경에 묻힌다. 이 화풍이 채택된 근거가 그것이다.

---

## 2. 생성 (모델은 무엇이든)

이 PC에서 실측으로 이미지 생성이 되는 CLI는 **codex**와 **grok**이다.
(⚠️ `--help`에 안 보인다고 "불가"라고 답하지 말 것 — 한 번 그렇게 잘못 답했다.)

```bash
codex exec -C . -s workspace-write --skip-git-repo-check - < brief.md
```

- 🔴 **codex 이미지 생성을 3개 이상 동시에 돌리지 말 것** — `STATUS_DLL_INIT_FAILED`로 프로세스 생성이
  실패한다(2개까지). vitest·dev 서버와 겹쳐 돌리면 더 빨리 터진다.
- 🔴 **grok은 경로가 260자를 넘으면 저장에서 실패**한다 — `C:\tmp\…`처럼 짧은 작업 폴더에서 돌릴 것.
- 브리프에는 **한 장씩 만들고 곧바로 저장·검사**하라고 적는다. 한 장에 오래 매달리지 않게 하고,
  픽셀을 재는 스크립트·HTML 미리보기·대조 표를 새로 만들지 말라고 못박는다(속도가 급격히 떨어진다).

### 브리프 뼈대

```markdown
# 화풍 기준 = `public/icons/`의 기존 그림
작업 전에 calendar.png · users.png · wallet.png를 반드시 열어 보라. 새로 그리는 모든 장이
이 세 장과 **같은 세트로 보여야** 한다.

(위 "1. 화풍 규격"을 그대로 붙인다)

## 절차
1. 한 장씩 생성 → `raw/<name>.png`에 저장.
2. 저장 직후 `powershell -File scripts/_icons/check.ps1 <name>`으로 검사.
   OK면 다음 장, FAIL이면 그 장만 다시 생성(최대 3회).

## 목록
- `<name>.png` — (형태를 한 문장으로. 예: "둥근 시계판 + 굵은 시침·분침")
```

## 3. 🔴 생성물은 그대로 못 쓴다 — 반드시 후처리

실측(2026-09-08, 49장): **생성물의 40%가 배경 불투명**으로 나왔고, 다시 뽑으면 이번엔
**흰 테두리 유무와 내용 크기가 장마다 갈렸다.** 모델을 탓할 일이 아니라 **파이프라인으로 흡수**한다.

도구는 전부 [`scripts/_icons/`](../scripts/_icons)에 있다. 입력 폴더는 `ICON_SRC`,
출력 폴더는 `ICON_OUT` 환경변수로 준다(기본값 `raw` / `final`).

### ① 투명 검사

```bash
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/_icons/check.ps1 <name> [<name>...]
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/_icons/alpha.ps1   # 전수 + 투명 비율
```

네 모서리 알파가 0이어야 `OK`. 실패 유형은 셋이고 고치는 법이 다르다:

| 증상 | 모서리 색 | 고치는 법 |
|---|---|---|
| 회색 체크무늬를 **그림으로 그림** | 회색 두 톤(~135/~200) | `ungrey.py` |
| 흰(또는 근백색) 배경 | 240~255 | `unbg.py` |
| 검정 배경 / 검정↔흰 체크 | 0 | `unbg.py` |

```bash
ICON_SRC=raw PYTHONUTF8=1 python scripts/_icons/ungrey.py mapPin receipt
ICON_SRC=raw PYTHONUTF8=1 python scripts/_icons/unbg.py clock wrench
```

- 🔴 **검정 배경에 `ungrey.py`를 쓰지 말 것** — 그쪽 배경 판정은 *무채색이면서 밝기 100~232*라
  검정(0)을 애초에 배경으로 안 본다(실측: `ungrey.py blackbg` → `FAIL 0.0%`, 한 픽셀도 안 지운다).
  검정은 `unbg.py`가 맡는다 — 배경색을 고정값이 아니라 **테두리에서 가장 자주 나온 두 색**으로 잡기 때문에
  검정이든 흰색이든 검정↔흰 체크무늬든 같은 방식으로 지워진다(실측: 같은 그림에 `unbg.py` → `OK 77.7% 제거`, 모서리 알파 0).
  ⚠️ 번짐은 4-이웃이라 **대각선으로만 이어진 칸**은 남을 수 있다 — 그때는 다시 뽑는 편이 빠르다.

- `unbg.py`는 **테두리에서 시작한 flood fill이 스티커의 그림자 링에서 멈추는 성질**을 쓴다
  (흰 배경과 흰 테두리는 색이 같아 색만으로는 못 가른다). 허용오차를 좁게 잡고, 지운 넓이가
  안전 범위를 벗어나면 **저장하지 않고 실패를 보고**한다 — 반쪽짜리 결과를 남기지 않는다.
- `ungrey.py`는 "무채색이면서 밝기가 회색 구간"을 배경으로 본다(체크무늬 경계의 안티에일리어싱까지 덮으려고).
- 🔴 **세 번 다시 뽑아도 안 되면** 후처리로 가는 게 맞다. 같은 장을 네 번째 다시 뽑지 말 것.

### ② 규격 통일 (이게 세트를 세트로 만든다)

```bash
ICON_SRC=raw ICON_OUT=final PYTHONUTF8=1 python scripts/_icons/sticker.py
```

[`sticker.py`](../scripts/_icons/sticker.py)가 한 번에 한다:

1. 알파 바운딩박스로 **트리밍** → 여백 제각각을 없앤다.
2. 내용을 캔버스의 **72%**(`CONTENT`)로 맞춰 가운데 배치 → 나란히 놓아도 크기가 안 튄다.
3. **같은 두께의 흰 테두리**를 두른다(`RING = 0.075` = 캔버스의 7.5%. 알파를 가우시안 블러 뒤
   급한 램프로 잘라 둥글게 부풀린다 — 모서리가 뾰족해지지 않는다).
4. 아주 옅은 그림자를 아래로 깐다.

🔴 **테두리를 생성 모델에 맡기지 말 것.** 맡기면 장마다 두께가 갈리고, 그 차이가 18px에서 그대로 보인다.

### ③ 대조 시트로 눈 검수

```bash
ICON_OUT=final powershell -NoProfile -ExecutionPolicy Bypass -File scripts/_icons/contact.ps1
```

칸마다 **큰 그림 / 남색 활성 탭 18px / 옅은 배경 18px / 허브 38px**을 함께 그린다.
**남색 위 18px에서 읽히는지**가 유일한 합격 기준이다.

## 4. 앱에 넣기

```bash
ICON_OUT=final powershell -NoProfile -ExecutionPolicy Bypass -File scripts/_icons/apply.ps1 public/icons
node scripts/_icons/wire-names.mjs .
```

- `apply.ps1` — 512px 원본을 **128px로 줄여** `public/icons/`에 넣는다
  (화면 최대 38px × DPR 3 = 114 → 128이면 충분. 512 그대로 넣으면 49장에 8MB다).
- `wire-names.mjs` — `public/icons`의 파일 목록을 [`MENU_GLYPH_NAMES`](../src/components/icons/menu-glyph.tsx)에 박는다.

**새 이름을 쓰려면 네 곳이 다 필요하다:**

| 곳 | 파일 | 없으면 |
|---|---|---|
| 카탈로그 | `aywa-icons.tsx` `AYWA_ICON_CATALOG` | `AywaIconName` 타입에 없어 타입 에러 |
| 선화 글리프 | `aywa-icons.tsx` 글리프 맵 | 그림이 없을 때 폴백이 빈 칸 |
| 그림 | `public/icons/<name>.png` | 가드 실패(그리고 선화로 폴백) |
| 소비처 | `MENU_ICON` 또는 `menu-hub.ts`의 `icon:` | 고아 파일로 가드 실패 |

## 5. 규칙 (가드가 잠근다)

- 🔴 **뜻이 다르면 그림도 다르다**(원장 2026-09-08 *"같은 아이콘을 안쓰면 좋겠는데"* — 메뉴 보드에서
  출석부와 수업 평가가 같은 클립보드였다). 선화 시절엔 공유해도 티가 덜 났지만, **색이 박힌 그림은
  나란히 선 타일에서 곧바로 같은 것으로 읽힌다.**
  - ⚠️ **같은 곳으로 가는 두 입구는 예외**(수납관리↔월별 청구·수납 / 교재↔billing 교재 탭 /
    지출↔billing 지출 탭 / 연동↔설정 연동 면) — 거기서 그림을 가르면 다른 데로 간다는 거짓 신호가 된다.
- 🔴 적용 범위는 **탭과 내부 탭뿐** — 사이드바 업무군 · 메뉴 버튼 · 강사 '내 메뉴' · 폰 상단 메뉴.
  버튼 안 보조 아이콘·툴바 글리프는 그대로 선화(`EyIcon`)다. **앱 전체를 갈아치우지 말 것**
  (저장 버튼까지 알록달록해지면 위계가 무너진다).
  - 🔴 **창 전환 스트립**(`spotlight-strip.tsx`)은 일부러 제외 — 카드마다 틴트가 돌아가고 아이콘이
    그 틴트 색을 따라가는 설계라, 색이 박힌 스티커를 넣으면 그 짝이 깨진다.
- ⚠️ 색이 그림에 박혀 있어 `className`의 글자색을 **따라가지 않는다**. 대비는 흰 테두리가 책임진다.

**가드**: [`menu-glyph.test.ts`](../src/components/icons/menu-glyph.test.ts)
— 그림 파일 존재 · 고아 파일 없음 · 메뉴가 쓰는 이름 전부 커버 · 탭 표면 4곳이 `MenuGlyph`를 실제로 그림 ·
서로 다른 메뉴가 같은 그림을 안 씀.

## 실패 사례 모음 (같은 함정을 두 번 밟지 않게)

| 무슨 일 | 왜 | 어떻게 했나 |
|---|---|---|
| 40장 중 19장 배경 불투명 | 모델이 "투명"을 **회색 체크무늬 그림**으로 그린다 | 브리프에 "체크무늬를 그리지 말 것" 명시 + `check.ps1` 즉시 검사 + 3회 실패 시 후처리 |
| 다시 뽑으니 흰 테두리가 사라짐 | 재생성은 화풍을 매번 다시 해석한다 | 테두리를 **후처리로 일괄**(`sticker.py`) |
| 이미 통과한 장이 재생성으로 망가짐 | 배치가 목록을 다시 훑으며 덮어씀 | 배치 끝난 뒤 **전수 `alpha.ps1`** 재검사 |
| 4개 동시 생성 중 프로세스 생성 실패 | `STATUS_DLL_INIT_FAILED` | 동시 **2개**까지 |
| grok이 저장 실패 | Windows 260자 경로 한계 | 짧은 작업 폴더(`C:\tmp\…`) |
| 손으로 그린 시안이 20px에서 한글 자모 'ㅠ'로 보임 | 가는 선 + 안쪽 여백 | 덩어리를 크게, 구분선은 테두리까지 |
