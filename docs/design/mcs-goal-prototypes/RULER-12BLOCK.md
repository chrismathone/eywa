# MCS 학기당 12블록 — 2026-09-18

이 문서는 기존 `RULER-24BLOCK.md`의 블록 수와 눈금 기준을 대체한다.

- 정규는 한 학기·과정 구간을 12블록으로 배분하며 월 4블록, 총 3개월이다. 단원과 수업일 원본은 유지한다.
- 복습·심화는 기존대로 월 4블록이며, 해당 반 수업일의 기록을 날짜별로 누적한다.
- 1차·2차 목표는 고정된 정거장이다. 작은 눈금 한 칸은 실제 1블록이므로 한 학기 분량은 12칸, 두 학기 분량은 24칸이다. 4블록마다 긴 눈금을 사용한다.
- 기존 정규 24블록 목표는 조회할 때 총 블록과 정거장 누적 블록을 절반으로 환산한다. 날짜, 단원, 수정 버전은 유지한다. 새 12블록 계획은 다시 나누지 않는다.
- 목표 확장 시 서버도 기존 정거장을 같은 단위로 환산해 비교하고, 12블록 단위로 저장한다. 과거 정거장 변경과 동시 수정은 계속 거절한다.
- `0273a_math_learning_twelve_blocks.sql`은 새 12블록 계획과 이전 24블록 계획을 모두 허용한다. 기존 저장 행은 변경하지 않아 배포 전후 읽기와 저장이 호환된다.
