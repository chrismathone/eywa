에이와 경영 분석 파일 수집기 1.1.0

대상: 에이와 경영 분석(원장 전용) 자료 수집함. Windows 10/11 + Windows PowerShell 5.1.
MakeEdu·ECOUNT에서 파일을 내려받는 작업은 수동입니다. 이 프로그램은 전용 폴더에 넣은 파일의 검증·전송만 예약 실행합니다.
보내는 곳은 https://www.aywa.co.kr 하나뿐입니다(연결 파일에 다른 주소가 적혀 있으면 설치하지 않습니다).

1. 학원에서 이 PC를 쓰는 Windows 계정으로 로그인합니다.
2. 에이와 경영 분석 → 자료 수집함 → 학원 PC 수집기에서 'PC 수집기 사용'을 켜고, 수집기 ZIP을 내려받아 압축을 풉니다.
3. 같은 화면에서 PC 표시 이름과 범위를 확인해 수집 전용 연결 파일을 발급합니다. 비밀번호·DB 키·다른 앱 설정은 필요 없습니다.
4. 설치.cmd를 실행하고 방금 받은 연결 파일(aywa-collector-....json)을 선택합니다. 연결 확인 후 Windows 사용자 암호화 저장소에 보관합니다. 원본 연결 파일은 설치 마지막 단계에서 휴지통으로 보낼 수 있습니다.
5. 수집폴더.cmd로 전용 폴더를 엽니다. 아래 폴더를 만들고 원본 XLSX를 넣습니다.
   makeedu\2026-10\수납통합내역_....xlsx
   ecount\2026-10\월별손익분석.xlsx
   MakeEdu 폴더의 월 = 청구월입니다. 전체원생·전체수납, 이전달 미납 제외로 출력한 파일만 넣으세요. 파일 자체에 청구월이 없어 폴더 지정이 원본 조회 조건의 확인을 뜻합니다.
   ECOUNT는 월별손익분석 XLSX 안의 실제 기간을 사용합니다. 해당 월의 계정별원장 CSV는 웹 경영 분석의 회계 영역에서 먼저 저장해야 합니다. 지원하지 않는 파일은 자동 확정하지 않습니다.
6. 파일 저장 후 30초가 지나면 수집 대상이 됩니다. 지금실행.cmd 또는 15분 주기 예약으로 전송합니다. PC 전원과 같은 Windows 계정 로그인이 필요합니다. 절전/종료 중에는 동작하지 않습니다.
7. 웹의 연결 상태 새로고침에서 마지막 접속·전송 성공을 확인합니다. 상태확인.cmd는 이 PC의 처리 요약을 보여줍니다. 접속 성공과 파일 전송 성공은 별도입니다.

중복·실패 처리
- 같은 파일은 하루 한 번 비교합니다. 에이와 자료가 바뀌었는지 다음 날 다시 대조하며, 서버는 파일과 비교 자료가 모두 같으면 중복 저장하지 않습니다.
- 중단 후 다시 시도할 수 있습니다. 전송은 됐지만 응답을 못 받은 경우에도 서버의 중복 방지가 적용됩니다.
- failed > 0 또는 connection_or_state_error: 인터넷·연결 유효기간·웹의 최근 결과·원본 형식과 월을 확인합니다. 다음 예약에서 다시 시도합니다.
- 웹에서 'PC 수집기 사용'을 끄면 모든 PC의 요청이 거절됩니다(다시 켜면 그대로 이어집니다).
- 수치 차이/식별 안 된 학생은 확인 업무로 기록합니다. 청구 변경·학생 삭제·회계 마감·문자 발송은 하지 않습니다.
- 원본 파일은 이동·삭제하지 않습니다. 최근 자료만 전용 폴더에 두고 보관 파일은 다른 폴더로 옮기면 다음 수집에서 제외됩니다. 한 번에 최대 20개, 파일당 4MB까지 처리합니다.

연결 만료·해제
- 연결 유효기간은 90일입니다. 웹에서 연결을 해제하면 이후 요청이 차단됩니다. 새 연결 파일을 발급해 설치.cmd를 다시 실행하면 다시 연결됩니다.
- 예약 중지: Windows 작업 스케줄러에서 AYWA-Collection-으로 시작하는 해당 작업만 사용 안 함으로 설정합니다. 다른 에이와 연동 작업은 그대로 둡니다.
- 설치 위치: %LOCALAPPDATA%\AYWA\Collection
- 실행 정책은 실행 프로세스에만 적용하며 컴퓨터의 기본 실행 정책을 바꾸지 않습니다.

아직 포함하지 않는 것: 원본 사이트 자동 다운로드, 학생·청구 실시간 동기화, 계정별원장 CSV 자동 확정, AI 자동 판단.
