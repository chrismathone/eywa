- **강사 보기에서 친 그날 합계는 그 강사 교시에만 나눈다 — 몫 판정은 서버가 화면과 같은 함수로** (원장 제보 2026-09-11 *"새로고침하면 강제로 어떤 숫자로 롤백"*). 나눔은 [`planDayCellUnits`](src/features/attendance/scoped-split.ts) 한 곳(`setAttendanceCell`·`setAttendanceRange` 공용) · 클라는 보기(`scopeTeacherId`)만 보내고 서버가 `ownsAttendanceSlot`으로 다시 판정한다([[#77]]). 🔴 **화면이 세는 교시와 저장이 나누는 교시는 같아야 한다** — 다르면 누가 쳐도 숫자가 틀어지고 사람들은 같은 숫자를 계속 다시 친다(4 → 2.7, 여섯 번). 🔴 새 출결 저장 경로에서 `splitUnitsAcrossSlots`를 직접 부르지 말 것(가드 `scoped-split-wiring.test.ts`). ⚠️ 상태는 종전대로 그날 모든 행에 간다 · 저장 쪽 몫 판정은 담임 시작일을 안 본다(반응속도 — 격자가 그 칸을 잠근다).

- **출석부 메뉴 기본 착지 = 월별 출석부** (`/attendance`, 2026-08-14). 사이드바 출석부(시간표 옆 부모 항목)를 누르면 월별이 열린다. 오늘 출결(`/attendance/live`)은 하부탭일 뿐 부모 href로 올리지 말 것. 하부탭 활성은 가장 긴 경로가 이긴다(`/attendance`가 `/attendance/live`를 같이 켜지 않게).

- **기간 단위 = 세션(`operating_periods`) 단일 소스, 미정의는 달력월 폴백** (0189a, 2026-08-07 원장: *"우리 학원은 세션으로 운영되기 때문"*). **세션 = 월~금이 각 4회씩 들어가는 구간**이고 공휴일로 빠진 요일은 다음 달로 넘어가서라도 채우므로 **라벨월과 실제 기간이 다르다**(2월 세션이 3/5까지 = 정상). 주말은 계산 대상이 아니지만 사이에 낀 날이라 구간에 편입, 공휴일은 회차에서 제외하되 출석부엔 날짜를 표기(휴일 서식). 🔴 **이름 셋을 구분할 것** — `session_units`(시수: 출석 한 칸이 몇 회분) · `*_sessions`(회차: 청구 N회) · **세션 기간**(`PeriodDef`/`PeriodWindow`)은 전부 다른 개념이고 셋 다 돈에 닿는다(새 코드에 맨몸 `session` 식별자 금지). 🔴 **폴백이 안전벨트** — 정의가 없거나 표가 아직 없어도(SQL 미적용) 예외 없이 달력월로 떨어진다(`resolvePeriodWindow` 밖에 폴백 분기를 두지 말 것). 검산("각 4회")은 **경고만** 하고 저장을 막지 않는다(법정공휴일 ≠ 학원 휴원일). 겹침은 DB(EXCLUDE)가 막는다.
