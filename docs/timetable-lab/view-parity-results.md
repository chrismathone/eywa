# 영어 연습실 — 강사뷰·통합뷰와 저장 색상

2026-10-02. 후속 지시: 영어는 기존 강사뷰에서 배치를 구성하고 통합뷰에서 학생 배정을 보며, 기존 색상과 화면 구성을 유지한다.

## 반영

- 강사뷰: 강사별 월~토(수업이 있는 일요일 포함) 주간 격자, 저장된 강사 순서·닉네임·배경/글자색, 격자 밀도·교시 경계·쉬는 시간. 요일 탭으로 하루만 보던 화면을 교체했다. 빈 요일 접기도 연습안에서 변경한다.
- 통합뷰: 기존 `buildRichCardGroups`를 공유하는 반별 카드. 수업명/강의실·담임·요일/교시 미니 격자·학생 명단, 저장 그룹 순서와 압축 교시축을 사용한다. 강사뷰와 같은 배치에서 즉시 도출한다.
- 불러오기: 수업색/글자색·담임과 강사색/글자색·닉네임, 지점 교시/그룹 설정, 로그인 계정의 강사 순서·접기 설정을 복사한다. 미래 주의 예약 그룹도 기존 예약 판정 함수를 사용한다. 예약 읽기 실패는 현재 배치로 조용히 대체하지 않고 불러오기를 실패 처리한다.
- 선택 수업 상세의 **색상 설정**: 강사색 또는 수업명 색상을 연습안에서 변경하고 Undo/Redo한다. 충돌은 별도 외곽선과 표식으로 표시하며 저장 색상을 덮지 않는다.
- 기존 운영 조회/표시 계산을 공유하되 운영 쓰기 컨텍스트·서버 액션은 편집기에 연결하지 않는다. 현재 계정의 보기 설정 읽기도 세션 RLS + tenant/user 조건으로 제한한다.

## 적대적 자체 검토와 수정

- 같은 반·요일·교시에 여러 배치를 놓으면 기존 읽기용 셀 맵이 마지막 항목으로 덮는 문제: 선택적 `sourceId/sourceIds`를 추가해 편집기에서 각각 표시/선택한다. 원래 읽기 뷰 입력·출력은 그대로다.
- 오전 수업을 축 하한에 표시할 때 오후 수업까지 밀리는 문제: 이른 수업에만 표시용 오프셋을 적용하며 실제 시간을 보존한다. 같은 화면 좌표의 오후 수업을 드래그해도 오전 시각으로 바뀌지 않도록 배치별 오프셋을 사용한다. 도착 위치 미리보기와 툴팁은 실제 시각을 보인다.
- 같은 과목의 타 요일 학생을 카드에서 잃는 문제: 실제 배치의 학생/요일 집합을 반별로 한 번 계산해 명단을 도출한다. 교시별 학생 이동은 기존대로 해당 배치만 바꾼다.
- 강사색이 경고 배경색으로 사라지는 문제, 교시선이 글자를 가로지르는 문제를 수정했다.
- 화면 검수에서 주말 하루 반의 폭이 줄어 이름이 잘리는 문제를 찾아 기존 카드의 최소 3칸 너비 규칙을 적용했다.
- LAB의 별도 수업 표시가 사람 강사로 이동한 뒤 남지 않도록 했으며, 복사에서는 해당 표시를 보존한다.
- 입력 스냅샷과 초안의 색상 객체를 분리했다. 명단 계산·셀 ID 조회의 반복 전체 탐색을 줄였다.

## 검증과 경계

- 실험 단위 25건 통과. 서버 소스/권한/색상과 기존 통합뷰 그룹·주말·교시 회귀 98건 통과.
- 전체 브라우저 정상 27건 + 원본 Univer Ctrl+Home의 예상 실패 재현 1건. 총 28건이 기대한 결과로 끝났다. 주말 너비와 오전/오후 표시 좌표 수정 후 신규 회귀 1건을 포함한 네이티브 화면 12건 및 실험 타입 검사를 다시 통과했다.
- 전체 앱 타입 검사 통과. 전체 ESLint 0 errors, 수정하지 않은 기존 파일의 warning 13개. 실험 production build 통과; 비교용 Univer 대형 chunk 경고는 유지된다.
- `experiments/timetable-lab-p0/.artifacts/teacher-week-view.png`, `integrated-class-view.png`를 직접 확인했다. 마지막 타입/lint/build 로그도 같은 폴더에 있으며 생성물은 커밋하지 않는다.
- 브라우저는 합성 응답이다. 실제 로그인 계정으로 운영 색상을 불러온 성공 경로를 검증한 것은 아니다. 색상 편집 중 운영 쓰기 요청이 0건임을 브라우저에서 확인했다.
- 최신 main `71418e490`을 작업 브랜치에 병합한 상태에서 검증했다. 별도 작업 브랜치를 유지한다.

공유된 통합뷰 계산은 기존 교시/주말/압축 규칙을 따른다. 현재 연습실 명단은 가져온 주의 활성 수강만이며 학교/학년·휴원/대기/퇴원 명단·학생 상태별 색상·임시 LAB 출결 표시는 아직 연결하지 않았다. 기존 운영 화면 전체와 동일한 기능이라고 주장하지 않는다.

영속 저장, 모든 단축키, 기본뷰·수학, 운영 반영은 후속이다. 수업 이동/복사는 강사뷰에서, 학생 배정 확인/교시 이동은 통합뷰와 상세에서 수행한다. 메모리 초안이므로 새로고침하면 사라진다.
