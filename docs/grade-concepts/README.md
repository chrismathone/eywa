# 통합 성적관리 화면 시안

- `index.html`: 기존 6개 시안을 하나의 성적관리 화면으로 합친 통합 시안. 전체 현황, 성적 원장, 학생 추이, 반별 분석, 학교·학년 분석, 시험 일정을 한 페이지에서 확인합니다.
- `concepts.html`: 처음 만든 개별 시안 6개를 비교하는 화면.
- `previews/unified.png`, `previews/unified-mobile.png`: 통합 시안의 데스크톱·모바일 이미지.
- `previews/1.png` ~ `6.png`: 기존 개별 시안 이미지.

모든 점수·학생·상담·일정은 레이아웃 검토용 예시 데이터입니다. 통합 시안의 원장 필터, 미입력 표시, 학생·반·학교학년 선택, 상담 수동 체크와 날짜 입력은 브라우저 안에서만 동작하며 저장되지 않습니다. 화면 색·글자 크기·테두리·버튼은 현재 앱의 디자인 토큰을 참고했습니다.
