# 단축키·클립보드 계약

2026-10-02 · 전체 호환이 목표다. 계획 당시 시험 0건에서 [P0 일부 실행 증거](P0-runtime-evidence.json)가 추가되었다. [공식 전체 목록](P0-shortcut-inventory.md)의 분모와 미시험 항목을 유지하며 전체 호환 완료로 표시하지 않는다.

## 전수 대조 원칙

- 사용자는 `Ctrl+C/V 등 스프레드시트의 모든 단축키`를 요구했다. 익숙한 몇 개만 만든 뒤 전체 지원으로 축소하지 않는다.
- 구현 0단계에서 [Google Sheets 공식 단축키](https://support.google.com/docs/answer/181110?hl=en&co=GENIE.Platform%3DDesktop)의 PC/Mac/ChromeOS 항목을 동결한 대조표를 작성한다. 원문 전체를 복제하는 대신 기능 식별자·키 조합·공식 출처·기대 동작·상태·시험 ID를 기록한다.
- 플랫폼마다 키 매핑이 다르므로 일괄 Ctrl→Cmd 치환으로 끝내지 않는다. 메뉴 순차키, 편집 모드 전용키, 스크린리더 관련 항목도 빠짐없이 조사한다.
- 상태: `미구현`, `엔진 문서상 제공·실행 미검증`, `앱 연결 필요`, `앱 예약키 충돌`, `브라우저/OS 제약`, `기능 결정 필요`, `검증 완료`, `실패`. 제약은 삭제해서 분모에서 빼지 않는다. 엔진이 아직 선택되지 않았으므로 현재 기본 제공으로 간주하는 항목은 없다.
- 일반 편집키와 앱 고유 의미(반 이동/학생 배정)가 연결되는 것, 구글 서비스 전용 기능인 것을 구분한다. 후자를 임의로 범위 제외하지 않고 대체 기능/제약을 공개한다.
- Google 자체도 언어/키보드 차이를 안내한다. 특정 환경에서 이벤트가 전달되지 않는 키는 도움말·메뉴·대체키로 접근 가능하게 한다. 이를 동일 단축키 완전 호환이라고 부르지 않는다.
- Grok 검토서의 `N`/`X`는 제외 제안이며 승인된 범위가 아니다. 사용자 요구가 우선한다. 수식/서식/행열 조작을 영구 미지원으로 확정하지 않고 P0에서 영역별 의미와 실현 방법을 검증한다.
- 연습 격자에 포커스가 있을 때 Ctrl/Cmd+K·B, Shift+F 등은 시트 편집 문맥을 우선한다. 격자 밖의 팰릿/사이드바 단축키는 유지한다. Ctrl+Enter 등은 입력 중/범위 선택 중을 분리해 실제 Google Sheets 동작과 대조한다.

## 기능군별 구현 책임

| 기능군 | 연습실에서 보장할 의미 | 필수 확인 |
|---|---|---|
| 복사/잘라내기/붙여넣기 | 텍스트·범위·배치·학생 연결을 문맥에 맞게 전달 | C/V/X 및 값만 붙여넣기, 외부 왕복 |
| Undo/Redo | 사용자 명령 한 묶음 복구 | 엔진/도메인 이중 이력 방지 |
| 셀 이동/범위 확장 | 연속/불연속/병합 범위와 가려진 행 규칙 | 방향키, Shift, 경계/페이지 이동 |
| 선택 | 셀/범위/행/열/전체 | 텍스트 편집 중 선택과 격자 선택 구분 |
| 셀 입력/지우기 | 직접 입력, 확정, 취소, 줄바꿈 | 한글 IME, Delete/Backspace, 빈 값 의미 |
| 채우기 | 범위 복제와 상대 참조 | 여러 수업/학생이 중복 생성되는지 검사 |
| 검색/치환 | 현재 안에서 찾고 변경 영향 확인 | 앱 전역 검색/브라우저 검색과 충돌 |
| 행·열 구조 | 표시 구조와 시간축 변경의 의미 분리 | 추가·삭제·숨김·복구·그룹 |
| 서식 | 표시만 변경 | 색/글꼴/정렬/테두리/표시 형식이 운영 값을 바꾸지 않음 |
| 수식 | 지원 엔진의 계산과 참조 | 상대·절대 참조, 범위 선택, 오류 표시 |
| 시트·연습안 이동 | 같은 연습안의 화면 이동 또는 명시 복제 | 숨김 탭/보조 탭/새 탭 이름 충돌 |
| 저장·열기·인쇄 | 연습안 저장과 미리보기 출력 | 저장 완료 표시, 브라우저 기본 동작 대체 여부 |
| 메모·댓글·이력 | 검토 의견과 변경 근거 | 미구현 항목을 단축키만 가로채지 않음 |
| 메뉴·도움말 | 동작 검색과 단축키 목록 | 마우스 없이 모든 핵심 명령 접근 |
| 접근성 | 위치·선택·오류·추천 결과 안내 | 포커스 보존, 스크린리더 출력, 색 외 표식 |

## 클립보드 경계

1. 같은 연습안 안: 셀 텍스트 외에 안정적인 배치/학생 ID와 명령 메타데이터를 보존한다.
2. 다른 연습안/다른 창: 지점/과목/기준 revision을 검증한다. 다른 지점 ID를 서버가 수락하지 않는다.
3. Google Sheets/Excel/텍스트: HTML/TSV를 임시 입력으로 파싱한다. ID 없는 이름은 수동 연결이 필요한 후보일 수 있다.
4. 잘라내기: 원본은 이동 예정으로 표시하고 붙여넣기 명령이 유효하게 완료됐을 때 제거한다. Esc/클립보드 교체/실패/창 닫힘은 원본을 지우지 않는다.
5. 붙여넣기는 원자적인 초안 명령이다. 범위 중 일부만 성공하는 경우를 기본으로 허용하지 않는다.
6. 병합 셀 일부, 필터/숨김 행, 서로 떨어진 선택, 전치, 빈 값, 여러 줄, 수식, 서식만 붙여넣기의 규칙을 데이터 계약으로 고정한다.
7. 붙여넣은 수식/HTML은 운영 데이터 쓰기를 유발하지 않는다. 외부 호출 함수·링크·HTML은 엔진의 보안 옵션과 앱 정책을 점검한다.
8. 운영 반영 시 임시 학생/반 연결과 잘못된 수식 결과를 서버가 재검증한다. 격자에서 보인 문자열만으로 반영하지 않는다.

## 엔진과 상태의 연결 실험

- 엔진을 고르기 전에 `입력 이벤트 → 의미 명령 → 도메인 상태 → 양쪽 화면`의 소유권을 확정한다.
- 엔진 내장 Undo와 앱 Undo가 별도로 움직이는 설계는 탈락시킨다. 셀 서식과 학생 이동을 연속 실행한 뒤 같은 이력에서 원복되는지 확인한다.
- 통합표의 수업 배치 셀은 강사표의 배치를 투영한다. 해당 셀 편집 명령은 강사 배치 편집으로 연결하거나 설명을 제공하며 별개 배치 값을 저장하지 않는다.
- 강사 열 이동은 표시 순서 변경과 담당 변경을 구분한다. 행 높이 변경은 수업 길이 변경이 아니다.
- arbitrary 행/열 삽입을 실제 교시 추가로 자동 해석하지 않는다. 교시 생성은 명시된 의미 명령으로 변환하고 미확정 영역은 연습 중 표시한다.
- 광범위한 스프레드시트 기능에 필요한 보조 메모/계산 탭을 검토한다. 운영에 반영되는 영역과 보조 영역을 명확히 구분한다.
- 수식은 연습 문서의 계산 기능으로 검증한다. 자동 재계산이 수업 시각/담당/학생 연결을 바꾸지 않으며, 일정 값으로 사용하려면 명시적 `값으로 확정` 명령(Undo 대상)을 거친다. 붙여넣기·자동 재계산으로 외부 요청이 발생하지 않아야 한다. 수식 지원을 가정하거나 영구 금지하지 말고 엔진별 실제 지원과 제약을 기록한다.

## 브라우저 시험

| ID | 실제 키보드/클립보드 시험 |
|---|---|
| K01 | 수업 2×3 범위를 복사해 다른 강사/요일에 붙여넣고 Undo/Redo |
| K02 | 여러 학생을 잘라내기 후 실패한 붙여넣기 → 원본 유지 |
| K03 | 구글 시트에서 병합·서식·여러 줄이 있는 범위를 복사하여 임시 검토 |
| K04 | 앱에서 구글 시트/Excel로 복사하고 다시 가져온 뒤 동일성 비교 |
| K05 | 셀 편집 중 Ctrl+A/C/V/Z와 격자 선택 중 같은 키의 문맥 구분 |
| K06 | 한글 조합 중 Enter/Esc/방향키/Shift 단축키가 조합을 깨지 않음 |
| K07 | 두 작업창을 열고 활성 창에서만 키가 작동하며 붙여넣기 대상이 섞이지 않음 |
| K08 | 검색/링크/도움말 키가 전역 팰릿과 이중 발화하지 않음 |
| K09 | HTTPS/iframe에서 Clipboard 권한 허용/거절, paste 이벤트 폴백 |
| K10 | 연결 끊김/자동 저장 오류 중 편집·Undo·복구 |
| K11 | 필터/숨김/병합/불연속 범위의 삭제·채우기·붙여넣기 |
| K12 | 키보드만으로 연습안 생성 → 편집 → 충돌 확인 → 추천 선택 → 저장 |

공식 API만 존재하는 것으로 통과 처리하지 않는다. 실제 브라우저의 신뢰된 키 입력과 클립보드 이벤트로 확인하고, OS별 미시험은 미시험으로 남긴다.

## 엔진 비교에 사용할 출처

- [Univer 클립보드](https://docs.univer.ai/guides/sheets/features/core/clipboard): 외부 앱 왕복과 선택적 붙여넣기 기능의 문서상 근거. 실제 Google Sheets 호환은 별도 실험.
- [Univer 저장소](https://github.com/dream-num/univer): 채택할 정확한 패키지·버전·라이선스 범위를 확인. OSS 엔진과 Pro 기능을 혼동하지 않는다.
- [Handsontable 라이선스](https://handsontable.com/docs/react-data-grid/software-license/): 평가와 상용 배포 조건을 구분한다.
- [AG Grid 클립보드](https://www.ag-grid.com/react-data-grid/clipboard/): 요구 클립보드 기능의 Enterprise 구분을 확인한다.
- 기존 dnd-kit은 현재 반/학생 드래그 재사용 후보지만, 그것만으로 스프레드시트 전체 기능이 제공되는 것은 아니다.
