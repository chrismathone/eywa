# 에이와 · 오늘의수학 연동 구현 완료 기록

2026-10-03 로컬 구현 완료 시점의 기록이다. 이후 사용자 승인에 따른 운영 적용은 [운영 적용 기록](todays-math-sync-production-2026-10-03.md)을 따른다. 실제 고정 운영 주소는 `https://www.aywa.co.kr`와 `https://today.aywa.co.kr`이다. 읽기 전용 조회로 침산의 원본 이름 `인재원 침산`, UUID `becaa316-e636-42e9-9d09-08b133e0b094`를 확인했다. 이 로컬 완료 시점에는 운영 DB 변경, Vercel 환경변수 변경, 원격 push 및 배포를 실행하지 않았다.

## 반영한 동작

- 공통 연결 설정을 한 번 입력하면 에이와 오늘의수학 ON으로 대상 지점이 자동 생성되고 재직 수학 교사·반·학생이 연결된다. 이후 지점별 환경변수/대상 지점 ID 등록은 필요 없다. 같은 이름이라도 고유 ID가 다르면 별도 지점이며 임의로 합치지 않는다.
- OFF·퇴사·자격 상실은 연동 계정의 이용과 기존 세션을 정지한다. 계정·반·학생·시험·학습 이력은 삭제하지 않는다. 다시 ON이면 같은 지점과 계정 ID를 재사용한다. 별도 수동 정지와 운영자 중지는 자동 해제하지 않는다.
- 이메일/이름이 일치하는 기존 계정은 동일인 후보로 보류한다. 본인 비밀번호 확인 또는 독립적인 확인 근거를 남긴 운영자 승인 후 연결/지점 이동한다. 불일치·중복은 기존 계정을 우선한다.
- 담당 교사·교시·대강·퇴사·이동·기간·휴원·복수 수강을 반영하고, 과거 자료의 지점 귀속을 보존한다. 중복/지연/역순 사건, 전송 장애와 재처리는 durable outbox/inbox 및 버전·세대·lease로 제어한다.
- 에이와 바로가기에서 오늘의수학 자동 로그인, 기존 다른 계정의 명시적 전환을 제공한다. 최초 접속이 웹훅보다 빨라도 검증된 원본 SSO 이후 연결된다.
- **원생 → 학생 상세 → 오늘의수학** 탭은 같은 학생 원장의 반·시험 현황·최근 기록을 조회한다. 풀이 결과를 에이와 DB에 영속 저장하는 역방향 이벤트 연동은 요청대로 추후 단계다.

에이와 최종 빌드는 실제 운영 자격 증명 대신 비운영 placeholder를 사용했다. 따라서 기존 공용 브랜딩 조회에서 예상된 네트워크 경고가 있었으며 빌드는 완료됐다. 오늘의수학은 최신 main의 별도 콘텐츠 작업을 병합한 후 전체 빌드와 로그인 HTTP 검증을 마쳤다. 공유 계약 파일의 SHA256은 양쪽 모두 `CF0B569D1A9F9BCBD94A6298DC80DA14FDA7018A6697A8F642F24A8B893C8B96`이었다.

이전에 실행한 넓은 회귀 범위에는 연동과 무관한 선수학습 알고리즘 테스트 1개가 남아 있다. 변경 전 원본 커밋에서도 동일하게 재현했으며, 기대값을 약화시키거나 관련 없는 알고리즘을 수정하지 않았다. 상세 증거는 오늘의수학 `docs/reports/eywa-managed-relations-2026-10-03.md`와 인접 baseline 기록에 있다. 별도 듣기 PostgreSQL 10개 테스트는 해당 전용 환경 설정이 없어 건너뛰었다. 따라서 프로젝트 전체 테스트가 모두 통과했다는 의미는 아니다.

## 운영 적용과 정리

실제 사용자 운영 로그인, 클라우드 cron/pg_net 전송, 운영 지연 시간은 배포 후 확인해야 한다. 별도 유료 큐·SSO 상품·상시 서버를 설치하지 않았으며 기존 서비스 사용량 한도/과금은 적용된다.

사용자가 수기로 입력할 비공개 `.env.eywa.local`, `.env.todays-math.local`, 선택 `.env.eywa-cron-if-missing.local`과 README를 작업 공간의 Git 제외 `work/todays-math-sync-<UUID>/`에 준비했다. 마지막 파일은 **운영 CRON_SECRET이 없을 때만** 사용한다. 기존 운영 값을 덮어쓰지 않는다. 적용 순서는 [운영 안내](todays-math-sync-operations.md)의 DB 변경 → 환경변수 → 수신/발신 배포 → 토글/로그인 확인을 따른다.

임시 컨테이너 `eywa-sync-fixture-20261003`와 그 전용 익명 데이터 볼륨은 모든 검증 후 삭제하고 부재를 확인했다. 다른 컨테이너·Docker 프로그램·다른 작업 프로세스는 중지하거나 삭제하지 않았다. 이 연동은 운영에 Docker를 요구하지 않는다.
