# eywa 현재 화면 기준

2026-09-10 전체 디자인 검수 후 적용 기준. 이전 선택의 내력과 세부 업무 제약은 [design-conventions.md](design-conventions.md)에 보존한다. 시각 수치가 충돌하면 이 문서와 `globals.css`의 현재 토큰을 따른다.

- 글꼴은 Pretendard, 기본 글자는 `#121212`, 흰 배경이다. 보조 정보는 위치·간격·500/700 두께로 구분한다. 과목·출결·위험 색은 기존 의미색을 사용한다.
- 본문 16/18px, 보조 정보의 바닥은 14px. 화면에 개별 px 글자 크기를 새로 만들지 않는다. A4 지면은 `paper-scale` 예외를 유지한다.
- 컨트롤 라벨 18px, 높이는 `--control-label / --control-fill`, 현재 fill은 **0.62**다. 내부 탭과 세그먼트의 클릭 높이도 이 수식에 맞춘다. 버튼/입력 모서리는 8~12px.
- 목록은 기간·주요 동작·현재 결과와 첫 업무 항목이 함께 보여야 한다. 업무용 요약은 `StatStrip`과 기존 `BigStat`으로 짧게 구성한다. 큰 분석 지표는 기존 카드형을 사용한다.
- 결과 수·필터·검색·등록 버튼은 한 줄을 우선한다. 별도 행을 고정하지 않고 실제 공간이 부족할 때만 감싼다. 금액·날짜·사람 이름 안에서 줄을 끊지 않는다. 여러 업무 단계의 대기 건수는 단계마다 따로 표시한다.
- 상위 면 전환은 `FaceTabs`, 면 안의 하위 선택은 `level="secondary"`를 사용한다. 긴 면은 가로 탐색과 현재 위치를 보존한다.
- 이름은 학교·설명·보조 배지보다 먼저 읽혀야 한다. 숫자는 tabular 정렬, 날짜·단위는 같은 열에서 같은 형식. 0·미입력·계산 불가·조회 실패를 구별한다.
- 등록상담 4열/고정 높이/이름+학교 한 줄, MCS 정규/특강 좌우 구분, 시간표·출결의 고정 축을 유지한다. 필요한 가로 스크롤을 글자 축소로 없애지 않는다.
- 폼은 필수 정보를 먼저 묶고 부가 도구는 접을 수 있게 한다. 저장 바·초안·미저장·동시 편집 보호는 유지한다.
- 메뉴별 실제 기본/최소 창에서 확인한다. 전체 화면에서만 검수하지 않는다. 대시보드 `view=one`도 글자·색 기준의 예외로 방치하지 않는다.
- 기본 `/dashboard`는 전체 현황이다. 모든 업무 창을 닫거나 최소화하면 이 화면이 보이며, 기존 메뉴 격자를 배경으로 표시하지 않는다. 공지 관리와 일일 브리핑은 대시보드에서 별도 창으로 연다.
- 퇴원 목록은 우측 사유 카드 높이에 맞춰 페이지 크기를 정한다. 마지막 페이지에서도 카드와 페이지 바 위치를 유지하고, 페이지 전환은 필터·스크롤 위치를 보존한다.
