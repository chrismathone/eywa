# 통합 연동 앱 실패 상황과 수용 기준

이 표는 [상세 설계](./unified-sync-agent.md)의 검증 기준이다. 1.0.0 구현 후 실제로 실행한 기기·권한·DB·업데이트·패키지 시험과 남은 현장 검증은 [수용 검증 보고서](../_audit/sync-agent-acceptance-2026-10-08.md)에 기록했다. 아래 전체 목록이 모두 시험을 통과했다는 의미는 아니다. 기존 코드의 가상 회귀만으로 새 EXE나 실제 외부 서비스의 통과 판정을 대신하지 않는다.

## 등록과 권한

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| A01 | 코드 11자리/13자리/문자/앞자리 0/공백·하이픈 | 정규화와 길이 검증. 앞자리 0 보존. 코드 원문 로그 없음. |
| A02 | 만료 직전/직후 요청과 PC 시계 오차 | 서버 시각으로 결정. 만료 코드는 등록하지 못함. |
| A03 | 같은 코드를 두 PC가 동시에 사용 | 한 등록만 성공. 다른 등록과 자격증명은 생성되지 않음. |
| A04 | 서로 다른 코드 발급 요청을 동시에 실행 | 지점의 유효 미사용 코드 한 개만 남음. |
| A05 | 등록 커밋 후 HTTP 응답 유실 | 같은 설치 증명으로 결과 복구. 새 기기/키를 계속 생성하지 않음. |
| A06 | 재발급 전 코드를 다시 사용 | 거절. 기존에 등록된 PC는 별도 해제 전까지 유지. |
| A07 | 무작위 코드 대입·IP 분산 | 입력/전체 발생률 제한. 응답으로 코드 존재·지점명 노출 안 함. |
| A08 | 공격자가 실패를 쌓아 지점 잠금 유도 | 피해 지점의 기존 실행이나 정상 코드 발급을 영구 차단하지 않음. |
| A09 | 사용자 입력 tenant ID 조작 | 세션/기기 등록의 지점만 사용. 다른 지점 조회·쓰기 없음. |
| A10 | 다른 지점 관리자 세션/권한 없는 사용자 | 코드 발급·로그·기기 관리 모두 서버에서 거절. |
| A11 | 퇴사·권한 회수 후 열린 브라우저/앱 설정 저장 | 현재 권한 재검사. 오래된 화면의 변경 요청 거절. |
| A12 | 기기 토큰으로 코드 발급/권한 변경/임의 SQL 시도 | 기능별 권한 분리. 요청 거절 및 민감 정보 없는 감사 기록. |
| A13 | 코드/토큰을 URL, 오류, 원문 로그에 포함 | 저장·표시·업로드되지 않음. 테스트용 탐지 문자열로 검사. |
| A14 | 기기 키를 다른 PC에 복사 | OS 보호 저장소와 기기 소유 증명 검증. 동시 유효 실행 한 개. |
| A15 | 잘못된 지점의 유효 코드 입력 | 서버 지점명 확인 단계에서 작업 전에 취소 가능. |
| A16 | 앱 서버 주소를 악성 주소로 변경 | 일반 설정에서 불가. 자격증명이 임의 호스트에 전송되지 않음. |

## 중복과 실행 잠금

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| D01 | EXE 더블클릭 두 번 | 인스턴스 하나, 기존 창 표시. |
| D02 | 설치 폴더 복사 후 두 번째 EXE 실행 | 단일 실행과 서버 실행 잠금으로 동시 처리 없음. |
| D03 | Windows 다른 사용자/RDP 세션에서 실행 | 같은 지점 동시 실행 차단. 잠금 권한 오류를 허용으로 처리하지 않음. |
| D04 | PC 이름이 같음/바뀜 | 불변 기기 ID로 구분. 다른 PC를 같은 PC로 인증하지 않음. |
| D05 | 두 프로세스가 같은 순간 서버 잠금 획득 | DB 경쟁 시험에서 한 실행 세대만 승인. |
| D06 | 소유 프로세스 종료 후 PID 재사용 | 다른 프로세스를 소유자로 오판하거나 종료하지 않음. |
| D07 | 로컬 잠금 파일/폴더 쓰기 실패 | 실행 제한과 오류 안내. 무잠금 발송 허용 안 함. |
| D08 | 네트워크 분리 뒤 옛 소유자가 늦게 재접속 | 이전 실행 세대의 작업 승인/상태 덮어쓰기 거절. |
| D09 | 긴 makeedu 동기화로 이벤트 루프 정지 | 공통 heartbeat 갱신 지속. 정상 작업을 오프라인으로 오판하지 않음. |
| D10 | PC 교체 중 기존 PC가 살아 있음 | 신규 수신 중지·작업 종료·기존 등록 폐기 후 새 PC만 실행. |
| D11 | 고장 난 PC 교체 후 구 PC가 돌아옴 | 구 키/실행 세대로 작업하지 못함. |
| D12 | 새 앱과 구 Windows 스케줄러가 함께 존재 | 전환 점검이 시작을 막음. 구 자식 프로세스 종료까지 확인. |
| D13 | 강제 종료 뒤 오래된 잠금 | 서버 만료와 작업 대조로 복구. 수동 파일 삭제를 일상 절차로 요구하지 않음. |
| D14 | 서버/PC 시계 역행, 미래 시각 | 실행 잠금과 예약 판정은 서버 기준. 무기한 잠금이나 이중 실행 없음. |

## 토글과 설정

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| C01 | 운영 측 OFF, 지점/PC ON | 해당 연동 새 작업 실행 0건. |
| C02 | 지점 모듈 OFF, PC ON | 새 작업 실행 0건. 일반 화면에 꺼진 연동 이름을 불필요하게 노출하지 않음. |
| C03 | 앱 설정 파일을 편집해 허용되지 않은 연동 ON | 서버 작업 승인에서 차단. |
| C04 | 작업 도중 OFF | 새 작업 수신 중지. 이미 접수된 외부 요청 결과를 기록하고 중단 상태 표시. |
| C05 | 설정 조회 실패/오래된 캐시 | 최신 허용 상태를 모르는 상태에서 새 부작용 작업 시작 안 함. |
| C06 | 전체/연동별 일시 중지 후 재부팅·업데이트 | 중지 상태 지속. 시간 지정이면 만료와 서버 허용을 함께 확인. |
| C07 | 웹과 앱에서 동시에 설정 수정 | 설정 버전 충돌 감지. 최근 값을 조용히 덮지 않음. |
| C08 | makeedu 정기 동기화 OFF 후 허용된 수동 요청 | 기존 의미에 맞게 수동 실행 가능. 연동 전체 OFF와 구분. |
| C09 | 클래스노트 발송 OFF/발송 시간창 밖 | 기존 발송 가드 유지. 단순 기동 점검으로 실발송하지 않음. |
| C10 | 새 연동 모듈이 업데이트에 포함됨 | 명시적으로 허용/설정되지 않은 기능 자동 시작 없음. |
| C11 | 알려지지 않은 설정 키/범위 초과/잘못된 시간 | 앱·서버 검증에서 거절. 예측 불가능한 기본값으로 실행 안 함. |
| C12 | 계정 비밀번호 변경·OAuth 해제 | 해당 연동만 연결 확인 필요. 다른 연동 유지. |

## 작업과 외부 서비스

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| J01 | 외부 발송 성공 후 응답 유실 | 외부 결과 대조 또는 확인 필요. 무조건 재발송 안 함. |
| J02 | 발송 성공 후 DB 결과 저장 실패 | 복구 시 외부 결과 확인. 완료 기록 실패를 미발송으로 단정하지 않음. |
| J03 | 여러 수신자 중 일부 성공 | 성공 항목 보존. 전체 배치 재전송 안 함. |
| J04 | 작업 승인 직후 프로세스 크래시 | 승인/외부 요청 단계에 따라 복구. 고유 요청 키 유지. |
| J05 | 작업 중 앱 업데이트·사용자 종료 | 신규 수신 중단. 작업 완료/불확실 결과 기록 전 강제 전환 없음. |
| J06 | 전원 종료·Windows 강제 업데이트 | 재시작 때 진행 작업 대조 후 재개. 작업 유실·맹목적 재실행 없음. |
| J07 | PC 절전·절전 복귀·긴 오프라인 | 잠금 재취득과 작업 대조. 놓친 예약을 여러 번 몰아 실행하지 않음. |
| J08 | 버튼 연타·네트워크 재시도로 요청 중복 | 같은 업무 요청은 멱등하게 접수/수행. |
| J09 | 정기 동기화와 수동 동기화가 겹침 | 같은 계정의 충돌 작업을 병합/직렬화. 실행 결과에 요청 출처 유지. |
| J10 | 로그인 실패·CAPTCHA·계정 잠금·429 | 유형별 재시도 제한/대기/관리자 안내. 반복 로그인 폭주 없음. |
| J11 | 클래스노트 브라우저 충돌 | 해당 연동 복구. makeedu와 공통 상태 전송은 유지. |
| J12 | 영상 대용량·디스크 부족·업로드 응답 유실 | 용량/중복/재개 정책. 일반 발송과 동기화 기아 상태 없음. |
| J13 | 지원하지 않는 API/모듈 버전 | 작업 승인 전 차단. 정상 처리로 기록하지 않음. |
| J14 | 서버 일시 장애 뒤 다수 PC 동시 복구 | 재시도 분산·요청 상한. 서버에 재접속 폭주하지 않음. |

## 설치와 업데이트

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| U01 | 변경된 설치 파일/체크섬/서명/앱 ID | 실행 전에 거절. 기존 버전 유지. |
| U02 | 공격자가 ZIP과 체크섬을 함께 바꿈 | 별도 신뢰된 서명키 검증으로 거절. |
| U03 | 오래된 정식 릴리스 정보 재전송 | 임의 다운그레이드 차단. 허용된 복구와 구분. |
| U04 | 압축 경로 탈출·절대 경로·링크·대소문자 충돌 | 대상 디렉터리 밖 쓰기 0건. 패키지 거절. |
| U05 | 압축 폭탄·과도한 파일 개수 | 해제 크기/개수 상한에서 중단. 현재 버전 보존. |
| U06 | 다운로드 중 통신 끊김·프록시 오류 | 재개 또는 재다운로드. 부분 파일을 실행하지 않음. |
| U07 | 디스크 부족·백신 파일 잠금·권한 부족 | 적용 연기/실패 표시. 정상 버전 삭제 안 함. |
| U08 | 적용 준비/전환/시작/검증 단계별 전원 종료 | 각 중단 지점에서 정상 버전 또는 검증 대상 하나로 복구. |
| U09 | 새 버전 기동 실패·실행 환경/브라우저 누락 | 실제 작업 시작 전에 검증 실패, 이전 정상 버전 복귀. |
| U10 | 새 버전 검증 중 서버 장애 | 버전 교체 반복 금지. 검증 보류 또는 기존 정상 버전 유지. |
| U11 | 복귀할 버전이 보안상 금지됨 | 금지 버전 실행 안 함. 중지와 해결 안내. |
| U12 | 동일 실패 버전을 계속 조회 | 격리 상태 유지. 자동 적용 무한 반복 없음. |
| U13 | 설정 스키마 변경 후 복귀 | 이전 버전이 읽을 수 있는 설정 복원. 기기 연결/중지 상태 보존. |
| U14 | 업데이트 파일에 `.env`/기기키/로그 포함 | 빌드/패키지 검사 실패. 배포하지 않음. |
| U15 | 작업이 장시간 끝나지 않음 | 업데이트를 연기. 작업을 강제로 종료하지 않음. |
| U16 | 정식/시험 채널 혼합 | 정식 PC는 시험 버전을 자동 설치하지 않음. |
| U17 | 지원하지 않는 Windows/CPU/필수 환경 | 설치 전에 구체적인 안내. 반쯤 설치된 실행 상태 없음. |
| U18 | 제거·재설치 | 업무/등록 해제 의도를 구분. 재설치로 중복 등록/무단 복귀 없음. |

## 로그와 운영 화면

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| L01 | 다른 tenant/device ID로 로그 제출 | 인증된 기기의 지점으로만 귀속하거나 거절. 타 지점 오염 없음. |
| L02 | 코드·토큰·전화번호·학생명·서명 URL 유입 | 허용 목록/검증으로 웹 업로드 없음. 테스트용 비밀 문자열 검출. |
| L03 | SQL/로그 메시지에 HTML·스크립트·제어문자 | 텍스트 표시. XSS/CSV 수식 실행 없음. |
| L04 | 같은 이벤트 배치 재전송 | 이벤트 UUID 기준 한 번만 저장. |
| L05 | 서버 저장 후 응답 유실 | 재전송으로 복구. 중복 저장 없음. |
| L06 | 로컬 전송 대기열 손상·용량 초과 | 정상 레코드 복구, 유실량 표시, 앱 기동 가능. 무제한 디스크 사용 없음. |
| L07 | 이벤트 시간 역행·순서 뒤집힘 | 수신 시각/순번으로 추적. 최근 성공을 옛 실패가 덮지 않음. |
| L08 | 대량/과도한 길이/깊은 JSON 로그 | 파싱 전 크기 제한과 스키마·속도 제한. |
| L09 | PC는 온라인이나 외부 로그인 실패 | 온라인과 업무 오류를 동시에 정확히 표시. |
| L10 | PC 종료 후 웹이 열린 채 유지 | 오래된 상태 표시. 온라인으로 영구 고정하지 않음. |
| L11 | 기기 해제 후 업로드·권한 없는 로그 조회 | 서버 거절. 이미 열린 페이지의 추가 조회도 검증. |
| L12 | 같은 오류 수천 회 반복 | 묶음 표시/알림 제한. 마지막 발생과 횟수·복구 시각 유지. |
| L13 | 다른 지점/해제된 PC의 로그 필터 조작 | 조회 범위 제한. 직접 URL·API 호출도 동일. |
| L14 | 모든 연동 OFF 후 기기 관리 | 공통 해제 기능 접근 가능. 꺼진 연동의 세부 기능은 감춤. |
| L15 | makeedu 담당 PC 카드 이전 | 기존 탭에는 업무 기능 유지. 공통 담당 PC 관리의 중복 표시 없음. |

## 기존 기능 동등성

대상 기능의 원본과 설정/상태 목록은 [기능 대조표](./unified-sync-agent-parity.md)에 있다. 각 항목은 새 앱 경로와 기존 경로에 같은 가짜 DB·외부 응답을 주어 비교한다.

| ID | 공격 또는 실패 상황 | 필요한 결과 |
|---|---|---|
| P01 | 기존 대기/부분 성공/회수/수정 큐를 가진 PC 전환 | 큐 ID·완료 대상·외부 글 ID 보존. 이미 처리한 대상에게 재발송하지 않음. |
| P02 | 발송 OFF에서 공지 수정·회수와 보고서 회수 요청 | 기존 업무별 조건 유지. 수신/읽음/보드 준비까지 일괄 OFF가 되지 않음. |
| P03 | 정기 OFF에서 makeedu 수동 요청·반복 클릭 | 허용된 수동 동기화 작동, 요청 병합·출처 유지. 전체 연동 OFF를 우회하지는 않음. |
| P04 | 자정·발송 시간 경계·PC 시간대 변경·놓친 예약 | 발송 시간과 정기/주간 버킷 중복 없음. 기존 예약을 신규 설치 기본값으로 덮지 않음. |
| P05 | 동명이인·공유 보드·원아 이동·퇴원·담임 변경 | 기존 신원/대상 가드 유지. 잘못된 학생 게시·무단 해제 0건. |
| P06 | 이미지 첨부 일부 실패·개인화 공지·단체 공지 부분 성공 | 첨부 빠진 성공 없음. 이미 성공한 반/학생 중복 게시 없음. |
| P07 | 학부모 글/댓글·첨부만 있는 연락·오래된 글의 새 댓글 | 모든 기존 수집 경로 유지. 초기/복구 알림 폭주·원문 누락 없음. |
| P08 | 답글 본문이 외부에서 바뀜·응답 유실·공감 이미 있음 | 외부 대조와 모드/쓰기 허가 유지. 남의 댓글·공감 변경 없음. |

## 결과 기록 형식

각 ID마다 시험 코드 또는 재현 절차, 빌드 버전, Windows/서버 환경, 주입한 실패 지점, DB/외부 상태 변화, 로그, 판정, 남은 제한을 기록한다. 로컬 가짜 외부 서버 시험과 실제 서비스 점검을 구분한다. 실패 항목과 미실행 항목이 있는 기능은 완료/정상으로 표시하지 않는다.
