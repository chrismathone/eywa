# 시간표 연습실 — Codex 초안 v0

2026-10-02 · 기준 `43e446535` · 상태: Claude/Grok 협의 전 · 구현·운영 변경 없음

## 사용자 요구사항

1. 운영 시간표에 영향을 주지 않는 별도 연습안. 이름을 붙여 저장하고 다음 달 안을 미리 작성한다.
2. 구글 스프레드시트의 자유로운 이동·범위 편집·단축키를 핵심 사용성 기준으로 삼는다. Ctrl+C/V/X, Undo/Redo뿐 아니라 공식 단축키 전체를 대조하고 지원/제약/검증 상태를 빠짐없이 기록한다. 일부만 구현하고 전체 지원이라고 보고하지 않는다.
3. 연습 중에는 충돌 위치에도 배치할 수 있다(사용자 확정). 충돌과 정보 부족을 즉시 표시하고 누가/언제/어느 수업과 겹치는지 설명한다. 연습안 저장과 실제 반영을 구분한다.
4. 영어 우선. 강사시간표에서 강사별 수업 배치를 작성하면 통합시간표에 같은 배치가 나타나고 통합시간표에서 학생을 배정한다. 같은 연습 상태의 두 표현이며 별도 저장본을 동기화하는 방식이 아니다.
5. 이후 수학에 확장한다. 공통 편집기/명령/검사 계약은 재사용하되 과목별 교시·배치·반 규칙을 어댑터로 분리한다.
6. JEV가 실제 도움이 되는 곳에 활용한다. 숫자·시간 충돌의 최종 판정은 결정적 코드여야 하며 JEV는 선택적 의미 분류/후보 추천 보조로만 검토한다.
7. 별도 워크트리에서 Codex 초안 → Claude/Grok 검토와 상호 쟁점 해소 → Codex 통합 계획 → Codex 단계별 실행.
8. 선행 요청인 구글 시트 보존: 앱 관리 3개 탭(영어 2개 + 숨김 수강편집)만 갱신하고 추가 연습 탭은 유지한다. 문서 전체 교체와 탭 삭제/재생성은 탭 ID·참조 파괴 위험 때문에 피한다. 아직 미구현.
9. 스마트 도우미: 충돌마다 놓을 수 있는 대안을 제시한다. 최종 연습 상태와 전 과목 학생/강사/방/분리등원을 검사하고, 이동량/영향 대상이 적은 안을 먼저 제시한다. 현재 조건에서 가능한 안과 조건을 바꿔야 가능한 안을 구분한다. 후보 선택 → 변경 미리보기 → 명시 적용이며 자동 이동하지 않는다. 후보 없음과 탐색 중/제한 시간 초과를 구분한다. 다단계 교환은 제한된 탐색으로 단계화한다.

## 코드에서 확인한 재사용 재료

- `src/app/(shell)/timetable/_components/timetable-board.tsx`: 학생/반 드래그 및 저장 전 큐. 현재 드래그 편집을 운영에서 제거하거나 다시 모드 토글로 되돌리지 않는다.
- `src/features/timetable/lib/class-move.ts`: 반 블록 모양/시간 길이 유지, 전 과목 학생 충돌, 강사/방/같은 반 충돌, 분리등원, LAB/JJ 예외, 강사 비수업 블록.
- `src/features/timetable/import/structure/conflicts.ts`: 합반 경고와 차단 구분. 이 경로는 타 과목을 검사하지 않아 그대로 연습실 통합 검사로 쓸 수 없다.
- `src/features/timetable/server/move-actions.ts`: 서버 재검증, temporal 배치, 출결 가드. 완성된 연습안 전체를 현재의 단건 이동 액션 연속 호출로 반영하면 중간 상태/부분 실패가 생긴다.
- `src/features/timetable/server/master-sheet-store.ts` 및 `src/app/(shell)/timetable/english-sheet/`: 적용일·변경 비교·최신 상태 확인·구조/명단/출결 반영. 일괄 적용의 기존 계약을 먼저 분석한다.
- `docs/decisions/timetable.md`: 기존 운영 드래그의 성능 규칙, 합반/자리/분리등원/이력/예약 규약. 새 연습실도 지켜야 한다.
- `src/features/integrations/google-sheets.ts`: 현재 XLSX로 문서 전체 교체. 추가 탭 보존 선행 작업이 별도로 필요하다.
- `src/lib/ai/jev.ts`, `docs/_audit/jev-feasibility-2026-10-02.md`: JEV는 후보 선택/분류 모델이며 일반 수식 계산기나 시간표 제약 해결기가 아니다.

## 초안 아키텍처

```text
운영 시간표의 기준일 스냅샷 + revision
            ↓ 복사
연습안(지점/과목/적용일, 수업 배치, 학생 배정, 표시 설정)
       ↙ 같은 상태 ↘
강사시간표          통합시간표
수업 배치          배치 출력 + 학생 배정
       ↘ 명령 처리 ↙
명령 이력 / Undo·Redo / 자동 저장 / 충돌 목록
            ↓ 실제 반영
최신 운영 데이터와 재비교 → 서버 검사 → 변경 미리보기
            ↓
원자적 일괄 반영 또는 오류 원인 표시(부분 반영 금지)
```

### 편집기

- UI 엔진은 아직 확정하지 않는다. 기존 dnd-kit 확장, 스프레드시트 엔진(예: Univer), 데이터 그리드 후보를 공식 문서·라이선스·실험으로 비교한다.
- 단축키와 마우스 동작은 같은 도메인 명령을 호출한다. 화면마다 직접 상태를 고치지 않는다.
- 학생/수업/스케줄 식별자를 셀 문자열과 분리한다. 이름 편집이 다른 학생/반 연결로 조용히 바뀌면 안 된다.
- 강사 셀에서 수업을 복사할 때 새 반 생성/기존 반 추가 배치/표시만 복제의 의미를 명시한다. 초기 기본은 기존 반의 새 배치 후보이며 새 반 생성은 별도 명령이다.
- 통합뷰에서 학생 붙여넣기는 새 학생 생성이 아니다. 명확한 기존 학생 ID를 연결하고 동명이인/미확인 이름은 검토 대상으로 남긴다.
- 잘라내기는 붙여넣기 성공 전 원본을 지우지 않는다. 여러 셀/병합/가려진 행/불연속 선택/범위 밖 대상의 의미를 명시한다.
- IME 조합 중 단축키 금지, 셀 입력 모드와 격자 선택 모드 구분, 포커스가 있는 창만 처리, 앱의 iframe/창 단축키와 충돌 회피.
- 구글 시트·Excel과 HTML/TSV 복사 왕복을 지원하되 임의 HTML·수식 실행으로 운영 데이터가 변하지 않도록 파서와 의미 검증을 둔다.

### 초안 저장/적용

- 연습안은 운영 테이블과 분리하며 지점 격리와 권한을 서버에서 검사한다.
- 서버 저장 revision/CAS, 브라우저 새로고침 복구, 다중 창 동시 편집 충돌 처리. CRDT 실시간 공동 편집은 별도 평가하며 필수로 가정하지 않는다.
- 자동 저장 완료/저장 중/실패/서버 변경 충돌을 구분한다. 네트워크 실패로 초안이 조용히 사라지면 안 된다.
- 적용일 기준 시간 이력과 미래 예약을 읽는다. 운영 수정 이후 오래된 안을 적용하면 충돌 위치를 보여주며 다시 비교한다.
- 실제 반영은 하나의 원자적 경계, 멱등 키, 적용 이력, 미래 예약 취소 규칙을 갖는다. 운영 변경 후 Undo는 연습안 Undo와 다르며 자동 역연산하지 않는다.

### 검사 결과 계약

- `code`, `severity`, `entityIds`, `day/time`, `sourceCells`, `relatedCells`, `evidence`, `resolutionHints`.
- 실제 불가능 / 확인 가능한 경고(합반 등) / 판단 정보 부족을 분리한다. 충돌 0과 검사 미완료를 혼동하지 않는다.
- 수업 이동뿐 아니라 학생 배정까지 반영한 최종 연습 상태를 검사한다. 운영 학생 목록만으로 검사하면 연습 중 배정 변경을 놓친다.
- 학생 충돌은 영어 작업에서도 수학을 포함한다. 자리 예외는 강사/방에만 적용하고 학생 중복에는 적용하지 않는다.
- 초안에 기존부터 있던 문제와 새 변경으로 생긴 문제를 구분하되 적용 영향 범위는 서버가 재계산한다.
- 출결·보고서·보강·미래 예약·권한·삭제/퇴원/휴원·필수 정보 누락에 대한 반영 실패도 같은 설명 구조로 표시한다.

## 계획 단계와 통과 조건 초안

0. 요구사항/코드 경계/단축키 전수 대조표/엔진 선정 실험. 합성 자료만 쓰는 브라우저 프로토타입으로 한글 입력·클립보드·양방향 화면 상태·큰 격자 성능 검증.
1. 구글 시트 추가 탭 보존 수정(독립 배포 가능). 추가 탭 값/서식/수식/ID 보존과 관리 탭의 업데이트를 검증.
2. 연습안 도메인·명령·이력·저장·권한·충돌 결과 공통 기반.
3. 영어 강사시간표 편집: 범위 선택, 이동/복사/붙여넣기, 단축키, 충돌 패널.
4. 영어 통합시간표 연결 및 학생 배정, 두 화면 왕복, 미배정/미확인 대상 목록.
5. 최신 데이터 재검증/변경 비교/원자적 적용/미래 예약/실패 복구. 출결 이관은 기존 적용 계약을 활용하되 회귀 검증.
6. 실제 사용 시나리오·부하·접근성·키보드/IME·다중 창 검증 후 영어 제한 공개.
7. 수학 어댑터와 과목 간 회귀 검증. 공통 기능이 있다는 이유만으로 수학 완료로 판정하지 않는다.
