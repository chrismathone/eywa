# 원생 충성도: 가족 동시 재원

적용 대상: eywa / www.aywa.co.kr. 기존 원생 기여도 경로와 메뉴 권한 키는 유지한다.

- 현재 충성도 = 기존 누적 활동점수 + 현재 가족 가점. 본인 포함 2명 100점, 3명 250점, 4명 이상 400점(설정에서 변경).
- 보호자 휴대폰 일치 또는 직접 지정한 형제 관계를 사용한다. 수동 제외가 우선이며 이름만 같거나 연락처가 상충하면 가산하지 않는다. 관계는 다른 형제를 거쳐 임의 확장하지 않는다.
- 본인과 가족 모두 실제 재원·정규 수강 기간을 확인한다. 휴원·전반·종료·보강 풀·테스트·병합 원본은 가산에서 제외한다. 점수는 매달 중복 누적하지 않는다.
- 목록과 상세는 1~5등급 및 상위 %를 제공한다. 검색해도 전체 재원생 비교 집단은 유지한다. 표본 5명 미만·전원 동점·자료 미확인은 등급을 보류한다. 최근 12개월은 가족 가점이 없는 활동점수끼리 비교한다.
- 담당 범위가 제한된 강사에게 가족 수·가족 이름을 노출하지 않는다. 확인 불가는 0으로 확정하지 않는다. 읽기 권한 화면에 저장 버튼을 표시하지 않으며 서버 쓰기 게이트도 유지한다.
- 42팩터 정밀분석은 기존 점수와 별도다. 가족 축이 40%로 가장 크다. F13은 현재 월에만 자동 확인하며 과거 월은 당시 근거가 필요하다. 입력·수정은 월별 근거와 기록자를 새 버전으로 저장하고 동시 수정 충돌은 거절한다.
- 운영의 기존 학생·상담·수납 기록과 월별 기여도 집계는 변경하지 않는다. 정밀분석의 확인 기록 표만 추가한다.

검증: 관련 테스트 74개, 범위 한정 TypeScript 검사, 변경 파일 ESLint 통과. 운영 DB에서 추연우·추민서·추윤서의 동시 재원·정규 수강과 동일 보호자 연결을 읽기로 확인했다. 실제 사용자 화면 확인 여부는 배포 결과에 별도 기록한다.
