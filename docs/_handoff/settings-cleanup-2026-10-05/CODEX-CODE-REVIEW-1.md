## 확인했고 문제 없음

- **P1-D 좁은 수정:** 열린 부서 키의 문자열 배열만 기본값 사본 위에 얹고 빈 배열도 보존한다. 일반판 추가 부서·침산 덮기/추가·잘못된 형식·기본 객체 불변 테스트가 있다(`src/features/owner/resolve.ts:37`, `src/features/owner/resolve.ts:126`, `src/features/owner/resolve.test.ts:124`, `src/features/owner/resolve.test.ts:138`, `src/features/owner/resolve.test.ts:143`).

- **운영 요청 4종·원 요청 검증:** 두 UI 면은 baseline 필수이고 누락/미지 face는 거절한다. 두 면의 full payload는 fresh 읽기 전에 검증하며, 시간표 요청은 외부 키를 strict 검사한다(`src/features/owner/server/operations-save.ts:58`, `src/features/owner/server/operations-save.ts:62`, `src/features/owner/server/operations-save.ts:65`, `src/features/owner/server/actions.ts:130`, `src/features/owner/operations-slice.ts:52`).
