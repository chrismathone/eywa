# 2026-10-23 원생 기여도 과목 보완

원장은 수업명뿐 아니라 해당 수업의 담당 강사와 담당 과목을 최대한 대조하도록 지시했다. 100점 프로젝트·스쿨버스비·스터디케어는 과목 수업이 아닌 기타 항목으로 확정했다. 원본 청구는 수정하지 않고 기여도 계산에서 분류한다.

## 연결 순서와 제한

1. 청구의 명시 과목 또는 연결된 반의 과목을 우선한다.
2. 수업명에 적힌 과목·과정·강사 표시를 기존 분류기로 확인한다. 직원의 표시 이름과 별도 영문명을 함께 읽는다.
3. 과거 수업 기록의 정확한 수업명 또는 마지막 괄호에 기록된 옛 이름을 담당 강사와 연결한다. 공백과 대소문자 차이는 정규화한다.
4. 현재 직원 정보에 없는 강사는 서로 다른 명시 과목 수업 두 개 이상이 같은 과목일 때 보완한다. 추론으로 정한 수업을 다시 학습 근거로 쓰지 않는다.
5. 같은 강사 이름의 다른 과목 근거, 합반, 합쳐진 강사 문자열, 이동 화살표는 한 과목으로 확정하지 않는다. 다른 학생의 담임을 이름만으로 옮겨 붙이지 않는다.
6. Drive 원본을 직접 대조한 예외는 지점·메이크에듀 번호·청구월·순번·수업명·금액이 모두 일치하는 기존 청구에만 적용하며, 수업명 기반 추정보다 우선한다. 다른 기간이나 같은 이름의 다른 학생으로 확대하지 않는다. 과목과 출처를 `model/reviewed-subjects.ts`뿐 아니라 계산 결과의 `historical[].subjectResolutions`와 `payload.subjectResolutions`에도 남긴다. 과거 달이 이미 마감됐으면 그 달을 수정하지 않고 현재 열린 달에 새로 확인한 출처를 보존한다.

과거 강사 조회는 집계 시 청크·페이지로 수행하며 동시에 실행하는 조회 체인은 4개로 제한한다. 강사의 괄호 영문명 유무를 함께 조회한 뒤 정규화한 이름이 정확히 같은 행만 근거로 삼는다. 목록과 탭 이동에는 추가하지 않는다. 이미 마감한 실적은 보존하고, 보완된 누적 실적과의 차이는 기존 정정 절차로 반영한다. 배점 변경은 없다.

100점 프로젝트·스쿨버스비·스터디케어를 기타로 분류하면 해당 금액도 수업료 기여에서 제외된다. 수업 과목·재원 개월만 바뀌는 것이 아니므로, 재집계 시 기존 점수가 내려갈 수 있다. 원본 수납 금액은 변경하지 않는다.
