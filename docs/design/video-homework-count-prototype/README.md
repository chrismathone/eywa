# 영상 과제 제출 관리 · HTML 시안

[index.html](./index.html)을 브라우저에서 열면 EYWA 관리자 화면의 영상 과제 제출 관리 시안을 볼 수 있습니다. 독립 HTML이며 앱 라우트나 데이터베이스에는 연결되어 있지 않습니다.

## 원본 시트와의 대응

참조: [영상과제 제출 점검](https://docs.google.com/spreadsheets/d/10k4JTwTEGTkkPQV57ddS5iHm00nC5UZe3V3AKxFJL7k/edit)

- 학생·반·담당교사별 기록을 따로 세고, 동일한 학생 이름도 기록 ID가 다르면 합치지 않습니다.
- 1~10회차 `✅`와 `⏰`는 제출수와 수업시수에 모두 포함합니다. `❌`는 수업시수에만 포함하고, 빈칸은 집계하지 않습니다.
- 제출률은 제출수 ÷ 수업시수입니다. 수업시수가 0이면 비율을 표시하지 않습니다.
- 전체·반별·담당교사별 제출률은 제출수 합계 ÷ 수업시수 합계입니다.
- 관리상태의 원본 계산식이 없어 `3회 미만 관찰중 / 3회 이상 80% 이상 정상 / 그 밖은 관리필요`를 잠정 기준으로 둡니다. 시안의 **집계 기준** 탭에서 바꿔볼 수 있습니다.
- 원본에서 `⏰`의 정확한 명칭은 확인되지 않아 화면에는 **시간 표시 제출**로 표기했습니다.

## 시안에서 확인할 수 있는 동작

회차 상태 클릭, 학생 상세 패널에서 상태·메모 입력, 학생·교사·반·관리상태 필터와 정렬, 반·교사별 집계, 잠정 관리 기준 조정이 동작합니다. 여러 학생을 선택해 같은 회차 상태를 일괄 입력할 수 있고, 학생 기록 추가·최근 입력 되돌리기·예시 초기화도 가능합니다.

**CSV 가져오기**는 `학생명`, `담당교사`, `반`, `1회`~`10회` 열이 있는 파일을 받습니다. 머리글 위에 제목·안내 행이 있어도 찾아서 읽습니다. `학교·학년` 또는 `학교`·`학년`, `기록ID`, `비고`는 선택 항목입니다. 회차 값은 `✅`, `⏰`, `❌`, 빈칸을 인식합니다. 기록 ID가 같은 행은 갱신하고, 새 ID는 추가합니다. **CSV 내려받기**는 현재 시안 데이터를 같은 형식으로 저장합니다.

입력은 브라우저 메모리에만 남으며 새로고침하면 초기화됩니다. 되돌리기는 학생 기록 변경에 적용되며 집계 기준 입력에는 적용되지 않습니다.

## 강사 화면 시안

**강사 화면 시안** 탭에서 카드뷰와 표뷰를 전환할 수 있습니다.

- 카드뷰: 기존 보고서의 사진/파일 첨부 아래 빈 공간에 **영상 과제 사전 검사**를 배치했습니다. 1~10회차를 선택하고 상태·메모를 기록합니다. 예시의 결석 학생도 보고서 입력과 별개로 사전 검사할 수 있습니다.
- 표뷰: 기존 **과제 수행률** 칸 바로 아래에 해당 회차의 빠른 상태 입력을 배치했습니다. 같은 반 학생을 연속해서 확인할 수 있습니다.
- 카드뷰·표뷰·관리자 제출 현황은 같은 시안 데이터를 공유합니다. 어느 화면에서 상태를 바꿔도 제출수·수업시수·관리상태가 즉시 갱신됩니다.

학생명·학교·교사명·기록 ID는 개인정보를 배제한 가상 예시입니다. 참조 시트의 `제출현황`과 `원본데이터`에 서로 다른 값이 있는 행이 있어, 실제 도입 시 원본과 현재 입력값을 대조한 뒤 연결해야 합니다.
