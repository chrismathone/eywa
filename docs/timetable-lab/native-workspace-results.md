# 영어 시간표 — 큰 편집 화면과 기존 시간표 불러오기

> 후속 수정: 하루별 블록 화면을 기존 강사뷰/통합뷰 구성과 저장 색상으로 교체했다. 현재 상태는 [뷰·색상 보완 기록](./view-parity-results.md)을 참고한다. 아래 내용은 최초 연결 단계의 기록이다.

2026-10-02. 사용자 후속 요청: 기존 시간표를 불러오고, 화면 공간을 최대한 쓰며, 수업을 자유롭게 옮겨 판단하는 편집기. 엑셀 UI 자체가 목적은 아니다. 별도 워크트리 `chrismathone/timetable-lab`에서 진행했다.

## 구현

- 기본 주소 `http://127.0.0.1:4317/`: 기존 시간표 불러오기 또는 예제로 시작.
- 강사별 열·요일 탭·시간축·수업 블록. 너비 제한을 없애고 남은 화면 높이를 편집에 사용. 상세/검사 패널은 접어서 사용한다.
- 수업을 다른 강사·시간으로 드래그하거나 요일 탭에 놓아 이동한다. Ctrl/Command로 복수 선택, Ctrl/Command+C/X/V·Z/Shift+Z, Delete, 방향키 커서, Enter 상세, Escape 취소를 연결했다. 더블클릭도 즉시 상세를 연다.
- 통합시간표 보기는 같은 배치를 학생 이름과 함께 출력한다. 선택한 교시의 학생을 다른 수업 교시로 옮기며 다른 요일·타 과목 배정은 보존한다.
- 충돌을 허용하면서 학생·강사·강의실이 겹치는 두 수업과 시간을 설명한다. 미확정 방·담당자는 별도 표시한다. 추천은 현재 같은 요일 16~22시/10분 간격의 제한된 결정적 탐색이다. 수업 길이·강사·방을 유지하고 최종 상태에서 새 겹침이 없는 후보만 제시한다. JEV/LLM 호출은 없다.
- 수업 이동·복사·지우기·학생 이동·추천·자료 불러오기를 같은 이력으로 Undo/Redo한다. 복사본은 새 배치 ID, 이동은 원본 배치 ID를 유지한다.

## 실제 시간표 연결

- 루트 Next 개발 서버 4320 + Vite 4317의 읽기 API 프록시. Vite에는 비밀 환경변수를 넣지 않는다.
- `/api/timetable/lab/source`: 기존 로그인 검증과 지점 전체 시간표/반 관리 권한을 모두 통과해야 한다. tenant는 세션에서만 결정하며 클라이언트의 tenant 매개변수는 쓰지 않는다. RLS를 유지하고 `private, no-store`, `Vary: Cookie`를 반환한다.
- 기준일이 포함된 월~일의 배치와 비수업 블록을 가져온다. 수강은 **각 수업 날짜**의 시작/종료·반이동 배타 종료·분리등원을 검사한다. 휴원 수강과 실제 퇴원 이후는 제외한다. 월요일 하나로 주중 학생을 판정하지 않는다.
- 기존 슬롯 조회를 공유하는 작은 export를 추가했다. 별도 명단 조회는 ID·이름·수강 기간/요일만 읽고, 수업보고서·학교·학년은 읽지 않는다. 타 과목 학생 명단은 영어에 존재하는 학생만 전송한다. 페이징·ID 청크·실패 시 throw를 사용한다.
- 강사는 표시 담당을 유일하게 연결할 때만 ID를 붙인다. 동명이인/미해결 담당은 미확정으로 알리고 추천을 확정하지 않는다. LAB/JJ는 사람으로 바꾸지 않는다.
- 불러오기 미리보기 후 시작을 누를 때만 현재 연습안을 교체한다. 실패하면 유지하며, 성공한 교체도 Undo 가능하다. 이름/요일/시간/ID가 불명확한 자료는 부분 가져오기 대신 중단한다. 방 미정 수업과 주말 수업은 지우지 않고 그대로 표시한다.

## 검증 결과

- 실험 단위 시험: 기존 13 + 새 7 = 20건.
- 서버 라우트/투영 시험: 13건. 무로그인 401, 두 권한 403, 세션 tenant 강제, 잘못된 날짜, 실패 503, 주중 수강 시작·전출 경계·분리등원·휴원·비수업 유효일·담당 연결을 확인한다.
- 브라우저: 기존 비교 정상 16건 + 새 수업 블록 화면 8건. 원본 Univer의 Ctrl+Home 실패 재현 1건은 `test.fail`이며 정상 동작 건수에 합산하지 않는다.
- 1440×1000 브라우저에서 접힌 패널 기준 편집 영역 너비 1400px 초과/높이 840px 초과를 확인한다. 수업 드래그·요일 이동·실제 clipboard 단축키·교시 학생 이동·추천·Undo·로그인 실패·불러오기·Escape·오래된 잘라내기·다른 자료의 복사 버퍼 차단을 브라우저에서 검증한다.
- 타입 검사, 변경 파일 ESLint, 실험 production build를 실행한다. Univer 비교용 대형 chunk 경고는 남으며, 기본 화면은 비교 엔진을 동적으로 분리한다.
- agent-browser에서 기본 시간표 화면을 직접 확인했다. 실제 Next 읽기 API의 무로그인 401과 로그인 페이지 200/입력 필드를 확인했다. 로그인 화면의 첫 컴파일에 35.6초가 걸려 최초 자동화 호출이 timeout한 뒤 정상 로드를 재확인했다.
- **실제 계정으로 운영 시간표를 읽은 검증은 아직 하지 않았다.** 가져오기 성공 시나리오는 합성 응답이며, 서버 명단 투영은 단위 시험이다. 운영 자료 조회 완료라고 보고하지 않는다.

## 커밋 전 검토와 수리

- 기존 수업의 방이 비어 있으면 화면에서 사라지던 경로를 수정했다. 미확정 상태로 남겨 검사와 추천을 구분한다.
- 담당 라벨이 교시별로 다를 때 반 담임 ID를 잘못 붙이는 경로를 제거했다. 학생·블록 유효일을 월요일에 고정하던 오류도 수업 날짜 기준으로 수정했다.
- 수업 포인터를 편집 영역에 캡처하면 더블클릭 대상이 바뀌는 실패를 실제 브라우저에서 재현하고, 블록에 캡처하도록 고쳤다.
- 연결된 겹침에서 카드 폭이 서로 다르거나 겹치던 배치를 겹침 그룹별 열 배정으로 수정했다.
- Escape 뒤 놓기, 잘라낸 뒤 다른 수정, 다른 스냅샷을 불러온 뒤 복사 붙여넣기, 끄는 도중 revision 변경을 취소하도록 했다. 명시 이동은 오래된 수식/rich text를 지운다.
- 학생 이동은 반 전체 명단에서 학생을 제거하던 비교 실험 명령을 재사용하지 않는다. 두 교시만 바꾸는 별도 명령을 둔다.
- 모달은 native dialog로 배경 초점을 차단한다. 드래그 중 반복 검사/레이아웃 계산을 메모하고, preview는 ref를 render에서 읽지 않는다.
- 기존 비교 시험을 삭제하지 않고 `/?compare=1`로 이동했다. 원본 엔진 실패와 새 기능 통과를 분리해 기록한다.
- 최종 적대 검토에서 가져오기/복사가 계산된 시간·담당 표시까지 배치 객체에 중복 저장하는 것을 발견했다. 배치에는 ID/행/참조만 보존하고 표시 의미는 셀에서 한 번만 투영하도록 수정해 오래된 두 번째 값을 제거했다. 이 경로를 단위 시험으로 고정했다.
- 최신 `origin/main`의 영상 링크 작업을 충돌 없이 병합했다. 타 작업 파일을 고치거나 관련 migration을 실행하지 않았다. 수동으로 해결한 병합 hunk는 없다.

## 남은 범위

- 이 연습안은 브라우저 메모리 상태다. 저장/복원, 여러 안 비교, 지점/사용자별 초안 권한·CAS는 P1에서 구현해야 한다. 새로고침·탭 닫기 시 유실 안내와 이탈 가드를 넣었다.
- 전체 132개 단축키 기능의 요구는 유지된다. 위의 키 검증으로 전체 호환 완료를 주장하지 않는다. 외부 Sheets/Excel 범위 붙여넣기·서식·한글 실제 IME·iframe 문맥도 남아 있다.
- 현재 통합 보기는 강사축에 학생을 출력하는 첫 투영이다. 운영 통합표의 전체 묶음 구성, 학생 범위 드래그, 반 전체 배정·분리등원 재매핑은 후속이다.
- 강의실 변경 UI, 수업 길이 조절, 수업 새로 만들기, 사용자 잠금, 기간별 검사, 출결 앵커, 합반 예외, LAB 고정 규칙, 타 과목의 비수업 블록, 저장/운영 반영은 미완료다. 경고가 없다는 사실은 운영 가능 판정이 아니다.
- 실사용 규모 성능·다른 브라우저·터치 자동 스크롤은 아직 검증하지 않았다.
- 구글 추가 탭 보존 S와 수학 편집 어댑터는 이번 변경에 포함되지 않는다. DB migration, 운영 테이블/시트 쓰기, main 배포를 하지 않았다.

루트 의존성 설치는 패키지를 설치했으나 `ERR_PNPM_IGNORED_BUILDS`로 끝났으며 설치 성공으로 기록하지 않는다. 실제 타입/빌드/실행 검증과 구분한다. 전용 워크트리의 `.env.local`은 gitignore이며 내용·인증정보·운영 학생 자료를 증거 파일에 남기지 않았다.
