# aywa vs 시중 학원관리 프로그램 — 전 측면 비교 분석

**작성일** 2026-06-18 · **방법** 시중 제품 20여 종 웹 조사(공식 사이트·제3자 비교글·앱스토어 교차검증) + aywa 코드/CLAUDE.md 기반 분석
**대상 비교군** ACA2000, 이코딩, 학원조아, 메이크에듀, 통통통, 클래스업, 클래스데이, 어나더클래스, 온하이, 공선학관, 랠리즈, 튜터시스템, 결제선생, 모두출첵 등

---

## 한눈에 결론

aywa는 **"원장·강사용 내부 운영 콘솔"**로서는 시중 어떤 제품보다 **모던하고(UX), 진짜 AI를 갖췄고, 멀티윈도우 워크스페이스라는 유일 차별점**을 가졌다. 기술 스택·멀티테넌트 보안 설계도 시장 평균을 크게 앞선다.

그러나 한국 학원관리 시장을 정의하는 **두 기둥 — ① 학부모 알림(등하원 알림톡/앱), ② 실전 결제 인프라(비대면 결제·키오스크·카드단말기·현금영수증·자동 정기청구) — 을 aywa는 (의도적으로) 비워뒀다.** 시중 제품은 바로 이 두 가지로 먹고산다. 또한 aywa는 아직 **데모 단계(단일 테넌트·합성 데이터·실고객 0)**라, 25,000곳(랠리즈 주장)·3,000곳(클래스업)을 운영하는 제품들과 "성숙도·검증"에서 격차가 크다.

**즉, aywa는 "관리 콘솔 + AI + UX"에서 이기고, "학부모 접점 + 결제 + 시장 검증"에서 진다.** 제품으로 성립하려면 후자 중 최소 한 기둥(알림 또는 결제)을 반드시 채워야 한다.

## 1. 시장 지형 (3계층)

| 계층 | 대표 제품 | 특징 | 가격 모델 |
|---|---|---|---|
| **레거시 올인원 (프리미엄)** | **ACA2000**(시장 1위), 이코딩 | 기능 최다·안정성 검증, 대형/입시 표준. **UI 노후·과중·PC 의존·견적가 비공개** | 가입비 20~50만원 + 원생수별 월 4~9만원 (견적) |
| **모던 클라우드 (신흥)** | **클래스업**(3,000+), **어나더클래스**(무료 300명), **클래스데이**(문제은행) | Next.js/Gatsby SPA, 모바일·앱 우선, 투명 가격, 페인포인트 카피 | 무료 ~ 월 29,000/89,000원 + 메시지 별도 |
| **무료/소형·니치** | 온하이(예체능), 공선학관, 랠리즈(웅진), 통통통, 망고에듀(5,500원), 결제선생(수납전문) | 진입장벽 0, 소규모 공부방·예체능·수납전문 | 무료 + 메시지/결제 마진 |

**시장 규모**: 2024 사교육비 **29.2조원**(역대 최고, 학생 수는 감소). 구매층은 부유하고 늘어나는 추세 — 단 소프트웨어 지출은 그 일부.

**수익 모델 2가지** (aywa와 직접 충돌):
- **A. "소프트웨어 무료 + 메시지·결제 마진"** (지배적). 알림톡 ~7~10원 / SMS ~12~18원 / LMS ~30~45원 건당(선불 충전) + 카드 결제 수수료(0.4~2.4%). → 결제선생·어나더클래스·온하이·클래스데이가 대표.
- **B. "원생수별 구독 + 가입비"** (레거시). 그래도 메시지는 별도 과금. → ACA2000·이코딩·메이크에듀(유료티어)·클래스업.

> **aywa 시사점**: aywa의 깨끗한 "테넌트 구독" 모델은 이 시장에서 드물다. 차별점이지만, 경쟁사 수익의 핵심인 **메시지·결제 마진을 포기**한다는 뜻 → 가격 설계에 반영 필요. 그리고 무료 경쟁선(300명 무료 등)이 거세다.

## 2. 측면별 비교

### ① 기능 범위 (운영 관리)

aywa의 12메뉴(시간표·출석부·수업·학생·등록상담·학생상담·퇴원/리텐션·직원·수납·회의록 + 강사/학생 원스크린)는 **학사·운영 관리 폭에서 중상위 올인원과 대등**하다. 특히 **회의록·리텐션(이탈위험 스코어링)·등록상담 AI**는 시중 제품엔 거의 없는 메뉴다.

| | aywa | 레거시 올인원 | 모던 클라우드 | 무료/소형 |
|---|---|---|---|---|
| 출결 기록·매트릭스 | ✅ (30일 매트릭스) | ✅ | ✅ | ✅ |
| 시간표 (드래그·인쇄) | ✅ | ✅ | △ | △ |
| 수업/학생/상담 CRM | ✅ | ✅ | ✅ | △~✅ |
| 성적 관리 | ✅(단 데모는 합성) | ✅ | △(클래스데이 ✅) | △ |
| 직원·급여 정산 | ✅ | ✅(대형) | △ | △(공선학관 ✅) |
| 회의록 | ✅ **(고유)** | ✗ | ✗ | ✗ |
| 이탈/리텐션 분석 | ✅ **(고유)** | ✗ | ✗ | ✗ |

판정: **운영 콘솔 기능 폭은 경쟁력 있음(무승부~우세).** 단 성적은 현재 데모가 합성 데이터라 실증 필요.

### ② 학부모 소통·알림 — **aywa의 결정적 공백**

시장 **전 제품의 핵심 기능**이 "등·하원 시 학부모에게 카카오 알림톡/앱 푸시/SMS 자동 발송"이다. 이것이 원장이 프로그램을 사는 **1순위 이유**다. aywa는 CLAUDE.md에서 **알림센터·학부모포털을 의도적으로 제외**했다 → 학부모 접점이 **없다**(출석부가 내부 기록용).

| | 학부모 알림 | 채널 |
|---|---|---|
| 시중 전 제품 | ✅ 자동 등하원 알림 | 알림톡 + 앱 푸시 + SMS |
| **aywa** | ❌ 없음 (의도적 제외) | — |

판정: **시장 기준 치명적 공백.** 데모/포트폴리오로는 무관하나, 실제 학원에 팔리려면 **반드시 채워야 할 1순위.**

### ③ 수납·결제 인프라 — **aywa의 두 번째 공백**

incumbent들의 "수납"은 단순 기록이 아니라 **실제 결제 처리**다: 비대면 모바일 결제(SMS/카톡 링크), 카드단말기 연동, 키오스크 무인결제, 현금영수증 원클릭, 다중사업자, **출결 회차 카운팅 → 자동 정기청구**(어나더클래스·온하이), 미납 일괄 독려. 메이크에듀·어나더클래스·학원조아가 특히 두껍다.

aywa의 수납관리는 **인보이스 발행·납부 상태·미수금·교재주문·지출 기록**까지는 있으나, **실 결제(PG/카드단말기/비대면 링크/현금영수증/키오스크)는 없다.**

판정: **기능 깊이에서 명확한 열세.** 결제는 한국 학원 SaaS의 최대 격전지 — 여기 없으면 "관리만 되고 돈은 못 받는" 도구로 인식된다.

### ④ 출결 방식 / 하드웨어

시중은 **키오스크·태블릿·출결키패드(번호 4자리)·BYOD(남는 폰)** 로 학생이 셀프 체크 → 자동 알림. aywa는 강사가 입력하는 매트릭스(내부용). 하드웨어 생태계(키오스크·자동문·카드결제 일체형) 없음.

판정: **열세** (단 BYOD 무료 출결은 모던 제품도 지향 → aywa가 웹 셀프체크 + 알림만 붙이면 따라잡기 쉬움).

### ⑤ 성적·콘텐츠·문제은행

**클래스데이**(기출 200만 문항, 시험지 제작, 오답 자동분석)·**튜터시스템**(OMR 스캔 자동채점)이 이 영역을 소유. aywa는 성적 표시는 있으나 **콘텐츠/문제은행/자동채점 없음**(애초 스코프 아님).

판정: **입시·수학 특화 제품엔 열세.** 단 aywa 타깃(보습 운영)에선 필수 아님.

### ⑥ AI — **aywa의 최대 우위**

조사 결론: **시장의 "AI"는 약 95%가 마케팅 라벨.** 온하이의 "AI 기반 차세대"는 보도자료에만 있고 공식 사이트엔 AI 언급조차 없다(실체=예약 발송+차트). 클래스업 "AI 학습 보고서"는 템플릿 추정. 랠리즈는 공지 자동답변 초안 수준. **진짜 LLM 분석에 가장 근접한 건 클래스데이(학습데이터 상담·생성형 문자) 하나뿐.**

aywa는 **실제 `generateJSON()` 기반**으로 ① 회의록 요약(AssemblyAI 전사 + LLM), ② 학생 케어 인사이트, ③ 등록상담 13섹션 분석을 한다. 게다가 **모델명 비노출 + 명시 트리거 + 결과 동결(print_payload)** 같은 성숙한 운영 원칙까지 갖췄다.

판정: **명확한 우위, 사실상 무주공산.** 단 시장에서 "AI"가 너무 닳은 단어라 **"주장"이 아니라 "실제 분석 출력물"로 증명**해야 함.

### ⑦ 디자인 / UX

시중은 두 세대로 갈린다. **모던(클래스업·클래스데이·어나더클래스)** = Next.js SPA·모바일 퍼스트·투명 가격. **구형(메이크에듀가 최악 — 3개 분리 도메인·원격지원·3년 약정·공포 마케팅, 학원조아·통통통 = PHP/ASP 서버렌더).** aywa의 Daylight 디자인·반응형·인터랙션은 **구형 세대 대비 압도, 모던 3종과는 정면 동급 경쟁.**

판정: **상위권.** aywa의 UX 완성도(스크롤바 하네스·드래그팬·모핑 애니메이션)는 모던 3종보다도 디테일이 깊다.

### ⑧ 멀티윈도우 워크스페이스 — **aywa 유일 차별점**

cascade/스냅/타일링되는 플로팅 창 워크스페이스는 **시중 어느 제품에도 없다.** 원장이 여러 메뉴를 동시에 띄워 일하는 "데스크톱 OS" 같은 경험은 aywa만의 것.

판정: **유일성 100%.** 단 "있으면 좋은" 차별점이지 "사는 이유"는 아님 — 결제/알림 위에 얹혀야 의미.

### ⑨ 성능

aywa의 명시적 1순위가 "반응속도"다. 구형 incumbent(PC 설치·무거운 ERP)는 느리고 무겁다는 게 시장 페인포인트(ACA2000 "과중"). 모던 3종은 빠르다. aywa는 **목표는 최상이나 현재 부채 존재**(코드 리뷰 결과: 대시보드 11쿼리 전건 fetch, 요청간 캐싱 0, cold start). **잠재력은 시장 최고, 현 상태는 모던 3종과 비등하거나 약간 뒤.**

판정: **잠재 우위 / 현재 동급.** 1순위 가치인 만큼 부채 해소가 곧 차별점.

### ⑩ 기술·아키텍처·보안

aywa: **Next.js 16 + Supabase + 전 테이블 RLS 멀티테넌트 + Drizzle + strict TS + 테스트.** 시중 제품 다수는 PHP/JSP/ASP 서버렌더(레거시 웹), 메이크에듀는 설치형 잔재. **멀티테넌트 RLS 격리를 코드로 강제하는 수준의 제품은 이 시장에서 보기 드물다.** (단 aywa도 코드 리뷰에서 권한 상승 취약점 1건 발견 — 수정 필요.)

판정: **아키텍처 우위.** 확장성·유지보수성에서 레거시 대비 세대 차이.

### ⑪ 플랫폼

| | 웹 콘솔 | 네이티브 앱(학부모/학생) | 키오스크 |
|---|---|---|---|
| 시중 모던/올인원 | ✅ | ✅ (별도 앱) | ✅ |
| **aywa** | ✅ (강점) | ❌ (웹 /my-learning·/onescreen만) | ❌ |

판정: **콘솔은 강하나 학부모/학생 네이티브 앱·키오스크 부재** → 소비자 접점 약함.

### ⑫ 가격·비즈니스 모델

aywa = 베타 구독(테넌트 단위). 시장 = "무료 + 메시지/결제 마진" 또는 "원생수 구독". aywa는 **메시지·결제 마진이 없어** 구독가에 그 비용을 녹여야 하고, **무료 경쟁(300명 무료 등)** 과 직접 부딪힌다.

판정: **모델 단순·투명은 장점, 무료 압박·마진 구조는 불리.**

### ⑬ 시장 검증·성숙도·지원

랠리즈 25,000곳·클래스업 3,000곳·ACA2000 20년 vs **aywa 데모(단일 테넌트·합성 데이터·실고객 0·1인/AI 개발).** 고객지원(24h 원격·채널톡)·레퍼런스·안정성 트랙레코드에서 격차가 크다.

판정: **현 단계 최대 약점.** 제품 성숙도가 아니라 "검증·신뢰·지원 체계"의 부재.

## 3. 종합 포지셔닝

```
                 기능 깊이 (결제·알림·콘텐츠) 높음
                              ▲
        ACA2000 · 이코딩      │   어나더클래스 · 클래스업
        (깊지만 노후·과중)     │   (깊고 + 모던)  ← aywa의 실질 경쟁자
                              │
  UI 구형 ──────────────────-┼──────────────────── UI 모던
                              │
        학원조아 · 메이크에듀  │   ★ aywa ★
        통통통                │   (모던·AI·멀티윈도우, 단 결제·알림 공백)
                              │   온하이·클래스데이(니치)
                              ▼
                 기능 깊이 낮음
```

aywa는 **"UI 모던 + 운영/AI 깊이"** 사분면 상단으로 올라갈 잠재력이 있으나, **결제·알림 공백 때문에 현재는 우하단(모던하지만 소비자 접점 얕음)**에 위치. 위로 올리는 열쇠 = 결제 또는 알림.

## 4. aywa 장점 요약

1. **진짜 AI** (회의록·케어·등록상담 LLM 분석) — 시장 거의 무주공산, 최대 차별점.
2. **모던 UX·디자인** — 구형 incumbent 압도, 모던 3종과 동급 이상(디테일은 우위).
3. **멀티윈도우 워크스페이스** — 시중 유일.
4. **운영 콘솔 기능 폭** — 시간표·출결·상담·직원·리텐션까지 중상위 올인원급. 회의록·이탈분석은 고유.
5. **기술·멀티테넌트 보안 아키텍처** — Next.js 16 + 전 테이블 RLS, 레거시 대비 세대 우위.
6. **성능 잠재력** — "반응속도 1순위" 설계 철학(부채만 해소하면).

## 5. aywa 약점·공백 요약

1. **학부모 알림(등하원 알림톡/앱) 없음** — 시장 1순위 구매 이유. 치명적.
2. **실 결제 인프라 없음** — 비대면 결제·카드단말기·키오스크·현금영수증·자동 정기청구. 최대 격전지에서 부재.
3. **학부모/학생 네이티브 앱·키오스크 하드웨어 없음** — 소비자 접점·출결 자동화 약함.
4. **문제은행·OMR 자동채점 없음** — 입시·수학 특화 제품 대비 열세(스코프 밖이긴 함).
5. **시장 검증·고객·지원 체계 0** — 데모 단계, 신뢰·레퍼런스 격차.
6. **현재 성능 부채** — 1순위 가치인데 대시보드 전건 fetch·캐싱 부재 등 미해소.
7. **수익 모델 불리** — 메시지·결제 마진 없음 + 무료 경쟁 압박.

## 6. 전략 제언 (우선순위)

1. **알림 또는 결제 중 하나를 반드시 채운다.** 가장 빠른 건 **카카오 알림톡 연동(등하원·청구 알림)** — 비용 작고 시장 1순위 기능. 그 다음 **비대면 결제 링크**(결제선생류 PG 연동)로 "관리+수금"을 완성.
2. **AI를 "주장"이 아니라 "증거"로 판다.** 실제 회의록 요약·상담 분석 출력물을 데모 전면에 — "AI" 라벨이 닳은 시장에서 실물이 곧 해자.
3. **타깃을 좁혀 우위 사분면 선점.** "보습/입시 중형 학원 + 원장이 직접 보는 모던 운영 콘솔 + 진짜 AI"로 포지셔닝. 예체능(온하이)·문제은행(클래스데이)·대형 ERP(ACA2000)와 정면충돌 회피.
4. **성능 부채부터 해소.** "반응속도 1순위"가 카피인데 현재 부채가 있으면 차별점이 무너짐(대시보드 RPC화·캐싱).
5. **무료 진입선 + 투명 가격**으로 모던 3종(무료~89,000원)과 경쟁선 맞춤.
6. **멀티윈도우·디자인은 "고급감" 보조 무기**로 — 핵심 구매 이유(알림·결제) 위에 얹어 프리미엄 인상을 강화.

> 정리: aywa는 **"원장이 매일 보고 싶은, AI 달린 모던 운영 콘솔"**로서는 시장 최고 수준의 잠재력을 갖췄다. 다만 한국 학원 시장이 실제로 돈을 내는 이유(**학부모 알림 + 결제**)를 비워둔 상태라, 이 둘 중 하나만 채워도 "데모"에서 "팔리는 제품"으로 도약한다.
