# MCS 전체 목표 기반 진도 관리 시안

## 목적

전체 목표 블록와 완료일을 먼저 정하고 실제 수업 일정에 배분해 월간·주간·일간 목표를 자동으로 산출한다. 강사는 오늘의 계획 위치와 실제 수업보고서 위치를 비교해 학생별 지연과 필요한 수업 속도를 확인한다.

## 비교할 다섯 구성

1. **반별 진도 레일**: 참고 이미지에 가까운 넓은 학생 행. 전체 구간의 실제 위치와 오늘 계획을 두 줄로 비교한다.
2. **목표 분해표**: 전체 → 이번 달 → 이번 주 → 오늘의 목표를 열로 정렬한다. 자동 배분 결과를 검토하기 좋다.
3. **월간 수업 지도**: 수업일별 계획 블록와 실제 블록를 나란히 놓는다. 지연이 발생한 날을 찾기 좋다.
4. **학생 집중 보기**: 학생 목록과 한 학생의 전체 계획·목표 분해·수업 기록을 좌우로 배치한다.
5. **진도 점검 보드**: 계획 대비 상태별로 학생을 묶고, 각 학생의 목표·실제 차이와 남은 속도를 표시한다.

## 디자인 방향

- 색: 흰색 #ffffff, 바탕 #f5f7fa, 본문 #243247, 보조 #637086. 현재 진도와 상태는 모두 파랑 #3274bd, 목표는 옅은 파랑 #739ada.
- 글자: Pretendard를 사용한다. 학생 이름 17px, 주요 진도 값 22px, 본문 14px, 보조 12px. 숫자는 고정 폭으로 정렬한다.
- 여백: 학생별 비교가 중심이므로 큰 요약 카드와 장식 그래픽을 두지 않는다. 넓은 진도 구간과 짧은 행 구분선을 주된 구조로 삼는다.
- 참조 이미지에서 학생 행·넓은 레일·정렬된 정보의 장점을 가져온다. 빠름·느림에 따른 색상 구분 없이 블록 차이를 글자로 표시한다.
- 안마다 색만 바꾸지 않고, 반 전체 비교 / 목표 분해 / 수업 이력 / 개인 지도 / 지도 우선순위라는 작업 기준을 다르게 둔다.

## 데모 계산 규칙

- 샘플 기준일: 2026-09-17. 모든 학생 이름과 수업 기록은 가상 데이터다.
- 수업 요일과 지정한 휴강일로 수업일 배열을 만든다.
- n번째 수업의 누적 목표 = floor(전체 블록 수 × n / 총 수업 수). 마지막 수업에서 전체 목표에 정확히 도달한다.
- 월·주·일 목표는 같은 수업일 배열에서 산출한다. 별도 수기로 관리하지 않는다.
- 상태는 항상 샘플 기준일까지의 계획과 실제 기록을 비교한다. 미래 월말 목표로 현재 학생을 지연 판정하지 않는다.
- 수업일 도중의 기준 시각 문제는 이번 디자인의 범위 밖이다. 데모는 9/17 수업이 끝난 상태를 가정한다.
- 학생의 결석이나 지연으로 기존 목표를 자동으로 뒤로 밀지 않는다. 전체 목표를 변경했을 때만 계획을 다시 계산한다.
- 블록마다 분량이 같은 균등 배분의 시안이다. 실제 적용 시 블록별 가중치·복습일·시험일 배분을 논의할 수 있다.
- 예상 진도와 실제 진도의 단위를 블록로 통일한다. 진도율은 학업 성취도나 정답률을 의미하지 않는다.

## 제공 파일

- `index.html`: 다섯 안을 전환하는 자체 포함 HTML. 목표 설정, 검색, 상태 필터, 학생 상세가 동작한다.
- `screenshots/`: 데스크톱 및 모바일 화면 확인용 이미지.

이 HTML은 가상 학생을 사용하는 디자인 프로토타입이다. 선택한 1번 구성은 MCS 코드에 적용했고, 학생 클릭은 4번 학생 집중 보기로 연결했다. 구현·검증 결과는 `IMPLEMENTATION.md`를 참고한다.
