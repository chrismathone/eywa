# 학부모 알림 통합 · 최대화 조작 행 — 2026-10-02

- 원장 요청: 알림 본문 클릭으로 기존 답글 오버레이를 직접 열고 외부 이동 확인창 폐지. ClassNote 이동은 실제 담임만. 설정·시간표 최대화는 제목을 숨기고 첫 조작 행에 복원 버튼 배치(선택 답변 확인).
- 알림 소유권은 세션 클라이언트 + tenant_id/recipient_id로 확인한다. 원문 번호·댓글 모호함은 서버에서 기존 매칭 규칙으로 판정한다. 목록 버튼용 조회가 늦어도 진입할 수 있으며 실패는 같은 창 안에서 안내한다.
- 이동 자격은 현재 활성 반의 teacher_id만 사용한다. 개인 보드는 확정 연결 및 같은 과목의 현재 수강을 확인하고, 반 보드는 연결된 해당 반만 본다. 임시 위임·부담임·다른 과목·관리자 직급은 우회 근거가 아니다. 조회 실패 및 다른 강사 뷰는 주소를 제공하지 않는다. 신규 SQL 없음. 원장이 0327a 적용 완료를 확인했다.

## 적대적 검토

- 목록에서 답글 대상 조회가 끝나기 전 클릭하면 외부 이동으로 빠지는 경로 제거: notificationId로 즉시 오버레이를 열고 서버에서 확인.
- 모호한 댓글 알림을 답글 후 다시 읽을 때 공감이 살아나는 문제 방어: hideReaction을 성공 응답에도 유지.
- 숨겨진 제목 행의 버튼이 DOM에는 남아 초점이 사라질 수 있어, 보이는 토글로 초점 이동. 실제 브라우저로 확인.
- 관리자 자동 통과·다른 지점·다른 과목·미래/종료 수강·반이동 당일 옛 반·비활성 반·원아 연결 불일치·조회 실패를 반례로 테스트.
- 기존 날짜/필터·저장 메타는 원복 시 유지. 다른 메뉴의 제목 동작/KPI는 숨기지 않고 기존 배치를 유지한다.
