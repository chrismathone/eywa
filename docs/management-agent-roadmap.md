# 경영 에이전트 개발 우선순위

2026년 10월 20일 기준 개발 순서다. 기존 에이와 기능을 재사용하고, 경영·학습상의 이상을 근거와 함께 확인한 뒤 담당자의 조치와 결과를 에이와에 남긴다. 슬랙·노션은 알림 용도로 사용한다. 운영 배포와 운영 DB 변경은 별도 승인 후 진행한다.

## 현재 구현과 다음 개발

[PR 31](https://github.com/chrismathone/eywa/pull/31)의 과거 캘린더 확인과 학생 상담 후속조치 에이전트는 검토용 첫 구현이다. 기본 모드는 끔이며, 실제 운영 배포·DB 적용·외부 발송과 구분한다. [첫 구현 범위](management-agent-mvp.md)와 [기존 검증 기록](management-agent-verification.md)을 유지한다.

1순위의 첫 구현으로 학생 상세에 **관리 요약** 탭을 추가했다. 재원·수납·숙제·출결·레벨·성적·학부모 상담을 읽어 보여주고 기존 지원 상담으로 연결한다. 새 카드의 비교 규칙과 자료 부족 표시를 가상 데이터로 검증했으며, 운영에는 적용하지 않았다. 구현과 남은 범위는 [학생 관리 요약 첫 구현](student-care-mvp.md)에 정리한다.

다음 개발은 학생 관리 신호를 담당자 업무와 재평가에 연결하는 단계다. 기존 유지관리 보드의 일괄 위험 계산을 새 규칙으로 이관하는 작업도 포함한다. 직접 만족도 수집과 재무 자료 정리는 병행한다.

## 우선순위

| 순서 | 개발 항목 | 주요 결과 | 필요한 재료와 선행 조건 |
| --- | --- | --- | --- |
| 1 | 학생별 재원 유지 관리 카드와 지원 업무 MVP | 재원기간·누적 순수납·숙제·출결·레벨·입학 후 성장·학부모 의견, 관리 등급과 근거, 담당·기한·처리·재확인 | 기존 학생·수강·수납·학습·상담 자료 재사용. 과목 혼합 비교와 문구 오탐을 먼저 보완. 카드의 확인된 근거를 기존 상담 후속조치에 연결하고, 자동 업무 생성에는 사건 출처 확장 필요 |
| 2 | 월별 영업이익 변동 원인 분석 | 학생 수·실제 단가·반 구성·인건비·광고비·공통 비용의 변화가 이익에 미친 금액 | 최근 24개월을 목표로 회계·실제 급여와 수업 기간별 매출 연결. 부족한 기간은 확인 범위 표시 |
| 3 | 반별 수익성과 강사 업무량 | 충원율, 수업 가동률, 직접이익, 손익분기 인원, 수업·보강·상담·준비 시간 | 시간표·실제 수업·총인건비·교육상 적정 정원. 기존 강사 급여 비율 지표 재사용 |
| 4 | 유입경로별 LTV와 CAC | 최초 유료등록 집단별 학생이익, 유지기간, 유치비 회수기간 | 순매출·직접 원가·광고비·유치 상담시간. 학생 중복과 문의→등록 시차 정리 |
| 5 | 학생 성장과 만족도 분석 고도화 | 과목별 비교 가능한 성장 추이, 직접 만족도 시계열, 30·60·90일 유지와 조치 효과 | 1순위에서 데이터와 재평가 기록 수집을 시작하고, 관찰기간이 성숙한 뒤 분석. 정기 설문과 평가 척도 정리 |
| 6 | 예정 상담 사전 브리핑과 반복 문의 업무 전환 | 예정자 과거 캘린더·입학 상담 이력 요약, 확인된 반복 문의의 담당 업무 | 기존 읽기 전용 조회 재사용. 동일인 확인 결과와 실제 상담 완료·등록 근거 필요 |

1순위는 모든 요청 영역을 카드에 넣되, 값이 없는 항목은 확인 필요로 남긴다. 5순위는 기본 항목을 뒤로 미루는 것이 아니라 평가 척도·시계열·효과 검증을 고도화하는 단계다. 월별 재무 자료 확보와 만족도·조치 결과 수집은 1순위 진행 중에도 시작할 수 있다.

## 공통 집계 기준

- **신규생 KPI**: 사용자가 정한 ‘기간 내 최초 입학 학생 수’를 유지한다. **상담전환율**은 ‘기간 내 첫 상담 학생 중 조회 종료일까지 입학한 학생 비율’을 유지한다. CAC의 최초 유료등록은 별도 정의로 표시한다.
- **학생과 수강**: 한 학생이 두 과목을 들어도 학원 학생 수·누적 재원기간·신규 획득은 중복 집계하지 않는다. 반별 수강 인원과 일부 과목 종료는 별도다.
- **금액**: 청구액, 실제 수납, 환불, 순수납, 수업 기간에 맞춘 매출을 구분한다. 누적 납부액을 LTV 또는 이익으로 부르지 않는다.
- **비용**: 강사 평가의 할인 전 청구액·세전 급여 기준을 보존하고, 경영 분석에서는 실제 총인건비와 순매출을 별도로 연결한다. 원가 배분 후 총액이 회계 자료와 일치해야 한다.
- **지원 우선순위**: 학생 관리 등급에는 납부액·LTV를 넣지 않는다. 납부액 접근 권한은 학습 자료 접근 권한과 구분한다.
- **자료 품질**: 기록 없음·조회 실패·실제 0을 구분한다. 모든 지표에 기간·출처·갱신일·관측 건수·추정 여부를 제공한다.
- **판단과 결과**: 규칙 기반 등급을 통계적 확률로 표현하지 않는다. 연락 완료와 문제 해결, 실제 재원 유지 여부를 별도 확인한다.

## 운영 확대 조건

각 기능은 가상 자료 검증 → 검토 환경의 권한·집계 대조 → 승인된 운영 관찰 → 제한 활성 순서로 진행한다. 실제 도입 일정은 데이터 접근과 기존 기능의 운영 검증 결과에 따라 정한다. 학생별 세부 사양과 경계 사례는 [학생별 재원 유지 관리 개발안](student-care-development-plan.md)에 둔다.
