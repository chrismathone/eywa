## 2. 카카오 지도 설정 (배포 전 체크)

- developers.kakao.com → 앱 → **[플랫폼 > Web] 사이트 도메인**에 실제 접속 주소를 등록해야 지도가 뜬다.
  등록 안 된 주소에선 SDK가 `AccessDeniedError: domain mismatched!`를 돌려주고, 화면은 "지도를 불러오지 못했어요"로 접힌다(실측).
  로컬은 `http://localhost:3000`(포트까지 정확히)로 등록돼 있다 — 그래서 로컬 dev 서버도 **3000번**으로 띄운다.
- 앱 설정에서 **카카오맵 사용**을 켜 둘 것.
- 운영 배포 주소(`https://www.aywa.co.kr` 등)는 운영에 반영할 때 추가.

## 3. 실시간 차량 — 지금 있는 것과 쓸 수 있는 것

| 기능 | 상태 | GPS에 쓸모 |
|---|---|---|
| 운행 상태(출발·종료, `shuttle_trips`) | ✅ | **그대로** — [출발]~[종료]가 위치 전송 시작·중지, "운행 중일 때만 차 표시"의 기준 |
| 셔틀 기록 권한(`recordGate`) | ✅ | **그대로** — 위치를 보낼 수 있는 사람 확인 |
| 학부모 범위(`getParentViewer` + 오늘 구간) | ✅ | **그대로** — "우리 아이가 탄 차"만 |
| 학부모 '실시간 차량' 지도 | ✅ 지도·학원·정류장 | 차 마커만 더하면 됨 |
| 정류장 좌표(위경도·주소·도착 반경 50m, 0244a) + 카카오 지도 입력 화면 | 🟡 칸·화면 있음, 좌표 입력 0곳(로컬) | 정류장 표시, 나중에 "곧 도착" 판정 |
| 학부모 15초 자동 갱신(알림) | ✅ | 같은 방식으로 차 위치 갱신 |
| 운행 현황 `/shuttle/live` · 실시간 위치 `/shuttle/track` | ✅ / 🟡 자리만 | track의 `VehicleMapSlot`을 실제 지도로 교체 |
| 화면 간 실시간 신호(방송 채널) | ✅ 직원 화면 3곳 | **위치 자체는 싣지 않는다**(공개 채널 전제) — "갱신됨" 신호만 |

새로 만들 것: ① 위치 저장 표(회차별 **최신 위치 1줄**) ② 셔틀 화면의 위치 보내기 ③ 지도에 차 마커.
정리 거리: 카카오 SDK 로더가 정류장 picker와 학부모 지도에 **두 벌** 있다 — 차 마커를 붙일 때 하나로 합친다.

## 4. GPS — 정한 방향

1. **1단계 = 웹 GPS.** 셔틀 '오늘 등하원' 화면이 [출발]~[종료] 동안 약 10초마다 위치를 보낸다(오차 큰 값은 버림, 운행 중 화면 꺼짐 방지).
   - 앱 없이 된다(크롬·사파리·삼성 인터넷). 조건: **https**(로컬 `localhost`만 예외) · 처음 한 번 위치 허용 · **운행 중 셔틀 화면이 켜져 있을 것**
     (화면 꺼짐·다른 앱 전환 시 멈춤 — "홈 화면에 추가"도 같다). 거치대 + 충전 권장.
2. **받는 쪽은 출처와 무관하게.** 저장 표·지도·권한은 그대로 두고, 나중에 **보내는 쪽만** 바꾼다:
   - 2단계 = 앱(리액트 네이티브/Expo 등) — 백그라운드 가능. 필요: 위치 **"항상 허용"**, 안드로이드 포그라운드 서비스(상단 고정 알림),
     스토어의 백그라운드 위치 심사, 삼성 등 **배터리 최적화 예외** 안내. 기사·동승 몇 명만 쓰면 APK/플레이 내부 테스트 · TestFlight로 배포 가능.
     셔틀 화면을 다시 만들지 말고 **위치 전송만 하는 작은 앱**(또는 웹 화면을 앱에 담기)으로.
   - 3단계(필요 시) = 차량용 LTE GPS 단말기.
3. ⚠️ **위치정보법** — 차량·사람 위치를 모아 학부모에게 보여 주는 형태라 운영 전에 확인할 것(보내는 선생님 **동의**는 필수, 서비스 형태에 따라 위치기반서비스사업 신고).
   지난 위치는 쌓지 않고 최신 1줄만(경로 기록이 필요하면 보관 기간을 정해 따로).

## 5. 로컬에서 진짜 폰 GPS로 시험하는 법

폰 브라우저는 **https 또는 그 기기의 localhost**에서만 GPS를 준다 — `http://192.168.x.x:3000`은 막힌다.

| 방법 | 진짜 GPS | 메모 |
|---|---|---|
| PC 브라우저 + 개발자도구 Sensors | ❌(가짜 좌표) | 개발 중 "차가 움직이는 것처럼" 시험 |
| 안드로이드 USB + `chrome://inspect` 포트 연결 | ✅ | 폰에서 `localhost:3000`으로 열림. **3000·54321 둘 다** 연결해야 로그인·실시간 정상 |
| PC에 자체 인증서 HTTPS | △ | 폰마다 인증서 신뢰 설치 · 로컬 Supabase(http) 섞인 연결 차단 · 같은 와이파이만 — 비추천 |

- 🔴 **Vercel 테스트 배포(Preview)로 시험할 땐 테스트 전용 Supabase에 연결** — Preview가 운영 DB 환경변수를 물려받으면 시험 기록이 운영에 들어가고 실제 학부모에게 알림이 갈 수 있다.
- 순서: 개발 중엔 **로컬**(즉시 반영 · 로컬 DB) → 완성 후 **Vercel 테스트 배포 + 테스트 DB**(며칠 실운행) → 운영 반영(DB 먼저, 앱 다음).

## 6. 남은 것 · 주의

1. 로컬 정류장 좌표가 0곳이라 학부모 지도엔 아직 학원 마커만 뜬다 — '노선 편성 → 정류장 관리'에서 찍으면 바로 나온다(같은 키로 동작).
2. 로컬 테스트 폴더의 창 띄우기 스크립트·`.env.local`(키 값)은 테스트 폴더에만 있다(저장소에 안 올림).
3. 전체 `tsc`는 로컬 PC 메모리 한계로 미실행 — 바뀐 파일 부분 타입 검사 0 · eslint 0 · 셔틀 테스트 통과. 본서버 CI의 typecheck를 볼 것.
