# 강의실 현황 2D/3D

## 운영 적용

- 2026-09-11 사용자 요청으로 개발 전용 제한을 해제했다. 대시보드 상단 `강의실 2D/3D`에서 `/dashboard?view=rooms`로 접근한다.
- 대시보드·시간표·반 관리 권한 및 강사 범위는 유지한다. 출결은 별도 열람 권한을 반영한다. 기본 대시보드 현황과 2D/3D 선택은 그대로 유지한다.
- 아래 개발 시안·미커밋 표시는 당시의 검수 이력이다. 마지막 사용자의 적용·푸시 요청으로 운영 반영을 진행한다.

## 현재 방향: 가상 건물과 중앙 복도

- 사용자 추가 지시: 층 순서 2·3·6·8. 정사각형에 가까운 가상 층 안에 중앙 복도, 복도 양쪽 교실. 실제 도면은 필요 없다.
- 3D 전체 보기는 내부가 가려진 외관이다. 층이나 건물 옆 화살표를 선택하면 420ms 전환 후 그 층의 3D 내부만 크게 표시한다. `건물 전체 보기`로 복귀한다. 여러 층 내부를 동시에 쌓는 이전 시안은 제거했다. 2D에서도 같은 복도·교실 배치를 사용한다.
- 층 라벨은 2층·3층·6층·8층만 표시하고 실 수를 제거했다. 회전 시에도 외관 오른쪽 밖에 투영한다.
- 기본 교실은 4열, 305·603 및 JJ는 면적 2배에 6열 배치다. 현재 수업의 중복 제거한 수강 학생 수만큼 책상을 표시하고, 출석한 학생의 자리만 채운다. 당일 최대 동시 수강 인원으로 격자를 고정하므로 교시가 바뀌어도 남은 책상 위치가 변하지 않는다. 기존 4×4·6×4 격자가 기본이며 인원이 많으면 행을 추가한다.
- 각 교실은 외벽에 붙여 배치하고, 내부 보기에서 카메라 쪽의 건물벽·교실벽을 숨긴다. 반대쪽 벽은 남긴다.
- 본원 2층·3층·6층과 고수 8층이라는 실제 분류는 그대로 표시한다. 가상 건물의 층 순서이며 실제 두 건물의 구조를 합친 도면이라는 주장은 하지 않는다.
- 교실 내부를 덮는 반·강사 정보 상자는 제거한다. 작고 짧은 호수 표시는 복도 쪽으로 옮기고 상세 정보는 선택 교실 패널에서 읽는다.
- 학생은 등록 인원으로 채우지 않는다. 출결 권한이 있는 경우 현재 수업의 유효한 출석·지각·보강 기록만 작은 인물로 표현한다. 교시를 특정할 수 없는 날 단위 기록은 여러 교실로 복제하지 않는다.

### 수업 인원별 책상 및 출결 좌석 연동

- 오늘 시간표에서 이미 조회한 수강 명단 ID를 개발 화면에만 선택적으로 전달한다. 기존 활성 수강 기간·분리 등원 요일 규칙을 재사용하고 추가 DB 조회는 하지 않는다.
- 교실의 현재 수업들을 학생 ID로 합쳐 책상을 만든다. 중복 시간표 셀·합반의 중복 학생은 한 자리다. 확인된 명단 외 보강 출석은 추가 자리로 표시하며 일반 과거 출석 기록만으로 수강 명단을 늘리지 않는다.
- 학생은 출석 순서가 아니라 수강 명단 순서의 자리에 앉는다. 출석 취소 시 해당 자리만 비워 다른 학생이 이동하지 않는다. ‘학생 표시’를 꺼도 책상 개수와 정보의 출석 수는 유지한다.
- 시간 미리보기에서는 해당 시간의 수강 인원만 표시한다. 수업이 없는 교실은 책상 0개, 학생 0명이다. 명단을 확인할 수 없는 경우 임의로 수강 인원을 추정하지 않는다.
- 브라우저 장면을 재생성하지 않고 책상·학생 인스턴스만 갱신한다. 출결·수강 변경 알림과 30초 갱신, 15초 시계로 반영한다.
- 자리별 출결 정정, 10개 책상/7명 출석, 동시 수업 중복 제거, 시간 경계, 보강, 출결 권한/미리보기, 다수 인원 및 명단 누락을 포함해 7개 파일 53개 테스트 통과. TypeScript 전체 검사 및 대상 ESLint 통과.
- 실제 로그인 브라우저에서 서버 명단의 교실별 현재 고유 학생 수와 21개 교실의 표시 책상 수가 일치했다(검수 시점 합계 85개). 본원 3층은 실제 가구 인스턴스 19개·학생 12명, 305호는 책상 11개·출석 10명 확인. 학생 표시를 끄면 3층 책상 19개 유지·인물 0명이며 305호 정보의 출석 수 10명은 유지된다.

### 빈 교실 칠판

- 현재 수업이 없는 경우만 칠판에 `수업 없음` 손글씨를 표시한다. 다음 수업 대기 중에도 현재 수업이 없으면 표시하고, 시간 정보 미확인·수업 진행 중에는 표시하지 않는다. 학생 수 0을 수업 없음으로 오인하지 않는다.

- 브라우저에서 수업 중인 204호의 기존 칠판과 수업 없는 SKY의 손글씨 칠판을 함께 확인했다. `logs/design-audit/classroom-idle-board.jpg`. 마지막 TypeScript·ESLint 검사 통과.

## 두 번째 시안: 같은 배치의 평면·입체 전환

사용자 검토: 교실 이미지가 반복되는 카드 목록은 효용이 낮다. 실제 도면 없이도 여러 교실의 관계와 현재 사용 상태가 한 화면에 보여야 한다.

- 색: 종전 남색 #173E76·흰색 #FFFFFF 유지, 배치판 #EDF3F8, 진행 #438A9D, 다음 수업 #C89B54, 비어 있음 #C8D3DE.
- 글꼴: 기존 Pretendard. 교실명 12–15px/700, 상세 정보 12px. 3D에서도 글자는 화면을 향해 읽을 수 있게 유지.
- 배치: 전체에서는 층별 판 2×2, 각 판 안 교실을 두 줄로 배치. 한 층을 고르면 그 판을 크게 표시한다. 교실 개념 배치이며 실제 위치 관계는 주장하지 않는다.
- 2D는 같은 좌표의 SVG 평면, 3D는 Blender GLB 모델을 놓은 WebGL 장면. 교실 상태를 바닥색으로 표시. 회전·확대·선택 교실 확대·전체 보기 제공.
- 성능: 3D를 선택할 때만 Three.js와 GLB를 읽고, 상시 애니메이션 루프 없이 조작/데이터 변경에만 렌더. 2D 전환 시 GPU 자원 해제. WebGL 불가 시 평면 보기로 복귀.
- 재검토: 그림을 얹은 카드는 제거한다. 장면 전체에 한 번만 도구를 두고, 상태·반별 수강 인원·바로가기는 기존 실제 데이터를 재사용한다. 교실별 인원을 합산해 실제 출석 인원으로 표현하지 않는다.

- 범위: `/dashboard?view=rooms`, 개발 환경 전용. 주 대시보드·운영 메뉴 변경 없음.
- 색: 남색 #173E76, 파랑 #3284AD, 바탕 #EDF3F8, 흰색 #FFFFFF, 예정 #926321, 진행 #257356.
- 글꼴: 기존 Pretendard. 제목 24/700, 교실 16/700, 정보 13/400, 시각·숫자는 tabular-nums.
- 배치: 왼쪽 정렬. 상단 제목·현재 시각·2D/3D 토글, 건물/층 필터, 교실 영역과 선택 교실 시간표.

```text
강의실 현황     현재 시각 / 시간 미리보기       [2D | 3D]
진행 중 / 수업 없음 / 다음 수업                 새로고침
[전체 / 본원 2층 / 본원 3층 / …]
┌ 교실 현황 ─────────────────┬ 선택한 교실 ───────┐
│ 교실 / 교실 / 교실          │ 현재 수업 / 반 열기 │
│ 교실 / 교실 / 교실          │ 오늘 시간표         │
└───────────────────────────┴───────────────────┘
```

검토: 실제 도면·정확한 가구 수는 필요하지 않다는 사용자 지시에 따라 방 위치를 흉내 내는 지도를 제외했다. 방마다 반복되는 입체 모형을 사용하고 정보는 평면 글자로 유지한다. 2D는 조밀한 목록으로 전환한다. 기본 이미지는 Blender에서 미리 렌더링하므로 WebGL·상시 렌더 루프가 없다. 모든 방 선택은 같은 상세 영역을 사용해 카드 높이를 늘리지 않는다. 모바일은 선택 교실을 팝업으로 연다.

데이터: 오늘 시간표의 교시별 교실·담당·활성 수강 대상. FK 우선, 시트 라벨은 유일하게 일치할 때만 등록 교실에 연결한다. 수강 인원은 실출석 인원이 아니다. 시간 미리보기는 오늘 일정에 한정하며 현재 운영 상태와 구분한다. 수업 없음은 시간표상 의미로만 표기한다.
