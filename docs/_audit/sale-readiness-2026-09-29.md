## 4. 이번 작업에서 얻은 교훈

- **손으로 돌릴 SQL은 `$fn$` 이름 달러 인용**으로 — 채팅에서 복사하면 `$$`가 깨져 `syntax error at or near "declare"`가 났다.
- **긴 SQL은 채팅이 아니라 파일로** 준다(`C:/tmp/aywa-sql/`) — 두 번째도 `syntax error at end of input`으로 잘렸다.
- **전제 SQL 미적용을 스스로 잡는 사전 점검 블록**을 넣을 것 — 0305a가 0170a 미적용을 잡아, 개인 예외자(설현·이승엽 등)의 저장이 에러 없이 0행이 되는 사고를 막았다.
- 운영 DB 확인은 **읽기 전용 트랜잭션**(`set session characteristics as transaction read only`)으로.
