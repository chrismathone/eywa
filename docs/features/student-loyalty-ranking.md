# 학생 로열티 기록실 (2026-11-09)

운영 경로: `/student-contribution/ranking`. 원생 충성도 메뉴에서 진입한다. 기존 누적 점수와 42개 팩터는 기록 확인용으로 유지하며, 새 랭킹은 별도의 100점 모델이다.

## 기본 배점

|항목|배점|기록 산식|
|---|---:|---|
|수강기간|20|유효 청구개월 + 추가 과목개월 × 25% + 2과목 이상인 개월 × 25%|
|총 납부액|20|월별 환불 차감 수업료 × (1 + 추가 과목 수 × 25% + 동시수강 25%)의 합|
|가족 재원|40|본인 누적 과목개월 × 현재 재원 형제자매 수(본인 제외)|
|설명회 참석|10|연결 범위 내 참석 확인 행사 수, 행사별 중복 제거|
|출결 근태|5|예정 정규 교시 대비 정상 1 / 지각·조퇴 0.5 / 결석 0|
|학교 성적|5|최근 학교 성적 50% + 향상도 50%. 동일 연도·과목·시험종류 최근 두 시험 비교, +20%p 이상 향상 지수 만점|

기간·납부·가족·설명회는 비교 집단의 항목 최고 기록을 만점으로 환산한다. 출결·학교 성적은 100점 척도다. 배점 합계는 100이며 설정에서 가산율과 성적 방식(향상/현재/혼합)도 수정할 수 있다. 교재비 등은 순수업료에 포함되지 않는다. 과목·기간은 유효 청구 기준이므로 실제 출석 수업시간이나 일 단위 재원기간이 아니다. 가족 수는 현재 확인된 가족을 사용하는 평가 정책이며 과거 가족 동시 재원기간을 재현하지 않는다.

## 데이터 및 안전한 계산

- 기존 `assembleContribution`에서 현재 원본을 재계산하여 열린 월의 `payload.loyaltyRanking`에 작은 요약만 추가한다. 마감 월과 수납·학생 원본을 덮어쓰지 않는다. 기존 예약 집계와 수동 집계가 함께 갱신한다. 별도 스키마 변경은 없다.
- 순납부액과 과목개월은 기존 병합·환불·2026년 소스 경계 판정을 재사용한다. 과목 미확인 청구가 있으면 해당 가산 축은 보류한다.
- 출결은 기존 수업 달력·유효 기록을 사용한다. 보강 좌석과 당일·미래 수업은 제외한다. 날짜만 있는 기록을 여러 교시에 재사용하지 않는다. 미입력 예정 교시가 있으면 출결 점수를 보류한다. 과거 휴원 기간 원장이 없어 재구성된 정규 일정과 차이가 날 수 있다.
- 학교 성적은 학교 시험으로 판별된 원본만 사용한다. 학원 월말 테스트, 미응시, 범위 밖 점수, 동일 날짜의 상충 점수는 제외한다. 향상도는 같은 연도·과목·시험종류가 2회 있어야 한다. 서로 다른 시험의 난이도까지 통계 보정한 값은 아니다.
- 설명회 신청만 확인된 기록은 실제 참석으로 간주하지 않는다. 미확정 명단이 있으면 보류한다.
- 미측정은 null이다. 미측정 배점을 다른 항목으로 재분배하지 않는다. 확인 점수 합에 따른 잠정 순위와 가능한 상한을 함께 표시한다. 서로 다른 자료 완성도를 가진 학생의 최종 우열을 확정하지 않는다.
- 동점 공동 순위, 백분위는 동점 그룹의 끝 위치, 20% 단위의 1~5등급. 5명 미만 또는 전원 동점은 등급 보류. 필터는 계산 후 적용하여 검색에 따라 기준이 흔들리지 않는다.
- 조회 시 기존 메뉴·수납 권한과 학생 담당 범위를 재검사한다. 담당 범위 사용자의 가족 정보는 숨기고 전체가 아닌 자신의 범위로만 비교한다. 출결·시험 권한이 없으면 해당 원시 요약도 제거한다. 계정·연락처·토큰은 클라이언트에 제공하지 않는다.

## 검증

월별 가산, 환불, 과목 미확인, 동점·소표본, 미측정 상한, 가족 권한, 시험 비교 조건, 예정 교시 미입력, 설명회 신청/참석 분리, 테넌트·학생 범위와 원시값 접근을 자동 검증한다. 기존 월 집계 회귀 테스트로 마감 기록 보존을 확인한다.
