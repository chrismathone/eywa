# 숙제 영상 재생

2026-10-14: 학생 영상·학부모 글/댓글·영상 제출 장부·손 배정 창은 같은 `HomeworkVideoPlayer`를 쓴다. 보관 완료를 재생 성공으로 단정하지 않는다.

- 기본 재생은 `/api/homework-videos/[id]/stream` 원본 영상과 브라우저 `<video>`다. 외부 Drive 미리보기의 변환·제3자 쿠키·Google 로그인 상태에 기대지 않는다. 원본 코덱이 브라우저에서 지원되지 않거나 연결에 실패하면 **다시 불러오기 / 호환 재생**을 제공한다. 호환 재생은 앱 안 Drive iframe이고 외부 Drive 이동 링크를 추가하지 않는다.
- 매 요청마다 로그인·직원·학생 메뉴·해당 학생 상세 열람 권한을 확인한다. 강사는 학생 목록에 전체 접근할 수 있어도 그 영상이 연결된 반이 자신의 학생 열람 반(담임·교시·위임)에 포함되어야 한다. 같은 학생을 한 과목에서 맡았다고 다른 과목 영상까지 새로 열어 주지 않는다. 손 배정한 반은 장부 뷰에서 읽고, 집계 제외 영상은 원래 반으로 권한을 확인한다. DB 조회는 지점과 영상 id로 제한한다. 워커가 학생을 아직 정하지 못한 영상은 `messageId`로 기존 답글 쓰레드 권한을 다시 판정하고, 그 쓰레드가 **이 영상 id**를 실제 재생 가능 목록에 포함했을 때만 허용한다. 이름·반·브라우저가 보낸 파일 주소로 추정하지 않는다.
- 파일에 각인된 `route.rootId`·`route.connectionId`를 `readPinnedVideoDriveCredential`로 확인한다. 현재 설정이나 다른 계정 자격으로 대신 읽지 않는다. 연결을 확인하지 못하면 기본 재생이 실패하고 호환 재생을 선택할 수 있다. 접근 토큰은 서버 밖으로 보내지 않는다.
- 파일 전체를 버퍼링하지 않는다. 단일 HTTP Range를 최대 2MiB로 제한하고 Drive의 206 응답 본문을 스트리밍한다. 시작/끝/전체 크기·Content-Length·영상 MIME을 확인한다. 탐색은 다음 Range 요청으로 이어지고 416은 전체 크기를 전달한다. 오류 HTML·전체 파일 200 응답은 전달하지 않는다.
- 재생 응답은 `private, no-store`, `nosniff`다. 파일·숙제 상태·매핑·알림·Drive 공유 권한은 바꾸지 않는다. 닫거나 다른 영상을 고르면 재생기를 제거해 소리도 멈춘다.
- 원본 손상·삭제·미지원 코덱은 로딩 오류로 안내한다. 썸네일 실패만으로 영상 접근권한을 판정하지 않는다. 옛 호출부(영상 id 없는 재생기)의 Drive 프리뷰는 호환용이며, 운영의 네 화면은 모두 영상 id를 넘긴다.

확인한 제보 파일: 원본 MP4(H.264/AAC), Drive 파일 조회/부분 다운로드 206 성공. 기존 화면 오류는 Drive iframe 내부라 에이와가 감지·재시도할 수 없었다. 기본 경로는 해당 iframe 의존성을 제거한다.
