# 연동 PC 워커 수정 적용 (2026-09-30) — 수학 반별 발송 '보낼 반' · 특강 반 보드 · 종강 반

> **한 줄 요약**: zip을 풀고 **워커를 다시 시작**하면 끝입니다. `.env.local`은 **건드릴 것이 없습니다.** SQL도 없습니다.

## 무엇이 달라지나

| 바뀐 것 | 내용 |
|---|---|
| 특강 반 보드 | **다음 새벽 동기화(5시 이후)부터 특강 반도 ClassNote 반 보드가 만들어지고** 원아가 자동 배정됩니다(정규 반과 같은 가드). 특강 보고서는 그 반 보드로 갑니다. |
| 특강 제목 | 학부모 보고서 제목이 `[특강] 수업 보고서`로 나갑니다(앱 쪽 — 캡처 이미지에 그대로 실립니다). |
| 종강 반 | ClassNote에 반 보드가 **살아 있는 동안** 계속 그 반으로 보냅니다. 보드를 지우면 다음 동기화에서 연결이 걷히고, 그 뒤 보고서는 '보낼 반'을 고르게 됩니다. |
| 보낼 반 | 보고서 반에 반 보드가 없으면 앱이 정한 '보낼 반'으로 보냅니다. 둘 다 없으면 지금처럼 1인 보드로(전환 전 대기분 등 1회성). |

- 앱 쪽(배포로 바로 적용): 관리자 직접 작성의 '보낼 반' 고르기 · 보낼 반이 없으면 발송 불가 · 일괄 발송의 '보낼 반 미지정' 제외.
- ClassNote 기능을 끈 학원은 아무것도 바뀌지 않습니다(제목의 `[특강]`만 모든 학원).

## 적용 방법 (연동 PC 경로 = `C:\eywa-sync-pc`)

1. zip을 풀어 **`C:\eywa-sync-pc\scripts\_classnote` 폴더 전체**를 덮어씁니다(일부 파일만 덮지 마세요).
2. **PowerShell을 "관리자 권한으로 실행"** 한 뒤 아래를 붙여넣습니다.

```powershell
cd C:\eywa-sync-pc
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'watch-classnote-queue' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
Start-ScheduledTask -TaskName eywa-classnote-worker
```

3. 끝입니다.

### 🔴 압축만 풀면 적용되지 않습니다

이미 돌고 있는 워커는 옛 코드를 메모리에 들고 계속 돕니다. 위 2번을 **반드시** 하세요.

### 특강 반 보드를 바로 만들고 싶으면

새벽 동기화를 기다리지 않으려면(선택):

```powershell
cd C:\eywa-sync-pc
node --env-file=.env.local scripts\_classnote\provision-math-class-boards.mjs            # 확인만(드라이런)
node --env-file=.env.local scripts\_classnote\provision-math-class-boards.mjs --apply --sync-db   # 실제 생성·배정
```

확인만 먼저 돌려 결과를 보여 주시면 같이 판단합니다.
