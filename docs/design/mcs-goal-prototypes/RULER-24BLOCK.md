# MCS 정밀 눈금과 24블록 계획 — 2026-09-17

> 2026-09-18 변경: 블록 수와 눈금 기준은 [학기당 12블록](./RULER-12BLOCK.md)으로 대체되었다. 아래는 이전 설계 기록이다.

사용자 확정 기준: 정규 월 8블록, 한 학기 3개월·24블록. 수요일은 월 4블록의 기존 학습·현행 심화 복습이며 정규와 별도 집계한다.

- `LearningRails`는 실제 블록 좌표에 맞춘 SVG 눈금, 8블록마다 긴 눈금, 짙은 현재 표시와 빈 원의 목표 표시를 쓴다. 두 위치에는 현재·기준일 목표 단원명을 붙인다. 현재진도는 파랑, **목표진도는 붉은색 계열**이다(원장 2026-09-18 *"수학 mcs에서 목표진도는 붉은색계열로 전부"* — 레일·눈금 표시·목표 칩·블록 수까지 전부). 두 줄이 같은 눈금을 쓰기 때문에 색이 어느 줄이 사실이고 어느 줄이 계획인지 가른다. 진도표 고정열의 목표 레일이 이미 붉은색이라(원장 2026-09-14) 두 화면이 같은 규약을 쓴다. 빠름·느림 판정은 색이 아니라 글자와 칩이 말한다.
- 단원 목록은 기존 `onescreen/curriculum`을 그대로 읽는다. 한 학기 단원을 24개 수업 블록에 균등 배분하고 상세의 ‘24블록 학기 진도표’에서 내용을 확인한다. 단원 선택 목록의 순번을 블록 수로 부르지 않는다.
- 정규 실제 위치는 기록된 단원의 상대 위치를 24블록으로 환산한다(소수 첫째 자리). 출석 횟수나 기록 건수를 정규 진도로 대신하지 않는다. 수요일 보고서는 정규 계산에서 제외한다.
- 월 목표는 누적 8·16·24블록이다. 각 월의 정규 수업일에 배분하고 휴강·수강 기간·분리 등원 요일을 반영한다. 수업이 없는 달은 목표 설정에서 확인하도록 한다.
- 수요일 실제는 해당 월, 해당 반의 수업일에 진도 내용이 있는 보고서를 날짜별로 세고 4블록을 상한으로 둔다. 반복 복습은 누적하고 정규 기록·미래 기록·중복 날짜·기간 밖 기록은 제외한다. 5번째 수요일은 4블록 완료 이후의 추가 복습이다.
- 전체 목표 설정 창의 **초기화**(배정 취소)는 **원장 이상급**만이다(원장 2026-09-18 *"'초기화'는 원장 이상급"*). 지우는 범위는 저장이 쓰는 그 한 칸(같은 반·학생·구분·시작월)이고, 옛 `math_learning_goals` 행도 함께 지운다(안 지우면 읽기 폴백으로 곧바로 되살아난다). 수요일 복습 초기화는 옛 표를 건드리지 않는다. 확인 단계를 한 번 거치고 감사로그(`mcs_learning_goal_reset`)에 남는다.
- 목표는 `math_learning_track_goals`에서 구분·시작 월별로 저장한다. 기존 `math_learning_goals`는 이전 목표의 읽기 폴백이며 새 정규 계획이 우선한다. 원본 보고서는 수정하지 않는다.
- 수업일·기록은 선택한 반 기준이다. 다른 반의 기록을 이름만으로 합치지 않는다. 수요일만 수업하는 반은 복습 화면을 기본으로 연다.
- `progress/learning-cadence.ts`의 기간 기준을 진도 시계의 미래 중등 계획과 공유한다. 기존 진도 시계 자체는 샘플 데이터 화면이며 MCS 학생 기록을 새로 연결한 것은 아니다.

검증: MCS·진도 시계·감사 테스트 428개, TypeScript, ESLint, 프로덕션 빌드 통과. 컴포넌트 브라우저 검증은 가상 학생으로 수행하고 실제 목표를 만들지 않는다. 0269c 마이그레이션은 연결 DB에 적용했으며 RLS·서버 전용 쓰기 권한을 확인했다.
