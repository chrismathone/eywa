## 배포 전에 할 일

1. **DB** — `supabase/migrations/0369a_shuttle_vehicle_positions.sql` 적용(새 표 하나 · 앱 배포보다 먼저). 안 깔려 있으면 차량 위치만 안 뜨고 나머지는 그대로 돈다.
2. **환경변수**
   - `NEXT_PUBLIC_KAKAO_MAP_KEY` — 카카오 **JavaScript 키**(지도). 카카오 개발자 콘솔 → 플랫폼 키 → JavaScript 키 → **JavaScript SDK 도메인**에 운영 주소를 등록해야 지도가 뜬다.
   - `KAKAO_REST_API_KEY` — 카카오 **REST 키**(서버 전용 — 회차 도로 경로 · 카카오모빌리티 길찾기). 없으면 경로 선만 안 그려지고 정류장·차량은 뜬다. 🔴 저장소에 넣지 않는다.
3. 정류장 좌표 — 지도·경로·노선도 위 차 위치는 `shuttle_stops.lat/lng`(0244a)가 있어야 한다. 정류장 관리에서 위치를 찍는다.

## 1. 학부모 화면

| 결석 잠금 | 그날 등원이든 하원이든 이미 탔으면 결석으로 못 바꾼다(서버 `absentRideCore`도 같은 판정) |
| 실시간 차량 | '오늘 타고 내리는 곳'(아이 × 등원/하원)을 누르면 그 회차의 정류장(번호) · 도로 경로가 지도에, 제목 아래에 버스 노선도. **탈 곳(초록) / 내릴 곳(주황)** 구분 — 등원 = 우리 정류장 → 학원 도착, 하원 = 학원 출발 → 우리 정류장 |
| 차량 위치 | 운행 중이고 기사 폰이 위치를 보내면 지도 🚌 + 노선도 위 🚌(10초마다 갱신, 60초 넘게 끊기면 회색 '위치 끊김'). **우리 아이 회차만** 서버가 골라 준다 |
| 🔒 수정 마감 강화 | 종전엔 "마감된 회차**로** 옮기기"만 막아서, 이미 떠난 회차에 탄 아이를 다른 회차로 옮길 수 있었다. 이제 **지금 타는 회차가 출발 10분 전을 지났거나 [출발]이 찍혔으면** 그 방향 수정·타지 않기를 막는다(서버 `closedRunsMessage`가 운행 출발 기록도 본다 · 화면 "차량이 이미 출발했어요 · 수정할 수 없어요"). 직원은 종전대로 마감 없음 · 결석은 그대로 가능 |

## 2. 직원 화면

| 차량 위치 보내기 | 오늘 운행 중인 회차 머리 아래 "📡 위치 보내는 중 · ±12m · 방금 보냄". **그 폰에서 [출발]을 누르면 자동으로 켜진다**(다른 폰은 [위치 보내기]를 눌러야 — 사무실 관리자의 위치가 차 위치로 찍히지 않게). 10초 간격 · 화면 꺼짐 방지 · 권한 거부/GPS 꺼짐/https 아님은 한글 안내. [종료]하면 멈춤 |
| 노선도 위 차 위치 | "🚌 지금 학원 출발에 있어요" / "A → B 사이를 지나고 있어요". 기준은 **출발 뒤 찍힌 탑승·미탑승·하차 기록의 가장 뒤 정류장**(기록이 없으면 학원 출발), GPS는 거기서 다음 정류장까지만 민다 — 기록을 건너뛰거나 뒤로 가지 않는다(`map/route-progress.ts`) |
| 지도 | 배지·이름표 축소 + 이름표 겹침 방지(아래 → 오른쪽 → 왼쪽 → 위, 자리가 없으면 이름표만 숨김) · 범례 한 줄 |

## 3. 서버 · 보안

- 위치 받기(`reportVehiclePosition`) — 등하원 기록 권한(`canRecordBoarding`) + **오늘 출발했고 종료 전인 회차**만 · 이상한 좌표/오차 300m 초과는 버림(`checkReport`).
- 위치 읽기 — 관리자(`getStaffVehiclePositions`, `isShuttleAdmin`) · 학부모(`getParentVehiclePositions`, `getParentViewer`의 아이 오늘 구간 회차만). 진행 칸은 정류장 id만 쓰고 다른 아이 정보는 싣지 않는다.
- 도로 경로 — 계산 본체는 server-only(`map/server/route-path-core.ts`), 공개 액션 둘이 권한을 가른다(관리자 / 학부모 = 우리 아이 오늘 회차만). 같은 정류장 조합 10분 캐시.
- 실시간 반영은 10초 폴링(WebSocket이 없는 환경에서도 된다).

## 6. 알아 둘 것

1. **웹 GPS 한계** — 기사 폰 화면이 꺼지거나 다른 앱으로 가면 전송이 멈춘다(특히 아이폰). 운행 중엔 화면을 켜 둬야 한다.
2. **위치 이력 없음** — 회차마다 최신 한 줄. 지나온 자취는 아직 없다.
3. **노선도 진행은 기록 기준** — 기사가 탑승·하차를 안 찍으면 🚌가 다음 정류장 너머로 안 간다(의도).
4. **카카오모빌리티 호출량** — 회차를 열 때 서버가 1회(10분 캐시). 무료 한도 확인 필요.
5. **학원 위치가 코드 고정값**(`map/academy-location.ts`, 인재원 침산남로 140) — 지점이 늘면 학원설정으로.
