지점 연결

웹의 설정 → 연동 → 연동 PC에서 발급한 12자리 코드를 입력하세요.

연동 상태

클래스노트

메이크에듀

PC 설정 잠금

웹의 연동 PC 탭에서 관리 코드를 발급하면 10분 동안 설정을 바꿀 수 있습니다.

기존 워커에서 이전

기존 워커가 하던 작업을 마치고 종료한 뒤, 기존 폴더를 선택해 계정과 기록을 가져오세요. 시작할 때 이전 예약 실행을 해제하고 서버에서도 종료를 확인합니다.

연동 계정

변경할 값만 입력하세요. 계정 정보는 이 Windows 계정의 보안 저장소에 보관합니다.

Google 영상 저장 계정과 폴더는 웹의 숙제영상 드라이브에서 관리합니다. 기존 PC에 저장된 Google 연결은 설정 가져오기로 이전합니다.

이 PC의 옵션

자동 다운로드를 켜도 적용 시점은 새 버전마다 직접 선택합니다.

업데이트

새 버전마다 지금 적용하거나 날짜·시간을 예약하세요. 선택하기 전에는 다운로드한 상태로 기다립니다.

예약은 표시된 버전 한 번에만 적용됩니다. 예약 시간에 PC가 꺼져 있거나 연결할 수 없으면 다시 선택해야 합니다. 진행 중인 작업은 마친 뒤 적용하며, 새 버전이 시작되지 않으면 이전 버전으로 복구합니다.

업데이트 적용 중

  1. 진행 중인 작업 마무리
  2. 새 버전으로 바꾸기
  3. 새 버전 시작 · 서버 연결 확인
