# MCS 학기당 12블록 — 2026-09-18

이 문서는 기존 `RULER-24BLOCK.md`의 블록 수와 눈금 기준을 대체한다.

- 정규는 한 학기·과정 구간을 12블록으로 배분하며 월 4블록, 총 3개월이다. 단원과 수업일 원본은 유지한다.
- 복습·심화는 기존대로 월 4블록이며, 목표 기간 안 해당 반 수업일의 발송 보고서를 날짜별로 누적한다.
- 표시 범위는 현재 진도가 속한 학기 이전 2학기와 현재부터 4학기를 합친 **최대 6학기**다. 현재 차시를 모르면 목표 시작 학기를 범위 기준으로 사용하되 진도 점은 추정하지 않는다. 커리큘럼의 처음·끝에서는 없는 학기를 추가하지 않으며, 고등 선택과목은 선택된 과정만 따른다.
- 파란·빨간 진도선은 정규·복습·심화 모두 **같은 화면 안에서 세부 차시 1개당 동일한 간격**이다. 화면이 넓으면 최대 12px까지 늘리고 좁으면 자동으로 줄인다. 반 전체의 최대 표시 차시 수로 공통 간격을 계산하므로 학생별 전체 길이는 차시 수에 비례하며 검색·필터로 배율이 바뀌지 않는다. 모든 차시를 표시하며 작은 눈금은 희미하게, 목표의 큰 눈금은 선명하게 표시한다.
- 학년·학기는 과거와 미래 모두 빨간 수직선 바로 아래에 빨간 글씨로 표시한다. 목표와 겹치는 학기도 생략하지 않는다. 좁은 화면에서는 두 줄로 나눈다. 과거 학기 끝에도 빨간 원을 표시하되 목표 번호나 가상의 완료 예정일을 만들지 않고 보고서 확인일·추정일을 구분한다. 저장된 목표는 같은 학기에 여러 개가 있어도 모두 표시한다. 마지막 목표 표시는 유지하며, 행마다 반복하던 범위·최근 보고서 설명은 제거하고 날짜와 출처는 툴팁에 표시한다.
- 최근 1년 안에 등록한 학생은 등록일 이후 보고서에서 확인되는 첫 차시부터 과거 구간을 표시한다. 학생 등록일이 없으면 최초 수강일을 사용한다. 오래 재원한 학생은 과거 보고서 보관 기간이 짧다는 이유만으로 이전 두 학기를 잘라내지 않는다.
- 현재 반과 같은 유형의 이전 수학반 보고서도 과거 이력 복원에 사용한다. 이전 수강이 현재 반 최초 수강일까지 종료된 경우만 허용하며, 동시 수강 반이나 이전 반 수강 기간 밖의 기록은 제외한다. 확인된 단원 사이에 빠진 차시 날짜만 보간하고 ‘추정’으로 구분한다. 원본 보고서나 목표에는 쓰지 않는다.
- 전체 진도율은 **표시 시작부터 현재까지 차시 수 / 표시 시작부터 빨간 목표 끝까지 차시 수**다. 계획 대비 차이는 실제·계획 차시 수의 차이이며, 남은 수업당 필요 진도는 남은 차시를 표시 목표까지 남은 수업 횟수로 나눈다. 시간표·수강 기간·휴강일은 기존 계획을 따른다. 목표를 넘은 진도율은 100%를 넘을 수 있으며 필요 진도는 음수가 되지 않는다. 한 학기 12블록·월 4블록 기준은 상세 일정 계획에 유지한다.
- 파란 점은 발송 보고서의 차시와 정확히 같은 눈금에 놓인다. 복습·심화의 수업 횟수 누적은 기존대로 유지하지만, 그 횟수를 차시 위치로 사용하지 않는다. 복습·심화에서 차시를 식별할 수 없는 경우 진도선의 위치를 추정하지 않는다.
- 기존 정규 24블록 목표는 조회할 때 총 블록과 정거장 누적 블록을 절반으로 환산한다. 날짜, 단원, 수정 버전은 유지한다. 새 12블록 계획은 다시 나누지 않는다.
- 목표 확장 시 서버도 기존 정거장을 같은 단위로 환산해 비교하고, 12블록 단위로 저장한다. 과거 정거장 변경과 동시 수정은 계속 거절한다.
- `0273a_math_learning_twelve_blocks.sql`은 새 12블록 계획과 이전 24블록 계획을 모두 허용한다. 기존 저장 행은 변경하지 않아 배포 전후 읽기와 저장이 호환된다.
- 현재 진도는 같은 테넌트·반·학생의 발송 완료 보고서만 읽는다. 성공 상태·발송 시각·Edutrix 발송 링크로 발송을 확인하며 폐기된 보고서는 제외한다. 수업일이 우선이고 같은 날은 발송 시각, ID 순서로 정한다. 기준일 이후 수업은 포함하지 않는다.
- 정규와 복습·심화 모두 목표 시작 전 마지막 확인 단원을 이어받는다. 여러 학년에 걸친 목표도 시작 단원 이전 기록을 진도선에 표시한다. 복습·심화의 블록 누적은 목표 기간 안 수업일만 센다. 최신 발송 내용이 ‘내신대비’·시험·자유 입력이면 마지막 확인 단원과 기준 수업일을 밝힌다. 같은 이름의 고등 단원은 선택된 과정으로 구분하며, 확인 가능한 단원이 없으면 위치를 추정하지 않는다. 다른 반의 보고서가 현재 진도를 덮어쓰지 않는다.
- 목표가 없는 학생도 발송 보고서의 최신 내용은 볼 수 있다. 원본 보고서와 목표 행은 수정하지 않는다.
- 파란 진도 점에 마우스를 올리거나 키보드 초점을 두면 단원·기준 수업일·현재/목표 차시를 확인한다. 최신 보고서가 내신대비라면 마지막 확인 단원의 수업일을 표시한다. 빨간 목표 점은 목표 단원·완료 예정일·누적 차시를 표시한다.
