# 대시보드 데이터·바로가기 검수 — 2026-09-11

로그인된 Orca 브라우저에서 로컬 검수 서버(3032)의 실제 데이터를 사용했다. `/dashboard`와 기존 `/dashboard?view=one`은 같은 화면을 제공한다.

## 변경

- 학교별 학생을 초등·중등·고등으로 나누고 두 행 높이 카드에 배치했다. 기타·미입력 학생도 합계에서 제외하지 않는다.
- 과목별 수강에 동시 수강과 정확한 과목 조합을 추가했다. 같은 과목 여러 반과 세 과목 이상 수강도 학생당 한 번만 집계한다.
- 현재 수업은 넓은 카드에서 과목별 좌우 배치, 좁은 카드에서는 세로 배치한다.
- 일정 제목을 `레벨테스트 및 첫수업 일정`, 날짜를 `yy.mm.dd (요일)`로 통일했다.
- 첫수업 반 연결은 일정일의 유효 수강을 우선한다. 동명이인 접미사·학교 약칭·과목을 함께 확인하며 모호한 후보는 연결하지 않는다. 배정 전에는 과목·학년·요일·시간·강사가 모두 일치하는 반 하나만 연결한다.
- 보고서 문구를 `수업보고서 미확인 건 (48시간 초과)`로 변경했다. 시간은 학원 설정을 따른다.
- 폐지된 브리핑 준비 알림을 생성·목록·미읽음 배지에서 제외했다. AI 멘트 생성·저장 기능은 유지한다.
- 기존 결석 알림도 최신 명칭과 링크로 표시한다. 알림 열기와 보관·삭제 버튼을 분리하고 보관함의 읽음 처리 후에도 보관함을 유지한다.

## 브라우저 연결 검수

기본 카드에 표시된 링크의 고유 경로 36개를 실제로 열고 대상 제목·학생/반·선택 탭을 확인했다. 중복 링크는 같은 경로로 묶었다.

| 영역 | 확인한 도착 화면 |
| --- | --- |
| 학생·수업 | 원생목록, 운영 수업목록, 반복 결석 학생 6명의 출결 탭 |
| 출결 | 오늘 날짜의 출결 처리 현황, 출석부 |
| 수납 | 당월 수납, 청구·수납 목록, 당월 지출 탭 |
| 상담 | 등록상담 통계, 원생상담, 후속 지연 필터 |
| 신규생·보고서 | 신규생 관리, 수업보고서 목록 탭, 영어·수학 강사 시트 |
| 일정 | 시간표, 표시 중인 반 4개의 상세, 첫수업 반 2개의 상세 |
| 행정 | 직원관리, 회의록, 문서, 시험, 셔틀, 결재 대기 |
| 자산·공지 | 자산 목록, 소모품 탭, 학원 공지 |

검수 중 수정한 연결:

- 오늘 출결 입력 → 해당 날짜의 처리 현황.
- 학습·학부모 보고 → 작성률 대신 보고서 목록.
- 행정·자산의 예전 전체 메뉴 링크 제거. 항목별 연결은 유지.
- 반복 결석 카드의 일반 출석부 상세 링크 제거. 학생별 출결과 전체 명단 팝업을 사용.

데이터 대조: 재원생 339명 = 초등 184 + 중등 124 + 고등 31. 영어 234명, 수학 196명, 동시 수강 93명이며 과목별 명단과 일치한다. 첫수업 링크 2건은 실제 반 상세의 당일/예정 학생 배정까지 대조했다.

## 검증

- 관련 Vitest 8개 파일, 59개 테스트 통과.
- TypeScript `tsc --noEmit`, 변경 TS/TSX ESLint, `git diff --check` 통과.
- 브라우저 폭 1920px에서 학교 카드 2행·영어/수학 동일한 y좌표의 좌우 배치, 390px에서 단일 열 전환과 가로 넘침 0px를 확인했다. 모바일 문서 높이는 뷰포트와 일치하며 본문 안에서 스크롤한다.
- 학교 전체 명단 팝업의 열기·닫기, 반복 결석 전체 11명 팝업의 본문 높이 유지와 추가 학생의 출결 탭 연결을 확인했다.
- 기존 결석 알림이 최신 문구로 표시되고, 클릭 후 알림 메뉴가 닫히며 대시보드의 반복 결석 카드로 이동하고 미읽음 배지가 갱신되는 것을 확인했다.
- 적대적 검토: 동명이인·부분 이름·복수 반·휴원/이동/종강·일정 유효기간·강사 열람 범위·폐지 알림의 배지 잔존·보관함 읽음 처리·중첩 버튼을 확인했다.
- 외부 발송, 크론 실행, 업무 데이터 변경 없이 검수했다. 학생/반마다 반복 생성되는 팝업 링크는 동일 컴포넌트의 ID 연결을 검토했으며, 모든 학생·반의 상세를 전수 개방한 검수는 아니다.
