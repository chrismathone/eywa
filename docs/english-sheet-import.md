# 영어 시트 반영

시간표의 영어 과목 메뉴 → **영어 시트 반영** (`/timetable/english-sheet`). 시트 연동 라이선스·권한과 반 일괄 관리 권한이 모두 있어야 사용할 수 있다.

1. 주소에서 탭을 불러와 같은 달의 강사별·통합 명단 탭과 적용일을 선택한다. 숨김 탭도 표시하지만 자동 선택은 공개된 해당 월 탭만 한다. 2026년 10월 마스터 시트는 `강사별영어시간표(10월)`과 앞 공백이 있는 ` 통합영어시간표(10월)`이다. 링크의 `1931155217`은 별도의 숨김 탭이다.
2. 미리보기에서 분류별 적용 불가 사유, 원본 탭/셀, 에이와 수정 링크를 확인한다. EiE 진급은 명단으로 기존 반에 자동 연결해 ID와 이력을 보존한다. 자동 연결되지 않는 반과 강사는 직접 선택할 수 있다.
3. 원본이나 연결을 수정한 뒤 다시 검사한다. 확인 항목은 개별·분류별·전체 확인과 해제를 지원한다. 전체 확인은 적용 불가 오류를 건너뛰지 않는다. 오늘 적용 또는 미래 예약 적용 버튼으로 저장한다. 데이터·검사 규칙이 달라지면 새 미리보기를 받아 다시 확인해야 한다.

EiE 자동 진급은 DB에 EiE로 등록된 반에만 적용한다. 학생 연결이 전부 확정되고, 최소 2명이 겹치며 시트·기존 반 양쪽에서 과반수인 유일한 최다 후보를 선택한다. 이름 숫자로 레벨을 추정하지 않는다. 동점·분반으로 여러 시트 반이 같은 기존 반을 차지하는 경우·프로그램 불일치·근거 부족은 이유와 함께 수동 연결 대상으로 남는다. 수동 선택(연결 해제 포함)은 자동 매핑보다 우선한다. 이름 점유·출결·수강 기간·예약 등의 적용 제약은 자동 연결 이후에도 검사한다.

강사 영문명이 달라도 원본 머리글의 한글 이름이 활성 계정과 유일하게 일치하면 자동 연결한다. 영문·한글이 서로 다른 계정을 가리키거나 동명이인이 있으면 직접 선택해야 한다. 원본 시트나 교직원 이름을 자동 수정하지 않는다.

에이와의 기존 반 이름·명단 매칭·수강 자격/기간·분리등원·담임 최빈값·LAB/JJ·합반 규칙을 재사용한다. 퇴원 학생을 자동 복귀시키지 않고, 기존 휴원과 이동 수강의 분리등원 요일을 보존한다. 원본에서 빠진 수강은 종료하지 않는다. 시트에 없는 반의 배치도 기본 유지하며 마감 선택과 개별 확인을 모두 거쳐야 한다. 중복 수강, 후속 예약, 보관 반 이름 충돌 등은 수정해야 진행할 수 있다. 유지되는 배치를 포함해 강사/방 충돌을 검사하며 학생 수업 시간은 타 과목까지 비교한다.

적용일 이후 미리 입력된 출결은 **기존 출결 이관**에서 학생별 이전 반·교시와 변경 반·교시를 확인한다. 같은 반·교시의 강사·방 변경은 출결을 유지한다. 반이동 또는 시각 변경은 같은 시각 우선, 유일한 동일 강사·자리 또는 하루 한 교시인 경우에 대응 교시를 확정한다. 상태·시수·메모·입력자·정정 이력과 기록 ID를 보존하고 반·교시만 옮긴다. 적용일 전 출결은 그대로 둔다. 새 반의 기존 출결, 여러 교시의 한 칸 합침, 교시 미확정, LAB/JJ 구분 변경, 보강·수업보고서 연결은 적용 불가 사유로 표시한다.

강사별 탭의 읽을 마지막 열은 이 마스터 주소의 경우 `EU`가 기본이다. 뒤쪽에 남은 과거 8월 LAB 영역을 제외하기 위한 값이며 원본 열이 바뀌면 범위 설정을 조정한다. 숫자만 있는 메모와 `EiE LAB`/`EiE JJ` 설명은 제외하고 경고를 표시한다. `EiE Lab실`도 기존 LAB 자리 별칭으로 인식한다.

배치·근무 블록·명단 이동·출결 이관·반 이름·담임·그룹·스냅샷을 한 DB 트랜잭션으로 저장한다. 이동 RPC의 부분 실패도 전체 실패로 처리한다. 적용 직전 출결 원본까지 재검사하며 출결·보고서·보강 쓰기는 트랜잭션 동안 잠금으로 보호한다(잠금 대기 5초 제한). 출결 시각은 UTC로 정규화해 미리보기와 적용 연결의 시간대 차이에 영향을 받지 않는다. 미래 반 이름/담임/그룹은 기존 `apply-due-class-updates` 작업으로 적용되며, 시간표의 예약 배지에서 취소하면 근무 블록과 이관된 출결까지 함께 복원한다. 이관 후 출결이 수정·추가되거나 보고서·보강이 연결되면 취소를 중단한다. 적용일이 이미 시작된 기록은 예약 취소할 수 없다. DB 스키마 변경은 없다.

코드: `src/features/timetable/import/master/`는 순수 검사, `server/master-sheet-{source,store,actions}.ts`는 원본 읽기·원자적 저장·권한/버튼 연결이다. 읽기 전용 CLI 검사는 `scripts/_english_sync/preview-web-master.mts`의 실행 예를 따른다. 원본과 학생 정보가 포함된 결과는 로컬 `output/english-sheet-preview/`에 저장되므로 배포물에 포함하지 않는다.

검증은 계획/트랜잭션 경계/화면 버튼 테스트와 로컬 웹앱의 실제 시트 미리보기로 수행한다. 운영 반영 여부는 성공 메시지와 스냅샷으로 별도로 확인한다.

반 연결의 **명단 보기**에서 원본 학생과 연결된 에이와 학생의 이름·학교·학년·상태, 적용일 기준 기존 영어 반을 확인한다. 비교 명단은 공통·시트에만·기존 반에만·학생 연결 미확정으로 구분하며 학생 ID로 비교한다. 휴원 수강과 적용일에 유효한 수강을 포함하고, 기존 반에만 남은 학생은 자동 종료하지 않는다. 자동 연결과 수동 선택을 구별해 표시한다. 자동 확정되지 않은 추천은 **추천 반 연결**로 선택하거나 다른 반을 직접 선택한 뒤 다시 검사한다.

학생 매칭은 접미사 형제 이름까지 고려하는 기존 규칙을 유지한다. 다만 공백을 제외한 전체 이름이 정확히 일치하고 그 이름의 학생 기록이 하나라면 별도 확인을 요구하지 않는다. 이름이 달라지는 연결(`이도윤 → 이도윤B`)과 실제 같은 전체 이름의 기록이 여러 개인 경우는 확인을 유지하며, 퇴원·미확정 동명이인·수업 충돌 검사는 그대로 수행한다.
