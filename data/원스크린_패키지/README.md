# 선생님 원스크린 — 전체 패키지

선생님의 여러 사이트 왕복을 한 화면으로 줄이는 워크스페이스 + 학생/학부모용 리포트.

## 화면 구성 (3종)
1. **선생님 원스크린** — 수업 마감용. 학생 목록 → 진도 확인 / 일일·확인 테스트 점수 입력 / today 보고서 자동작성·발송. (Tweaks로 레이아웃·밀도·베이스 톤 전환)
2. **학생 데일리 리포트** — 학생/학부모가 그날 하루를 읽는 화면. 오늘 진도·테스트·선생님 한마디.
3. **내 학습 현황(누적 대시보드)** — 학생 로그인 후 보는 누적 화면. KPI · 점수 추이(과목 필터) · 과목별 진도 · 출결 달력 · 최근 기록(클릭 시 그날 리포트로 이동).

## 폴더

> ⚠️ **standalone HTML(파일당 약 23MB)은 2026-11-10부터 git에서 추적하지 않는다**(수정 계획 P4 · 저장소 무게). 받는 법:
> - 이력에서: `git show 32c7bb619df8:"<이 폴더 경로>/<파일 이름>" > "<파일 이름>"` (예: `git show 32c7bb619df8:"data/원스크린_패키지/학생 데일리 리포트 (standalone).html" > "학생 데일리 리포트 (standalone).html"`)
> - 통째로: `git archive -o handoff.zip 32c7bb619df8 data/원스크린_패키지 data/원스크린_전달`
> - 맥 백업 사본: `~/eywa-data/design-handoff-html-backup-2026-11-10/`

- **(루트) standalone 3개**(git 추적 중단 — 위 방법으로 받는다) — 폰트·스크립트까지 모두 박아 넣은 단독 실행본.
  더블클릭하면 인터넷 없이 **1픽셀 동일**하게 열립니다. 그대로 이식/배포·디자인 기준용.
  - `선생님 원스크린 (standalone).html`
  - `학생 데일리 리포트 (standalone).html`
  - `내 학습 현황 (standalone).html`
- **소스/** — 편집용 원본. 화면 간 링크(대시보드 ↔ 데일리 리포트)가 살아 있습니다.

## 실행
- **빠르게/그대로 보기**: 루트의 standalone 파일 더블클릭.
- **편집 + 페이지 이동까지**: `소스/` 폴더를 로컬 서버로 여세요.
  - 예) `소스/`에서 터미널: `python3 -m http.server` → `http://localhost:8000/내 학습 현황.html`
  - 편집본은 React·Babel·Pretendard를 CDN에서 받습니다(인터넷 필요). 오프라인·완전 동일 재현은 standalone.

## 커스터마이즈 (소스/)
- **과목 색**: `data.js` → `SUBJECT_COLORS` (수학·파랑 / 영어·자홍 / 과학·연보라 / 국어·주황 / 사회·청록)
- **학생·진도·점수·이력**: `data.js` → `STUDENTS` + 이력 자동 생성부(결정적이라 새로고침해도 동일)
- **선생님 화면 기본값**: `app.jsx` → `TWEAK_DEFAULTS` (현재 stacked / compact / cool)
- **공용 토큰**: `styles.css`(선생님) · `student.css`·`dashboard.css`(학생/대시보드)

## 데이터/연결 메모
- 데일리 리포트는 `학생 리포트.html?student=<id>&date=<M/D>` 파라미터로 특정 날짜 세션을 렌더링합니다.
- 대시보드와 데일리 리포트는 `data.js`의 동일한 세션 이력을 공유합니다.
