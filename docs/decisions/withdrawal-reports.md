- 작성 요청은 창 크기를 늘리지 않는 오버레이다. 학생은 검색 가능한 드롭다운 하나에서 고르고, 강사·관리자·원장은 복수 선택한다. 작성 강사는 실제 수강 반 담임만 후보이며 대상 수강의 담임 모두를 포함해야 한다. 관리자 목록과 기본 선택은 선택한 담임의 대상 수강 과목에 맞춘다. 여러 과목이면 해당 관리자들의 합집합이며, 강사가 다른 곳에서 가르치는 과목은 포함하지 않는다. 개인별 담당 범위가 있으면 그 범위를 우선한다. 강사를 바꾸면 범위 밖 관리자 선택을 제거하고 새 과목 관리자를 기본 선택하되, 여전히 유효한 직접 선택·해제는 유지한다. 담당 관리자가 없으면 요청을 막고 담당 과목 확인을 안내한다. 이승엽·박소선의 표시 역할은 관리자이며 원장 후보에는 나타나지 않는다. 관리자 후보에도 같은 과목 필터를 적용한다.
- 원본의 성명·학교·학년·반·수강기간·담임·종료일·출결·퇴원사유·상세사유·학생/학부모 상담·담임 의견·원비·미납을 반영. 상세사유는 제출 시 200자 이상. 상담하지 못했다면 사유를 기재한다. 임시 저장에는 제출 필수값을 강제하지 않는다.
