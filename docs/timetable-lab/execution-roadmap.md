## P1 — 공통 연습안 도메인과 영속 저장

제안 경계(폴더/테이블 이름은 구현 전 최종 확인):

```text
src/features/timetable-lab/
  domain/       상태·명령·이력·revision·검사 결과
  constraints/  공유 규칙 어댑터와 완성 상태 검사
  subjects/     영어/수학 교시·뷰 투영 어댑터
  editor/       엔진 포트·키보드·클립보드·포커스
  suggestions/  후보 생성·검사·정렬·취소
  server/       초안 CRUD·CAS·미리보기·반영
src/app/(shell)/timetable/lab/
```

저장할 정보:

- `tenantId`, 소유/편집 권한, 과목, 이름, 적용일, 상태, schemaVersion, revision.
- 기준 스냅샷/해시와 안정적인 class/student/teacher/placement ID.
- 배치의 원본 schedule ID와 이동 후에도 유지되는 ID. 복사로 생긴 별도 배치는 새 ID를 발급하고 원본을 덮어쓰지 않는다.
- 초안 수업 배치, 학생 배정, 비수업 블록, 사용자 잠금, 검사 불가능한 임시 입력.
- 표의 표시 설정과 메모/계산 자료는 운영에 반영되는 의미 데이터와 분리.
- 개인 확대/열 폭/접기 설정은 기존 계정 ui_prefs 규약, 통합표 그룹/줄 구성 같은 안의 내용은 초안에 저장.
- 명령 묶음 ID/이전 revision/다음 revision/역연산 또는 스냅샷, 마지막 서버 저장 시각.

DB는 초안 전용 저장소로 확장하며 RLS/권한/테넌트 격리를 검증한다. JSON 통째 저장 여부와 이력 압축은 실제 자료 크기 측정 후 결정한다. 오래된 자동 저장 응답으로 최신 수정이 유실되지 않게 한다. 실시간 공동 편집은 별도 구현 범위이며 초기에는 revision 충돌을 명확히 해결한다.

통과: D01~D04, H01~H05, 네트워크 실패 복구. 초안 저장은 운영 테이블/출결/알림에 쓰지 않는다.

## P5 — 실제 반영과 예약

기존 `master-sheet-store.ts`의 트랜잭션/출결 이관을 재사용하되, 시트 문자열 파서와 전체 영어 교체를 초안 적용 계약으로 그대로 사용하지 않는다.

1. 안정적인 ID 기반의 목표 상태 → 명시적 `changeSet` 생성. 포함 범위와 삭제 대상은 별도로 명시한다.
2. 기준/현재 운영/연습안의 **3-way 비교**로 운영만 바뀐 내용을 보존하고 양쪽 변경 충돌을 해결한다. 적용일/이력/미래 예약/권한과 해시를 다시 검증한다.
3. 신규·변경·삭제·학생 이동·출결 이관·예약의 미리보기를 표시한다.
4. 서버가 다시 검사한 동일 changeSet만 하나의 트랜잭션에서 반영한다.
5. 멱등 키와 결과 저장으로 재전송을 처리한다. commit 이후 캐시 갱신 실패를 반영 실패로 오인하지 않는다.
6. 반영 이력과 예약 취소는 연습안 Undo와 분리한다. 과거 운영 내역을 즉흥적으로 역연산하지 않는다.
7. 기존 단건 수정/시트 반영과 함께 동시성 경계를 검사한다. 한 경로만 lock을 잡는다고 전체 충돌이 해결되지 않는다.

통과: P01~P07, 실제 DB의 격리 시험/롤백 시험, 기존 영어 가져오기·출결 이관 회귀. 새 스키마가 적용되지 않은 배포에서도 기존 화면은 동작해야 한다.

추가 게이트: 기존 시트 플래너 분리 전후 결과가 같은 골든 시험, 연습안 무변경 적용 시 삭제/종강 0, 운영에서 새로 추가된 학생과 타 반 변경 보존, 미래 예약 뒤 기존 반 수정의 회귀 시험. 기존 시트의 확인 가능 충돌 정책은 바꾸지 않고 연습실도 같은 정책 계약을 명시적으로 따른다. 정보가 부족한 후보는 도우미가 `가능`으로 추천하지 않는다.

**전환 순서**: 연습실 delta 플래너가 기존 하위 순수 함수/트랜잭션 부품을 활용하는 것으로 시작한다. 기존 시트 입력 경로 자체를 공통 플래너로 옮기는 작업은 P5 안정화 이후의 별도 전환이며, 골든 비교 전에는 진행하지 않는다. 추가 탭 보존 작업 S는 이 반영 플래너 전환과 독립이다.

## P6 — 영어 제한 공개와 안정화

- 승인된 지점/역할 범위의 플래그로 노출, 기본 OFF에서 시작.
- 실제 규모에 가까운 합성/허용된 익명 자료로 성능·누수·키보드·브라우저 검증.
- 오류·자동 저장·충돌 계산·추천·반영 성공/실패를 개인정보 없는 운영 지표로 확인.
- 기능 플래그를 내려도 저장한 연습안과 기존 운영 시간표가 유지된다.
- 단축키 전수 대조표에 미해결 제약이 있으면 전체 호환 완료로 발표하지 않는다.

## P7 — 수학 확장과 선택적 JEV

- 수학 교시·배치·강사/반 운영·명단 표현을 어댑터로 구현한다.
- 영어↔수학 학생 충돌, 양 과목 동시 초안/운영 변경, 공유 강의실을 회귀 검증한다.
- 공통 엔진을 그대로 재사용하고 영어 전용 가정을 공통 모듈에 넣지 않는다.
- JEV는 스마트 도우미의 선호 해석/외부 헤더 후보 연결을 별도로 평가한다. 정확한 판정·시수 계산·원자적 반영 경로에는 넣지 않는다.
