# 대시보드 배정·첨부 알림 — 커밋 전 적대적 리뷰

대상: `fix/attachment-only-reply`, 기준 `9b26c762c`.

## 반증과 수정

1. 배치 편집 폼이 이전 직원 배정을 덮는가: 직원 배정 배열을 보존하고 dashboard 기준값 + DB updated_at 충돌 검사를 추가했다. 오래된 폼 거절/배정 보존 회귀 통과.
2. 다른 지점 직원 또는 비원장이 대시보드 범위를 바꾸는가: 원장/총괄·owner 쓰기 게이트, 같은 지점 대상 검증, 직원 폼의 재직/등록 과목 검증을 확인했다. 기존 0327a DB 가드 적용 완료. 타 지점 배정 거절 회귀 통과.
3. 미지정/조회 실패가 전 과목이 되는가: 미지정은 공지만, 관리자 과목 조회 실패는 제한된 기본 배치. 기본값을 현재 전 과목으로 넓히지 않는다. 기존 명시 배정 전 계정의 범위만 호환 유지한다.
4. 직원 숫자가 실제 대상과 다른가: 재직/역할/개인 예외/총괄/모듈 캡을 적용하고 실제 목록에서 센다. 조회 실패는 별도 상태. 학생/퇴직/대기는 제외한다.
5. 역할 확장으로 권한이 열리는가: 역할별 카드 해석의 메뉴 상한, 금액/전화번호 기본 가림, 강사/학생 대시보드 접근 잠금 유지. 옛 other 배치 이관과 기본값 정규화 회귀 통과.
6. 원문 없는 영상을 다른 가정에 연결하는가: 지점·글·댓글 번호·단일 확정 학생·기존 학생 열람 게이트가 모두 필요하다. 시험 모드 우회 금지. 실제 ClassNote 원문이 오기 전 답글/공감 대상 id를 만들지 않는다.
7. 복구가 옛 글을 발송/AI 분류하거나 발송 루프를 지연시키는가: GET 전용, 학부모 첨부 전용만 기존 멱등 저장 함수에 전달. 한 작업만 백그라운드로 실행, 실패 대상 재시도 간격 적용. 피드 세션이 준비된 뒤 시작해 로그인 경합도 피한다.
8. 모바일에서 조작이 잘리거나 역할 목록이 가로로 넘치는가: 1894px/390px Chromium에서 9개 탭, 배치 전환, 해당 직원 목록, 답글 하단 행을 검사했다. 가로 넘침/런타임 오류 0. 긴 공감 상태는 제목을 보존해 줄임표 처리한다.
