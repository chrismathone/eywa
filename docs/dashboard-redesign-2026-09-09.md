# 대시보드 재설계 — 확정 설계서 (2026-09-09)

원장 지시: *"대시보드를 스크롤 없이 한 화면에"*(참고 = HR 엑셀 대시보드의 **스타일**) · *"모든 데이터가
실시간으로 움직여야 한다, 새로고침 없이"* · *"완성되면 열린 창이 없을 때 바탕에 대시보드가 보이게"*.

설계는 **codex(gpt-6-astra)·grok 두 외부 모델에 같은 브리프를 던져 독립으로 받은 답을 합친 것**이다.
🔑 둘이 독립으로 같은 결론에 도달한 항목은 신뢰도가 높고, **갈린 지점이 곧 검증 대상**이다(§9).

---

## 1. 이 화면의 일 (한 줄)
**30초 안에 "오늘 누가·무엇을 막아야 하는가"를 고르는 것.** 학원 전체를 엑셀처럼 그려 주는 것이 아니다.
HR 대시보드에서 가져올 것은 **차트 종류가 아니라 밀도·무스크롤·상단 KPI 스트립**뿐이다.
🔑 이 학원(재원 338 · 반 121 · 오늘 출결 359행)에서 행동으로 이어지는 것은 **분포가 아니라 이름 있는
예외**다. 그래서 본문은 차트 격자가 **아니라** 목록이다.

## 2. 상단 KPI — 4개 (5개 이상은 1120폭에서 숫자가 죽는다)
| 타일 | 주숫자 | 보조 | 그 숫자를 보고 하는 행동 |
|---|---|---|---|
| **재원생** | 오늘 유효 재원 | 이번 달 등록 n / 퇴원 n · 7일 인원 점선 | 퇴원이 등록을 이기면 퇴원관리·상담을 연다 |
| **오늘 출결** | **마감 전 = 미기록 반 수** / 마감 후 = 출석률 % | 결석 n · 지각 n · 처리 n/m반 | 미기록>0 재촉 · 결석>0 무통보만 골라 연락 |
| **이번 달 수납** | 수납 완료 % | 미납 n건 · 완료/전체 · 가로 진행 막대 | 수납관리를 연다 |
| **오늘 할 일** | 결정론 신호 **권한 통과분** 합계 | 구성(미기록·미작성·발송실패·승인대기) | 눈을 바로 아래 목록으로 내린다 |

🔴 **진행 중 출석률을 주숫자로 쓰지 않는다** — 121반 중 40반만 찍힌 %는 항상 높아 보여 **거짓 안심**이 된다.
🔴 **합산한 '총 문제 수'를 만들지 않는다**(대상·단위가 겹친다).
🔴 **영어 미작성 보고서는 세지 않는다**(영어는 ClassNote에 쓴다 — 매일 140명 거짓 경보).
🔴 **살펴볼 학생 건수는 타일로 올리지 않는다** — 아래 목록 머리가 그 숫자다(같은 값 두 번 금지).
색은 **왼쪽 3px 테두리에만**: 0=초록 / 주의=앰버 / 무통보 결석·기한 지난 후속=빨강.

## 3. 차트 — 정확히 2개 (`next/dynamic` 지연로드, 정적 import 금지)
1. **최근 7일 출석률 · 선** — *"이번 주 출석이 무너지나, 어제만 나쁜가"*. Y축은 0–100이 아니라 실제 범위±여유.
   🔴 오늘이 미마감이면 마지막 점은 **점선(진행 중)** 이거나 그리지 않는다.
2. **최근 4주 등록 vs 퇴원 · 그룹 막대** — *"학원이 늘고 있나 줄고 있나"*. 등록=딥네이비 / 퇴원=앰버.

🔴 **쓰지 않는 것**: 도넛·파이(길이 비교 불가) · 교시 히트맵/하루 밀도(원장이 걷어낸 '실시간 운영'의 재탕) ·
과목별 비교(영어 보고서가 외부라 **거짓 대칭**) · 등록상담 퍼널(월 10건은 점이 안 선다) · 차트 3개 이상.

## 4. 격자 (12열 · 스크롤 0 · 내부 스크롤 0 · 탭접힘 0)
```
행1  88px 고정   [재원생 3] [오늘 출결 3] [이번 달 수납 3] [오늘 할 일 3]
행2  1fr(≈400)   [오늘 할 일 목록 5] [살펴볼 학생 4] [일일 브리핑 3]
행3  168px(창)   [7일 출석률 선 6] [4주 등록/퇴원 막대 6]
       220–260px(바탕 — 세로가 남을 때)
바깥 패딩 16 · 갭 8 · 면 화이트 · 구분 1px 테두리
```
- **오늘 할 일 목록**: 결정론 payload를 긴급도 순 최대 10줄(한글 제목 + 건수 + 원본 메뉴 링크).
- **살펴볼 학생**: 결석 위험 + 상담 후속(기한 오늘/지남)을 **한 목록으로 합쳐** 최대 8명.
  🔴 **오늘 새로 찍힌 마일스톤을 맨 위로** — 매일 같은 8명이면 공지와 같아져 아무도 안 본다.
  🔴 결석 사유 원문(건강·가정사)은 이 화면에 **안 올린다**.
- **일일 브리핑**: 유지하되 히어로가 아니라 **숫자 옆의 서술**. 넘치면 fade + 클릭 시 기존 창(새 AI 호출 0).
- 칸이 넘치면 **말줄임 + 원본 창**. 넓어지면 **칸을 더 넣지 않고 칸이 커진다**.

## 5. 최소 크기
| 표면 | 최소 | 근거 |
|---|---|---|
| 창으로 열 때 | **1120 x 720** | 등록상담 선례. KPI 4x~260 + 행2 3칸x~280이 여기서 성립 |
| 바탕화면 | 사이드바(~160) 뺀 영역이 **1120 x 720** | 1366x768 사무 노트북 = 콘텐츠 ~1206x720 |
| 앱 셸 권장 하한 | 뷰포트 **1280 x 800** | 상단바를 빼도 세로 720이 남는다 |

⚠️ **1120에서 3열 목록은 한글 이름이 잘린다**(등록상담 카드가 이미 겪은 실패). 이 설계는 잘림을 전제로 하고
클릭을 원본 창에 맡긴다. 이름+학년을 완전체로 넣으려면 **최소 폭을 1280으로 올려야 하고 그건 원장 결정**이다.

## 6. 실시간 — **행 패치로 화면을 패치하지 않는다**
원칙: Realtime·이벤트버스는 **"더러워졌음"만 알리고**, 숫자는 **집계 RPC 한 번**으로 갈아끼운다.
(출결 INSERT 200건이 2초에 들어와도 200번 그리지 않는다.)

| 지표 | 수단 | 합치는 창 |
|---|---|---|
| 오늘 출결(미기록·결석·처리 n/m) | Realtime + 이벤트버스 | **디바운스 3초 / maxWait 8초** -> RPC 1회 |
| 오늘 할 일 | 해당 표 Realtime | 5초 |
| 재원생·월 등록/퇴원 | 학생 상태 Realtime 또는 폴링 | 30초 ~ 5분 |
| 이번 달 수납 | Realtime 또는 폴링 | 15 ~ 60초 |
| 살펴볼 학생(14일 RPC) | **폴링 5분 + 다시 보일 때 1회** · Realtime 금지 | 무거운 RPC — 출결 폭주에 묶으면 수업 시작마다 멈춘다 |
| 7일 선 · 4주 막대 | 폴링 10분 + 다시 보일 때 1회 | 과거 점 |
| 일일 브리핑 | 폴링 15분(현 5분은 과함) | 저장된 서술 |

**가시성 2단**
1. `document.visibilityState === "hidden"`(다른 탭·최소화) -> **구독 해제 + 모든 interval 정지**.
   `visible` 복귀 시 **집계 1회 + 구독 재개**.
2. **바탕이 창에 가려짐**(같은 문서라 Visibility API가 안 잡는다) -> 구독은 유지하되 **RPC·리렌더 금지,
   dirty 플래그만**. 창 관리자가 "바탕이 다시 보인다"를 내면 dirty면 1회 flush.
   🔴 `document.hasFocus()`를 쓰지 말 것 — 출석부 창에 타이핑 중이면 포커스는 창에 있다.
🔴 숫자 카운트업·차트 전환 애니메이션 **금지**(떨림의 절반은 트랜지션이다).
🔴 채널은 **학원당·세션당·표 몇 개**이지 반 121개 구독이 아니다.
🔴 **늦게 온 응답이 최신 숫자를 덮지 않게** 한다. 갱신 실패를 **0으로 그리지 않는다**.
🔴 화면 전체에 **하나의 "기준 시각"을 붙이지 않는다**(주기가 지표마다 다르다 — 칸마다 적는다).

## 7. 권한 — **확정 뒤 격자를 만든다**(조회하고 감추기 금지)
영역 플래그 6개(출결·수납·학생·상담·직원·브리핑)로 칸을 켜고, **꺼진 칸의 쿼리는 만들지 않는다**.
빠진 칸은 "권한 없음" 자리를 남기지 않고 **남은 트랙이 먹는다**. 단 **허용된 칸의 결과가 0건인 것은 다르다** —
그 칸은 유지하고 '미기록 없음'처럼 상태를 적는다.
- 출결만 -> 타일 1(미기록) + 할 일·살펴볼 6/6 + 7일 선 12열(입퇴 막대 삭제)
- 수납만 -> 타일 1 전폭 + **미납 상위 목록을 본문으로**(전권한 화면에서 버린 것을 이 역할에서 되살린다)
- 학생만 -> 재원생 + 입퇴 신호 + 4주 막대
- 여러 권한 = **합집합 격자**(역할별 페이지가 아니다)
🔴 **AI 브리핑은 통짜 텍스트라 권한 밖 정보가 샌다** — 권한 범위로 생성·저장된 판이 있을 때만 보여주고,
   없으면 그 칸을 빼고 재배치한다. 캐시 키에 **권한 프로필**을 넣는다.
🔴 **강사 계정엔 이 화면을 마운트하지 않는다**(홈은 원스크린) — 새어 들어오면 미기록 순위판이 된다.

## 8. 틀리기 쉬운 것 (구현 중 계속 대조)
1. **시간축 혼선** — 오늘/이번 달/7일/4주/14일이 한 화면에. 칸 제목에 축을 **글자로** 박는다.
2. **미시작 = 미기록 거짓 경보** — 휴원일·아직 안 열린 교시를 분모에 넣으면 아침부터 빨강.
3. **PostgREST 1000행 절단** — 숫자는 RPC, 목록은 서버 `limit`.
4. **0건 = 조회 실패 = 예정 없음** 셋을 같은 초록으로 그리면 원장이 전화를 안 한다.
5. **등록 처리일 != 수강 시작일** — 섞이면 차트와 학생목록이 다른 학원이 된다.
6. **recharts 정적 import** — 바탕 첫 페인트가 367KB에 막힌다. KPI·목록은 차트 청크 없이 그려져야 한다.
7. **이벤트버스만 믿고 Realtime을 빼면** 옆자리 데스크가 찍은 출결이 원장 화면에 안 온다(둘 다 같은 진입점).

## 9. 두 모델이 갈린 지점 = 원장 결정 대기
| 쟁점 | codex | grok | 채택(잠정) |
|---|---|---|---|
| KPI 4칸 | 미기록·살펴볼 학생·수납 미완료·상담 후속(**전부 할 일**) | 재원생·오늘 출결·수납·오늘 할 일 | **grok** — 바탕화면이라 '체온'이 필요하다 |
| 차트 | 오늘 출결 가로막대 + 이번 달 입퇴 막대(**추세선 없음**) | 7일 출석률 선 + 4주 입퇴 막대 | **grok** — 타일은 수준, 선은 방향 |
| 권한 축소·실시간 규칙 | 상세 | 상세 | **양쪽 합집합**(6·7) |
