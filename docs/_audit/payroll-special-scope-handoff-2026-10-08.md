# 개인별 급여 산정 범위: 고등학생 + 전 학년 특강

## 요청과 기준

- 이성우 선생님의 기존 대상은 학생 학년 `고등`이었다. 2026-10-08 운영 조회에서 고용 형태는 프리랜서이며 정규·특강의 초·중·고 비율은 모두 50%다.
- 요청에 따라 이 선생님의 특강은 학년과 관계없이 포함한다. 대상 밖 정규 수업은 계속 제외한다. 코드에 이름이나 계정 ID를 조건으로 넣지 않는다.
- 주말내신특강 중2·중3은 2026-09 회차 확정 기록이 각각 10줄·9줄이고 수납이 있는 청구서와 연결되어 있다. 반 이름의 종강 날짜가 수업한 달의 급여를 없애지는 않는다.

## 구현

- 기존 `attendance_salary_rates.rates` JSON에 개인별 `includeSpecial: true`를 추가한다. 생략·false는 기존 동작이며 다른 선생님의 설정은 변경하지 않는다. 스키마 변경은 없다.
- 특강 판정은 기존 `isSpecialLecture`를 쓴다(특강 토글 또는 이름에 '특강'). 대상 학년 판정·학년별 비율·반별 예외 비율의 우선순위는 공유한다.
- 학년 미확인 특강은 초·중·고 특강 비율이 모두 같거나 반별 비율이 있는 경우에만 지급 비율을 확정한다. 정규 수업의 미확인 학년은 기존 검증을 따른다.
- 확정 단가·수업한 시수·청구액 상한·0원·차감·반올림 규칙을 바꾸지 않는다. 수납 여부를 별도 전역 필터로 추가하지 않는다. 미확정 단가는 기존처럼 '빠진 줄'로 표시한다.
- 출석부 실급여, 합계, 프리랜서 명세서, 인쇄 별지, 수업인원·퇴원·연 누적은 같은 개인별 범위를 쓴다. 학생 단위 필터로 특강에 포함된 중학생의 정규 수강까지 되살리지 않도록 수강 구간마다 거른다.
- 명세서 지표의 반 범위는 프리랜서가 실제 가르친 달의 출석부를 따른다(종강·담임 이력 포함). 일반 고용 형태의 티어 정산은 그대로다.
- 발행된 명세서는 기존 동결본을 보존한다. 새 동결본에는 `sheetIncludeSpecial`도 저장한다.
- 출석부 '비율 설정'에 '특강은 학년 제한 없이 포함'을 두었다. 관리자 쓰기 권한과 지점·선생님 검증은 기존 액션을 따르며, 설정 변경은 한글 감사로그로 남긴다.

## 검증

- 급여·명세서·비율 설정 17개 파일 288개 테스트 통과.
- 출석부와 감사로그 198개 파일 2,998개 테스트 통과.
- 전체 TypeScript 검사 통과. 변경 파일 ESLint 오류 없음(기존 인쇄 클래스 경고 1개).
- 전 학년 특강, 정규 제외, 다른 선생님의 기본 동작, 0원, 청구액 상한, 미확정 단가, 같은 학생의 중복 수강 구간, 설정 저장·감사로그를 검증했다.
- 운영 자료 조회·로그인 화면의 기존 9월 명세서를 읽어 변경 전 기준을 확인했다. 테스트를 위해 실제 명세서를 발행하거나 수납·출결을 변경하지 않는다.

## 후속 개인별 설정 공간

- 사용자는 우선 이 수정부터 푸시한 뒤 개인별 예외 설정 공간을 원했다.
- 추천 위치는 직원 상세의 급여 탭이다. 동일한 출석부 급여 설정을 연결하고 개인별 적용 범위를 한눈에 보여준다. 새 계산식이나 별도 저장소를 만들지 않는다.
- 급여 설정을 볼 수 있는 관리자만 개인별 설정을 열고, 쓰기 권한이 있을 때만 수정한다. 고용 형태·대상 학년·특강 예외·반별 예외 비율을 한 사람의 설정으로 관리한다.
