> 대상 파일: [`curriculum.ts`](./curriculum.ts) (`MATH_CURRICULUM`)
> 최종 점검: 2026-06-01 · 누락 **17차시 남음** (초3·초4 입력 완료 ✓ · 초5~6 남음. 중등은 차시 코드 없어 누락 개념 없음)

## 무엇인가

초등 차시 코드(`학기-단원-차시`, 예: `1-2-3`)에서 **번호가 건너뛴 자리**다.
원본 커리큘럼을 받아 `~` 범위를 개별 차시로 분리하는 과정에서, 원본에 애초에
빠져 있던 차시들이 그대로 비어 있다. **차시 이름을 받지 못해** 코드만 비어 있는 상태.

- 진도 선택 동작에는 지장 없음 — 데모 학생 9명의 진도는 전부 **존재하는** 차시로 맞춰 둠.
- 채우려면: 아래 코드 자리의 **차시 이름**을 확인해, `curriculum.ts`의 해당 단원 `lessons`
  배열에 코드 순서대로 끼워 넣으면 됨.

## 채우는 법

`curriculum.ts` → 해당 학년 → 해당 단원 `lessons`에 `"<코드> <차시명>"` 형식으로 삽입.
코드 오름차순 유지. 구분자 `·`는 테스트 범위 분할과 충돌하므로 차시명에 쓰지 말 것.
