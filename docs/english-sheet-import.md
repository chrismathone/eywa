# 영어 시트 반영

시간표의 영어 과목 메뉴 → **영어 시트 반영** (`/timetable/english-sheet`). 시트 연동 라이선스·권한과 반 일괄 관리 권한이 모두 있어야 사용할 수 있다.

1. 주소에서 탭을 불러와 같은 달의 강사별·통합 명단 탭과 적용일을 선택한다. 숨김 탭도 표시하지만 자동 선택은 공개된 해당 월 탭만 한다. 2026년 10월 마스터 시트는 `강사별영어시간표(10월)`과 앞 공백이 있는 ` 통합영어시간표(10월)`이다. 링크의 `1931155217`은 별도의 숨김 탭이다.
2. 미리보기에서 적용 불가 사유, 원본 탭/셀, 에이와 수정 링크를 확인한다. 진급은 기존 반을 직접 연결해서 ID와 이력을 보존한다. 명단 일치는 후보 안내이고 자동 진급 근거가 아니다. 강사 별칭도 직접 연결할 수 있다.
3. 원본이나 연결을 수정한 뒤 다시 검사한다. 기존 가져오기 규칙상 확인이 필요한 충돌은 항목별로 확인한다. 오늘 적용 또는 미래 예약 적용 버튼으로 저장한다. 검사 후 데이터가 달라지면 새 미리보기를 받아 다시 확인해야 한다.

에이와의 기존 반 이름·명단 매칭·수강 자격/기간·분리등원·담임 최빈값·LAB/JJ·합반 규칙을 재사용한다. 퇴원 학생을 자동 복귀시키지 않고, 기존 휴원과 이동 수강의 분리등원 요일을 보존한다. 원본에서 빠진 수강은 종료하지 않는다. 시트에 없는 반의 배치도 기본 유지하며 마감 선택과 개별 확인을 모두 거쳐야 한다. 적용일 이후 출결, 중복 수강, 후속 예약, 보관 반 이름 충돌 등은 수정해야 진행할 수 있다. 유지되는 배치를 포함해 강사/방 충돌을 검사하며 학생 수업 시간은 타 과목까지 비교한다.

강사별 탭의 읽을 마지막 열은 이 마스터 주소의 경우 `EU`가 기본이다. 뒤쪽에 남은 과거 8월 LAB 영역을 제외하기 위한 값이며 원본 열이 바뀌면 범위 설정을 조정한다. 숫자만 있는 메모와 `EiE LAB`/`EiE JJ` 설명은 제외하고 경고를 표시한다.

배치·근무 블록·명단 이동·반 이름·담임·그룹·스냅샷을 한 DB 트랜잭션으로 저장한다. 이동 RPC의 부분 실패도 전체 실패로 처리한다. 미래 반 이름/담임/그룹은 기존 `apply-due-class-updates` 작업으로 적용되며, 시간표의 예약 배지에서 취소하면 근무 블록까지 함께 복원한다. 적용일이 이미 시작된 기록은 예약 취소할 수 없다. DB 스키마 변경은 없다.

코드: `src/features/timetable/import/master/`는 순수 검사, `server/master-sheet-{source,store,actions}.ts`는 원본 읽기·원자적 저장·권한/버튼 연결이다. 읽기 전용 CLI 검사는 `scripts/_english_sync/preview-web-master.mts`의 실행 예를 따른다. 원본과 학생 정보가 포함된 결과는 로컬 `output/english-sheet-preview/`에 저장되므로 배포물에 포함하지 않는다.

검증은 계획/트랜잭션 경계/화면 버튼 테스트와 로컬 웹앱의 실제 시트 미리보기로 수행한다. 운영 반영 여부는 성공 메시지와 스냅샷으로 별도로 확인한다.
