## 합의한 주요 결정

1. 수학 소수 반부터 도입하고 영어 교시/원수업 묶음은 별도 확정·검증한다. 다른 날짜 분할, 날짜별 다른 실시강사, 한 참여의 복수 원결석 배분을 지원한다.
2. 기존 같은 강사의 정규+1보강 흐름과 시수 산식을 보존한다. 같은 학생·과목·날짜의 둘째 보강 및 같은 일별 칸의 다른 강사 귀속은 첫 출시에서 거절한다. 보고서 upsert 전에 막는다.
3. 보강 권리 잔량·급여 시수/귀속·청구 소비를 별도 장부로 둔다. 청구 소비는 최신 0267a의 quantity_basis에 따라 시수 합 또는 일수이며, 옛 0263a 날짜 수를 전체 규칙으로 쓰지 않는다.
4. 노쇼·부분검증에서 미실시 배정을 해제하고 의무는 유지한다. 인정 반전은 원배분만 복원하며 실제 출결/급여/청구를 자동 수정하지 않는다. 살아있는 약속은 별도 취소 후 종결한다.
5. 원사건 UID와 접수 경로를 나누고 출결·이관·정정은 source aliases로 연결한다. 가짜 결석일을 만들지 않는다. 추가 지도 앵커/돈 정책 확정 전에는 예약 확정·출결 연결을 차단한다.
6. 보강 효과 실패가 정규 출결/키오스크 등원을 막거나 되돌리지 않게 한다. 수기 시수 차이와 노쇼 후 선반영 시수는 대사·관리자 정정으로 해결한다.
7. mapped 직접쓰기 보호와 모든 명단·보고서·영상숙제·시수/수납/급여·시간표 이동/삭제 소비처를 연결한다. 기능 종료는 on/draining/off로 구분하고 저장된 mapping 보호를 유지한다.
8. 정규 합류/합반을 실제 학생·방·정원 충돌과 구분한다. 모든 관련 writer의 새 공통 잠금/보호 계약과 실패 복구를 출시 조건으로 둔다.
