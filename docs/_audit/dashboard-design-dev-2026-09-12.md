## 확정된 화면

기존 카드 순서와 반응형 열 배치를 유지한다. 현재 수업은 수업·운영 영역의 원래 위치에서 한 번만 표시한다. Pretendard와 기존 스티커 아이콘을 사용하며, 배경 #f1f5fa·흰 카드·남색 주요 수치·구분된 제목과 여백을 적용했다. 선택한 표현 스타일은 _overview/appearance.module.css에 둔다.

- 상단 6개 카드는 항목명과 큰 숫자만 표시한다. 클릭하면 프로그램별 인원·명단·일정 등을 간이 팝업에서 확인한다. 결석 기준은 '어제'로 짧게 표시한다. 갱신 실패는 느낌표 및 팝업 설명으로 알린다.
- 영어 #D23C48, 동시수강 #9B2EB7, 수학 #1267D5, 미수강 #47505C를 사용한다. 흰 배경 대비는 각각 4.69·6.05·5.35·8.17이다.
- 과목별·학년별·초중고별·학교별·신규생 단계별 그래프, KPI 팝업, 강사 시트, 현재 수업 과목 제목에 같은 과목 색을 적용한다.
- 누적 막대는 영어·동시수강·수학 순이며 안쪽 흰색 1px 구분선으로 나눈다. 학년·급별 미수강은 맨 아래 독립된 진회색 막대다.
- 학교별·신규생 단계별 막대는 전체 인원을 유지하고 기타 과목·미수강까지 분해한다. 학교 전체 보기 팝업에도 동일한 구성을 사용한다.
- 콜&상담은 지난달·이번 달의 접수·결과·등록 전환율을 비교하고 각 월 목록으로 연결한다.
- Blender로 렌더한 책 이미지는 헤더의 정적 19,642바이트 WebP다. 배포 이미지는 public/previews/dashboard/study.webp, 재생성 코드는 scripts/design/render-dashboard-study.py에 있다. 중간 PNG·Blender 파일은 배포하지 않는다.

## 데이터

기존 loadOverview·useOverview·권한 정책·30초 갱신과 실시간 구독을 유지한다. 실패한 조회를 0으로 표시하지 않는다.

학교·학년·급별 집계는 같은 재원생과 프로그램 매핑을 사용하며 학생을 중복 제거한다. 신규생은 기존 관리 대상인 재원·휴원 학생을 유지하고, 종료되지 않은 과목 행을 학생 한 명으로 접어 집계한다. 과목 미지정 수강이 있는 학생을 미수강으로 오인하지 않도록 기존 조회에서 수강 여부도 전달한다. 추가 DB 조회는 없다.

상담은 기존 집계 RPC를 지난달 1일~다음 달 1일(KST, 끝 제외)로 제한한다. 1월에는 전년도 12월을 포함한다. 다른 화면의 연간 통계는 유지하며, 과거 연간 스냅샷도 화면에서 월 키로 두 달만 고른다.

- 최종 적대적 리뷰: 집계 중복·미수강/기타 과목 구분·KST 연도 경계·조회 실패·권한 범위·실시간 구독·팝업·바로가기·기존 배치를 검토했다. 차단할 앱 결함은 발견하지 않았다. 새 체크아웃에서 이미지 재생성이 실패하지 않도록 로그 폴더 생성만 보완했고 Python 구문 검사를 통과했다.
