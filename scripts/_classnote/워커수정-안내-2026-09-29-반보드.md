## 무엇이 달라지나

| 기능 | 내용 | 켜는 법 |
|---|---|---|
| 수학 반별 발송 | 보고서를 1인 보드 `(수학)이름` 대신 **aywa 반과 같은 이름의 반 보드**로 올립니다. 반이 없는 보강 보고서는 선생님이 보낼 반을 고릅니다. | 보고서 설정 → '수학 발송 경로' (기존 / 반별 / 일부 선생님만 반별) |

| 회수 | 반 보드로 나간 보고서도 지금의 '회수' 버튼으로 똑같이 지워집니다. | 자동 |

- 1인 보드 `(수학)이름`은 **그대로 둡니다**(해제하지 않습니다).
- 🔴 **원아 해제·반 삭제는 자동으로 하지 않습니다** — ClassNote가 막아 두었습니다. 퇴원·반 이동한 원아는 ClassNote 화면에서 손으로 해제해 주세요.
- 반 단체 공지는 보드의 원아가 **전부 aywa 재원생과 맞을 때만** 나갑니다. 하나라도 어긋나면 보내지 않고 이유를 화면에 적습니다.

## 적용 방법 (연동 PC 경로 = `C:\eywa-sync-pc`)

1. zip을 풀어 **`C:\eywa-sync-pc\scripts\_classnote` 폴더 전체**를 덮어씁니다.
   ⚠️ **일부 파일만 덮지 마세요** — 이번엔 **새 파일이 여러 개**입니다
   (`class-route-decide.mjs`·`classnote-class-route.mjs`·`class-notice-guard.mjs`·`classnote-class-notice-core.mjs`·
   `math-class-boards-apply.mjs`·`math-class-boards-db.mjs`·`math-class-boards-sync.mjs`·`math-class-teachers.mjs`).
   하나라도 빠지면 워커가 아예 못 뜹니다.
2. **PowerShell을 "관리자 권한으로 실행"** 한 뒤 아래를 붙여넣습니다.

```powershell
cd C:\eywa-sync-pc
Get-CimInstance Win32_Process -Filter "Name='node.exe'" |
  Where-Object { $_.CommandLine -match 'watch-classnote-queue' } |
  ForEach-Object { Stop-Process -Id $_.ProcessId -Force }
Start-ScheduledTask -TaskName eywa-classnote-worker
```

3. 끝입니다.

### 🔴 압축만 풀면 적용되지 않습니다

이미 돌고 있는 워커는 옛 코드를 메모리에 들고 계속 돕니다. 위 2번을 **반드시** 하세요.

### 적용 확인

새 코드가 돌면 워커 하트비트에 **`mathClassRoute`·`classWideNotice`·`classBoardSync`** 가 실립니다.
적용하셨다고 말씀만 해 주시면 조회해서 확인해 드립니다 — **확인된 뒤에** '수학 발송 경로'를 바꾸세요.
