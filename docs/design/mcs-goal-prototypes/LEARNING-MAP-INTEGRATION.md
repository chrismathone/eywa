# 학생 진도맵과 MCS 연동 — 2026-09-18

MCS 학생 목록과 집중 보기의 ‘진도맵’에서 실제 학생 지도를 연다. 전체 진도율, 계획 대비 차이, 남은 수업과 필요 차시는 MCS와 동일하다. 연간·분기·월간·주간·일간 지도는 선택한 기간에 배치된 차시의 도달률을 표시한다. 과거 학기를 복습했다는 이유로 차시가 중복되거나, 지난 날짜라는 이유로 완료 처리되지 않는다.

## 데이터와 접근

1. `/mcs/progress-map?classId=…&student=…&month=…`가 MCS 메뉴 접근을 확인한다. 잘못된 식별자나 배열 매개변수는 404다.
2. `getStudentLearningMap`이 `getMathSheetMonth`의 반 접근 게이트와 해당 월 명단을 사용한다. 다른 테넌트·반 접근이 거절되거나 학생이 명단에 없으면 학습 기록을 조회하지 않는다.
3. `getMathLearningData`를 선택 학생 한 명으로 호출한다. 목표와 현재 진도는 목록과 같은 쿼리·계산이며, 해당 반의 발송 보고서는 30건 제한 없이 가져온다. 등록 전·기준일 이후·폐기·미발송 기록은 포함하지 않는다. 복습·심화는 목표 시작 전 마지막 확인 단원도 볼 수 있도록 앞선 보고서를 포함하되 목표 종료 후 보고서는 제외한다.
4. 종료된 이전 수강의 같은 유형 수학반은 기존 `buildLearningHistory` 규칙으로 과거 차시 이력에만 반영한다. 현재 반 진도를 다른 반 기록으로 바꾸지 않는다. 날짜를 보간한 차시는 ‘추정’으로 남는다.
5. 학생 식별자 없는 기존 시안은 관리자 이상에게만 열리는 별도 샘플이다. 실데이터 조회 실패·목표 없음·권한 거절을 샘플이나 0%로 대체하지 않는다.

## 계산의 단일 소스

기존 화면 전체를 `buildLearningDashboard`로 연결한다. `ProgressMapPanel`의 단계별·연간·연속 지도, 분기와 월별 `CurriculumTimelineCard`, ‘계획 대비 실제’, ‘입학부터 종강까지’의 학기 카드 및 지금 학습·다음 단원을 실데이터 화면에 함께 표시한다. 학생 식별자 없는 관리자 시안은 기존 쪽수 모델을 유지한다.

- **단계별 지도:** 선택한 연도→분기→월→주→일로 확대한다.
- **연간 지도:** 같은 연도의 분기·월·주·일 링을 함께 표시한다.
- **연속 지도:** 탐색 월 앞 5개월·뒤 6개월의 합계와 링을 사용한다. 시계를 돌리거나 월 슬라이더·연도 정거장·세로 목록을 움직이면 같은 월로 이동한다. 연속 12개월의 비율과 전체 목표의 비율은 범위를 구분한다.
- 월 제목은 원본 수학 커리큘럼의 대단원을 사용하고 상세에는 세부 차시를 표시한다. 실데이터에 없는 교재 쪽수·선형 일수 차이를 만들지 않는다.

- `learningTopicTicks`: 등록 이력으로 잘린 시작점부터 현재 이전 2학기 + 현재부터 4학기, 최대 6학기의 모든 세부 차시.
- `learningRailMetrics`: 현재 눈금 수, 표시 목표까지 눈금 수, 전체 진도율, 기준일 계획, 차이, 남은 수업, 수업당 필요 진도. 지도는 이 결과를 그대로 사용한다.
- `learningTopicPositions`와 `progress.days`: 한 차시의 계획일은 누적 계획 블록이 그 차시 위치에 처음 도달하는 실제 수업일이다. 새 요일·휴일 규칙이나 쪽수 환산을 만들지 않는다.
- `buildLearningMap`: 차시당 원장 항목 하나. 목표 범위 내 항목을 연도→분기→월→주→일로 분할한다. 분자는 현재 차시 위치까지 도달한 항목 수이며 비율을 평균하지 않는다. 복습으로 현재 위치가 되돌아가면 MCS와 함께 분자도 되돌아간다.
- 계획 시작 전 차시의 날짜는 보고서 확인일 또는 명시된 추정일이다. 계획 안의 차시는 계획일을 사용하며 실제 보고서 날짜도 별도로 유지한다. 일정이 없으면 보고서 날짜를 가상의 계획일로 쓰지 않는다.
- 날짜가 없는 차시는 ‘날짜 미확정’에 보존한다. 연도별 배치 차시와 미확정 차시의 합은 표시 목표의 전체 분모와 같다. 전체 진도율과 특정 연도 도달률은 분모가 다르므로 각각 범위를 표시한다.
- 일별 어댑터의 `lessons.positions`를 직접 세므로 같은 날짜의 차시 번호가 비연속이어도 사이의 차시를 가산하지 않는다. 반복 보고서를 추가해도 차시를 중복 가산하지 않는다. 보고서만 있는 시험·복습 수업도 목록과 상세에서 보존한다.
- 학기 카드의 완료 판정도 현재 차시 위치에서 가져온다. 과거 날짜라는 이유로 완료시키지 않으며 미확인 진도는 `—`와 ‘확인 필요’를 유지한다.

## 양방향 선택

- 파란 현재 점 → 마지막으로 단원이 확인된 수업일과 차시. 최신 보고서가 내신대비여도 그 날짜로 현재 위치를 덮지 않는다.
- 빨간 목표 점 → 완료 예정일이 속한 월과 실제 목표 차시. 예정일이 휴일이어도 해당 월의 계획 수업일을 함께 볼 수 있다.
- 과거 학기 끝 점 → 확인/추정 수업일과 해당 차시. 확인일이 없으면 알려진 계획일을 사용하고, 둘 다 모르면 날짜 미확정 상태로 연다.
- 지도 기간 선택 → 같은 기간에 배치된 계획 눈금 및 보고서 이력 눈금 강조. 개별 단원 선택 → 동일 차시 강조 및 계획일/수업일 전환.
- 기간별 목록과 원형 지도는 같은 선택 상태를 사용한다. 연간 목록은 월별로, 월간 목록은 주별로 펼쳐 세부 차시까지 진입한다.
- URL의 `month`는 MCS 기준월이다. `date`와 `view`는 탐색만 바꾸며 기준일과 전체 실제 수치를 바꾸지 않는다. `topic`은 학년+단원 식별자라 학기 이동으로 눈금 번호가 바뀌어도 같은 단원을 찾는다. 새로고침·뒤로 가기·키보드 선택과 `embed=1`을 유지한다.
- `display=drill|full|continuous`도 URL에 보존한다. 모드만 바꿀 때 날짜·차시는 유지하며 목록의 자동 스크롤과 화면 크기 변경은 선택 날짜를 바꾸지 않는다. 사용자가 직접 목록을 스크롤할 때만 지도와 URL을 따라 움직인다. 스크롤 탐색은 `replaceState`를 사용해 뒤로 가기 목록을 채우지 않는다.
