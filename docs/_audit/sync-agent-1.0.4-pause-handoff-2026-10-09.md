# 연동 앱 1.0.4 계획: 앱에서 바로 일시 중지·재개

## 사용자 지시와 상태

2026-10-09 사용자는 기존 설정을 가져오려다가 `연동을 일시 중지하고 현재 작업이 끝난 뒤 가져와 주세요`라는 안내를 확인했다. 웹앱에서 중지해야 하는 것으로 느껴지므로 **1.0.4에서 워커 앱 안에서 바로 중지할 수 있게 검토하고 반영**하도록 요청했다. 동시에 **지금 구현하지 말고 기억해 두라**고 명시했다.

이 문서는 구현 계획만 기록한다. 런타임 코드·버전·릴리스 순번·배포된 1.0.3 EXE와 ZIP은 변경하지 않았다. 다음 1.0.4 작업 때 이 지시를 포함한다.

## 현재 기능과 불편의 원인

- 1.0.3은 `이 PC의 옵션`에 `이 PC에서 연동 일시 중지`와 `옵션 저장`을 제공한다. `main.cjs`의 `settings` 명령이 로컬 설정을 저장하고 `Supervisor.drain()`을 호출한다. 웹의 연동 ON/OFF를 변경할 필요는 없다.
- 옵션 변경은 관리 코드로 설정 잠금을 해제해야 한다. 상단에 바로 중지하는 버튼이 없어 사용자가 가져오기 차단 문구와 떨어진 아래 옵션을 찾아야 한다.
- 가져오기 명령은 실행 중인 모듈이 있으면 차단한다. 이 조건은 기록·세션 복사와 실행 중 쓰기의 충돌을 막으므로 유지해야 한다.
- 프로세스가 떠 있다는 뜻의 `Supervisor.busy`와 업무 실행 중이라는 뜻을 혼동하지 않도록 화면에서 `실행 중 → 작업 마무리 중 → 일시 중지`를 구분해야 한다.

## 1.0.4 구현 방향

1. 상단 `연동 상태` 가까이에 **연동 일시 중지 / 연동 재개** 버튼을 둔다. 일시 중지 여부, 마무리 중인 모듈, 가져오기 가능 상태를 같은 위치에서 보여준다.
2. 일시 중지는 관리 코드 없이 허용하는 별도 명령으로 설계한다. 로컬 `paused` 값만 저장하며 계정·Google 인증·지점 연결·웹 설정·모듈 토글 변경 권한은 추가하지 않는다. 앱 종료와 마찬가지로 로컬 실행을 멈추는 동작이다. 기존 설정 입력 명령의 잠금은 유지한다.
3. 중지를 누르면 새 작업 시작을 막고 기존 drain 경로로 보고서 게시·동기화·영상 업로드와 결과 기록을 마무리한다. 자식 프로세스를 강제 종료하거나 처리 중 DB 행을 완료로 바꾸지 않는다. 모듈 종료 확인 후 가져오기를 허용한다.
4. 재개는 로컬 일시 중지만 해제한다. 웹 설정, 모듈 사용 설정, 연결 상태, 유효한 실행 임대, 이전 워커 종료 확인과 계정 준비 조건을 그대로 다시 확인한다. 웹에서 끈 연동이나 해제된 PC를 버튼으로 다시 켜지 않는다.
5. 가져오기 차단 안내에서 상단 중지 동작으로 바로 이동할 수 있게 한다. 작업이 끝나기 전에 폴더 선택·기록 복사가 시작되지 않도록 한다. 가져오기 후에는 이전 계정 설정으로 워커가 재기동하지 않도록 재개 시 새 저장 값을 읽는다.
6. PC 옵션의 일시 중지 체크박스와 상단 버튼은 동일한 로컬 설정을 사용한다. 종료·업데이트 적용·연결 해제 중의 중복 클릭, 네트워크 단절과 재연결, 자동 시작 때도 상태가 일치해야 한다.

## 필요한 검증과 릴리스 조건

- 실제 컨트롤러 fixture에서 설정 잠금 상태의 일시 중지는 성공하고 계정 수정·다른 옵션 변경은 거부되는지 확인한다.
- 작업 수행 중 중지는 다음 작업을 시작하지 않으며, 영상·첨부 마무리와 모듈 종료 전에 가져오기를 열지 않는지 확인한다.
- 로컬 재개가 웹 OFF·임대 상실·연결 해제·업데이트 적용 중 상태를 우회하지 않는지 확인한다.
- 관리 코드 없는 중지·재개와 기존 옵션 저장 경로가 같은 상태를 표시하는지 확인한다.
- 패키지에서 실제 버튼 동작·자동 시작·창 닫기·재실행을 확인한 뒤 **새 릴리스 순번의 1.0.4**로 게시한다. 기존 sequence 5의 파일·명세·해시는 덮어쓰지 않는다.

Google 영상 설정 이전은 별도 운영 확인 항목이다. 상단 중지 UI를 만들었다고 Drive 계정·폴더 이관이 완료된 것으로 판단하지 않는다. 현재 학원이 테스트와 서버 댓글 수정의 실제 검증 결과는 [1.0.3 검수](sync-agent-1.0.3-live-acceptance-2026-10-09.md)를 참조한다.
