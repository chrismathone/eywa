지점 연동

하나의 앱에서 지점의 연동을 관리합니다.

지점 연결

웹의 설정 → 연동 → 연동 PC에서 발급한 12자리 코드를 입력하세요.

연동 상태

클래스노트

보고서·공지·학부모 연락·숙제영상 보관

메이크에듀

학생·상담·수납·반 동기화

PC 설정 잠금

웹의 연동 PC 탭에서 관리 코드를 발급하면 10분 동안 설정을 바꿀 수 있습니다.

기존 워커에서 이전

기존 워커가 하던 작업을 마치고 종료한 뒤, 기존 폴더를 선택해 계정과 기록을 가져오세요. 시작할 때 이전 예약 실행을 해제하고 서버에서도 종료를 확인합니다.

연동 계정

변경할 값만 입력하세요. 계정 정보는 이 Windows 계정의 보안 저장소에 보관합니다.

Google 영상 저장 계정과 폴더는 웹의 숙제영상 드라이브에서 관리합니다. 기존 PC에 저장된 Google 연결은 설정 가져오기로 이전합니다.

이 PC의 옵션

시작과 종료를 같게 두면 모든 시간에 허용합니다. 진행 중인 작업을 마친 후 적용합니다.

업데이트

새 버전을 자동으로 받고 검증합니다. 새 버전이 시작되지 않으면 이전 버전으로 복구합니다.

창을 닫아도 알림 영역에서 계속 실행됩니다.
