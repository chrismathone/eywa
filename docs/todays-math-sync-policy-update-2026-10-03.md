# 운영 확인 후 확정한 연동 정책

2026-10-03 사용자의 후속 지시다. 최초 Claude·Grok 검토 계획 이후 변경된 사항이며, 아래 항목은 최초 계획의 이름 비교·기존 계정 확인·이전 지점 자료 유지 조건보다 우선한다. 구현·배포 여부는 [운영 적용 기록](todays-math-sync-production-2026-10-03.md)에서 확인한다.

## 기존 교사 계정의 자동 이전

- 신뢰 설정과 서명을 검증한 에이와의 현재 자격을 기준으로 동기화한다. 이메일을 앞뒤 공백 제거·소문자로 정규화해 기존 계정을 찾는다. 공급자별 점·별칭 추측은 하지 않는다.
- 기존 계정과 이메일이 유일하게 일치하면 이름과 무관하게 자동 연결하고 해당 지점으로 전환한다. 이름의 `선생님` 표기 차이뿐 아니라 다른 이름도 확인 절차를 요구하는 이유로 사용하지 않는다.
- 기존 계정 ID·비밀번호·학습 기록을 보존한다. 데모 지점의 해당 교사는 새 계정을 만들지 않고 `인재원 침산`에 연결한다. 연결 이후에는 에이와의 고정 사용자 ID를 사용하고 재동기화는 멱등 처리한다.
- 다른 원본 신원이나 다른 관리 연결이 이미 점유한 계정, 정규화한 이메일이 중복인 경우, 보호 계정은 자동으로 빼앗거나 합치지 않는다. 수동 정지·거절·삭제를 자동 해제하지 않는다.

## 반과 학생 명단

- 연결된 교사의 원본 수학 반과 반별 학생 명단을 함께 반영한다. 교사 계정만 연결하고 실제 담당 관계를 누락하지 않는다.
- 기존 교사 소유의 이전 가능한 로컬 반·학생도 지점 전환에 함께 반영한다. 반·학생·시험 ID와 학습 이력을 보존하고, 다른 교사의 자료나 다른 관리 연결에 속한 반은 옮기지 않는다. 시험의 지점 범위는 연결된 반을 따른다.
- 학생 매칭은 원본 학생 UUID로 한다. 이름만으로 학생을 병합하지 않는다. 복수 수강·휴원·수강 종료와 과거 이력을 유지한다.
- 미확인·퇴사 교사 또는 담임 없는 반을 임의의 사람에게 배정하지 않는다. 필요한 원본 담당 정보 또는 명시적 보관 담당자를 확인한다. 영어 시험 등 요청 범위 밖의 자료는 별도로 보존한다.

## 학생 로그인 계정

- 동기화는 학생 명단·반·학습 정보만 생성한다. 학생 로그인 계정을 자동으로 발급하지 않는다.
- 학생 계정은 권한 있는 사용자가 **계정 생성**을 명시적으로 실행했을 때만 만든다. 일반 학생 추가와 계정 발급을 혼동하지 않는다.
- 지점 관리자 이상이 허용된 지점의 학생 계정을 발급한다. 일반 교사는 원본에 관련 capability가 있더라도 계정을 발급하지 못한다. 권한은 화면뿐 아니라 모든 발급 API·서비스에서 검증한다.

## 계정 목록의 연결 표시

- 실제 연결된 계정은 이름 오른쪽에 연결 고리를 표시한다. 마우스를 올리거나 키보드로 확인하면 실제 지점명을 넣어 `인재원 침산과 연동됨`처럼 안내한다.
- 연결되지 않았거나 보류된 계정은 끊어진 연결 고리와 해당 사유를 표시한다. 같은 지점에 속한다는 사실만으로 연동 완료로 판단하지 않는다.
- 브라우저에는 표시용 상태·지점명·정리된 사유만 전달한다. 원본 control 전체, 내부 예외 원문, 인증 값은 전달하지 않는다.

기능 OFF·퇴사 시 삭제 대신 정지, 수동 정지 보존, 서명·고정 주소·멱등 처리·최대 60초 권한 확인, 일회용 SSO 등 나머지 계약은 유지한다. 실제 풀이 결과를 에이와에 영속 저장하는 역방향 연동은 계속 추후 단계다.
